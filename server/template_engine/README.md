# V2 模板草稿生成器

`generate_v2_template.py` 是单次模板草稿生成入口。它只负责生成剪映
5.9 原生草稿和结构报告，不启动剪映，也不负责视频导出。

`runner.py` 是 V2 服务调用的执行器：

- 排队记录提交后才启动一个后台线程；
- `RUN_LOCK` 保证模板生成器同一时间只有一个任务；
- 成功写回草稿、报告和模板配对参数路径；
- 失败或超时写入中文错误，并恢复本次领取的真人视频文件名。

T06、T07、T08 已从生产 CLI（命令行入口）移除。对应旧模块保留为迁移
参考，不能由生产任务直接调用；BGM、真人资源和调整/特效等成片阶段能力
由后续成片生成器实现。

当前完成边界：结构生成与本地状态回写已接入。剪映打开、视频导出和 MP4
媒体验收仍是后续独立阶段，不能仅凭脚本返回成功认定完成。
