# 小V猫 MCP 工具能力清单

**现场快照：2026-10-28**  
**来源：** 当前运行的小V猫 MCP `tools/list` 实时响应，加上用户提供的 MCP 工具设置截图；115 个暴露工具逐项保留工具名、工具说明、输入参数 Schema 及 MCP annotations，另外登记 4 个界面列出但未启用的工具。

## 口径与边界

- 设置界面共列出 **119 个工具**：当前 `tools/list` 实际返回 **115 个可用工具**，另有截图中明确显示“未启用”的 **4 个写工具**。差额已由用户提供的截图核实，不再视为未知工具。
- 这是 MCP 能力目录，不等于 V3 已接入或已允许调用。当前 V3 `server/publishing/vcat.py` 仅允许 4 个只读工具（账号列表、草稿列表、发布任务列表、发布参数查询），其余工具都被 V3 本地白名单拒绝；真实发布另有独立写入门禁。
- MCP `annotations.readOnlyHint`、`destructiveHint` 是工具提供方的提示，不是安全保证；写入、诊断刷新、平台访问、删除/隐藏等工具仍须逐项审查。
- 本次目录获取和数据验证均为只读；未创建草稿、未发布、未刷新诊断/统计、未改账号或MCP写入权限。
- 不含本机账号昵称、UID、Cookie、令牌、作品数据或平台登录信息。

## 与“账号数据”方向直接相关的能力

- `vcat_list_accounts`：账号、平台、昵称、分组、登录状态及粉丝总数。
- `vcat_get_overview` / `vcat_get_account_stats`：账号总览、粉丝/播放/作品/互动等统计与分日数据。
- `vcat_list_posts` / `vcat_get_post` / `vcat_get_post_daily`：作品列表、单作品表现、违规原因和可用的分日指标。
- `vcat_get_post_stat`：作品KPI、违规数量、平台分布、发布时段、趋势和账号排行。
- `vcat_list_punish_feeds` / `vcat_get_verify_result`：异常作品及账号诊断问题、账号状态、近期异常视频。
- `vcat_refresh_account_stats`、`vcat_verify_account(s)`、`vcat_refresh_account_feeds`：会触发平台访问或刷新，不应混入默认自动读取；应设计成用户明确操作并呈现更新时间/失败状态。
- `vcat_delete_punish_post` / `vcat_hide_punish_post`：删除/隐藏异常作品，破坏性操作，不适合纳入普通分析页。

## 后续复核建议

- 若要补齐截图中的 119 个工具，应先确认截图时小V猫版本和 MCP 模块开关，再重新获取 `tools/list`；新增工具以新快照追加/更新，不手工编造。

- 平台明确返回的诊断原文、工具同步到本机的统计缓存、V3 根据指标计算的关联信号，应分层展示并标明来源和更新时间。
