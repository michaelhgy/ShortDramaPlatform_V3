## 2. 成片生成：中插 / 尾插 可选 + 可指定序号

- **现状（2026-09-17 核查）**：
  - 素材取自 `生成资源/引流视频/`，文件名以"中插"/"尾插"开头。
  - 代码**自动取序号最大的一条**（`final_engine/runner.py` 的 `_numbered`），**用户无法指定**。
  - **两条都必须有**：缺一条直接报错（"缺少可用的中插或尾插视频"）。
  - 已有例外：素材**太短**时自动跳过中插（成片结构降级为 爆款-尾插）。
  - 成片主轨结构在 `jianying59_final/composition.py` 里**写死只认两种**：`爆款-中插-爆款-尾插` 或 `爆款-尾插`。
- **用户要求**：
  1. 中插、尾插各自可**要/不要**；**三种组合都要支持**（不要中插 / 不要尾插 / 两个都不要）。
  2. 默认用**最新序号**，但可以**手动改成指定序号**（即选用目录里的哪一条素材）。
  3. **两层配置**：设置里设一次**全局默认**；个别剧集可以**单独覆盖**；不覆盖就用全局。
- **已确认（2026-09-17 用户拍板）**：
  - 覆盖层级 = **生产任务级**（界面上"日期-账号-剧名"那个卡片）；设一次，该任务下所有成片都听它的。
  - "最新序号" = **动态跟随**：每次生成时重新在目录里找序号最大的那条；若用户手动指定了某一条，则锁定那一条。
  - 优先级约定：**人工设置优先于"素材太短自动跳过中插"的自动判断**；只有用户没设过时才走自动逻辑。
  - 界面形态：设置页放**全局默认**；生产任务上放"跟随全局默认"开关，关掉才展开单独设置。
- **影响面（已核查，供排期参考）**：
  - `server/final_engine/runner.py`（选素材逻辑、缺件报错）
  - `server/final_engine/jianying59_final/composition.py`（成片结构校验必须扩展，否则新组合会被拒）
  - 设置页（全局默认）、生产任务界面（覆盖项）
  - 数据库需要新增"中插/尾插策略"的存放位置
