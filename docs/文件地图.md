## tools/ 目录详解：你该双击哪一个？

> 2026-09-17 体检（引用关系已核实）。**日常只需要 `start_v2_desktop.bat`，其余不用记。**

| 文件 | 是什么 | 谁在用 |
|---|---|---|
| ⭐ **`start_v2_desktop.bat`** | **日常启动入口**：双击即起（V2 服务 8782 + 前端 3000 + 窗口） | 你；README、术语对照表等 5 份文档都指向它 |
| `run_v2_desktop_restart.py` | 上面那个 bat 的实际调用者：先清掉残留进程再重启 | 被 `start_v2_desktop.bat` 调用 |
| `run_v2_desktop.py` | **正式版入口**（加载已构建的前端），**打包成 exe 用的** | `packaging/v2_portable.spec`（打包）+ 2 个后端测试 + 微信指数抓包 |
| `run_v2_desktop_test.py` | 开发用窗口（起 Vite 开发服务器 + pywebview 窗口，1440×920） | 被 restart 调用；见 `docs/Desktop_Test.md`、`docs/UI迁移规则.md` |
| `run_v2_file_service.py` | 只启动后台数据服务（8782），不弹界面 | 被 restart / test 调用（内部依赖） |
| `run_v2_final_generation.py` | 🔧 手工调试：给指定素材排队生成成片（需传 ID） | 备用，日常不用 |
| `run_v2_real_export.py` | 🔧 手工调试：跑一次真实剪映导出（需传任务 ID 与草稿路径） | 见 `docs/V2视频导出器设计.md`；备用 |
| `verify_v2.py` + `一键验证.bat` | 一键验证（后端测试 + 前端类型检查，自带隔离） | 见 `docs/验证基线.md` |
| `__pycache__/`（4 个 .pyc） | Python 自动生成的缓存 | 🟢 可再生、不进 git，**不用管** |
| `tmp_taskcenter_zip_0827/`（3 个文件） | 2026-08-26 的临时打包副本（内容与 `src/components/taskcenter/` 重复） | 🟡 疑似垃圾，**未清理**（按铁律：宁可归档不删除） |

> ⚠️ 最容易混淆的一对：`run_v2_desktop.py`（**正式版 / 打包用**）与 `run_v2_desktop_test.py`（**开发测试用**）——名字像、用途完全不同。
