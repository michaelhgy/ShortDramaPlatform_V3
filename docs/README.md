# docs/ 怎么用（门牌）

> 打开这个文件夹不知道点哪个？**按下面 1→4 看就够了**，其余是"用到才查"。

## ⭐ 从这里开始

| # | 想知道什么 | 点这份 |
|---|---|---|
| **1** | **现在什么状态、等我决定什么** | `1-交接进度总览.md`（30 秒看完） |
| **2** | **某个功能是什么规矩** | `功能档案/README.md` → 再点对应那份说明书 |
| **3** | **接下来要做什么** | `2-待做需求清单.md` |
| **4** | **以前为什么这么做** | `4-决策日志.md` |

## 其余几份（用到才查）

| 文件 | 什么时候看 |
|---|---|
| `0-业务全景.md` | 想看"这门生意整体怎么跑"（开新会话第一份读它） |
| `3-验证基线.md` | 改完代码要验、想知道当前基线数字 |
| `7-多机部署现状.md` | 要给多台电脑装的时候（里面有你还没答的 5 个问题） |
| `6-视频号算法与短剧分发机制.md` | 平台算法 / 判重 / 红线 / 法规（行业知识） |
| `8-本机第三方插件清单.md` | 想查本机装了哪些 AI 助手插件 |
| `5-文档索引.md` | 全部文档与归档件的总目录 |

## 两个文件夹

| 文件夹 | 里面是什么 |
|---|---|
| **`功能档案/`** | **每个功能一份说明书**（19 份）：它做什么 / 怎么用 / 业务规则 / 可调参数 / 改动须知。**"某功能什么规矩"的唯一出处。** |
| **`archive/`** | **历史文档**（41 份）：过期、已完成、被取代的旧文档，**都不删**，每份顶部标了"替代文档在哪"。 |

## 几条规矩（免得又变乱）

- 新功能做完 → 在 `功能档案/` 建或改对应档案，并更新 `功能档案/README.md` 的状态列。
- 时间性内容（进度、排查过程、某次决定）**不进档案** → 去 `4-决策日志.md` / `2-待做需求清单.md`。
- 决策日志**按天分卷**：正文只留最近一卷，更早的进 `archive/`。
- 改了 `docs/` 里任何一份 → 顺手更新 `5-文档索引.md` 的状态列与日期。
