# V2 生产文件迁移清单

本文只列迁移判断，不授权代码、数据库或文件系统修改。

## 可复用的 V1 能力

| V1 能力 | V2 用途 | 迁入条件 |
| --- | --- | --- |
| 素材目录扫描、自然排序、媒体扩展名筛选 | 生产文件/素材扫描 | 输出目录改为 V2 生产文件目录 |
| 安全两阶段重命名和失败回滚 | 原素材编号命名 | 按 V2 文件名规则适配 |
| 文件内容哈希 | 爆款素材去重 | 增加 MD5；保留 SHA-256 兼容历史数据 |
| 模板、成片、导出任务与版本记录 | 模板和成片生产 | 归属从 V1 计划批次调整为 V2 生产任务 |
| 导出文件与媒体参数校验 | 成片完成判定 | 保留 V1 严格串行剪映队列 |
| 文件所有权检查、清理预览、物理先于数据库 | 删除剧集和立即清理 | V2 清理后保留已发布业务记录 |

## 必须改造的 V1 规则

| V1 当前规则 | V2 目标规则 |
| --- | --- |
| `爆款/批次/剧集` 实为普通生产素材输入 | 改为 `生产文件/创建日期/账号/剧集/素材`；爆款资产另设内容资产池 |
| 成片按发布日期账号目录保存 | 成片放入同一生产任务的 `成片` 目录 |
| 模板属于计划级目录 | 模板归属当前 V2 生产任务 |
| 真人资源移动到 `模板/素材库/已使用/批次` | 保留在生成资源原目录，改为 `已使用_...` 前缀 |
| 发布后整份计划 24 小时清理 | 按单个生产任务和文件类别分别计算清理时间 |
| 清理后删除生产、模板、成片、导出等数据库记录 | 已发布任务只更新文件清理状态，保留业务、发布、收益和清理记录 |

## 必须新增的 V2 能力

- 五个一级目录的自动初始化和后端路径服务。
- 生产任务与每个物理文件的关联、清理状态和清理到期时间。
- 爆款素材的 MD5、资产池副本、来源信息和跨任务复用关联。
- 发布登记的省、市、区或县、详细地址字段。
- 系统设置中的生产过程文件和原素材保留期。
- 已使用真人资源的临时领取清单及到期清理。
- 已发布任务的“已清理”文件状态，而不是删除业务历史。

## 实施顺序

1. 确认本规则及字段定义。
2. 建立 V2 后端文件路径与生产任务数据合同，不改动既有 V1 目录。
3. 已迁入素材扫描、自然排序、安全重命名和 MD5/SHA-256 记录；媒体时长、分辨率等校验仍待单独接入并用真实视频验收。
4. 迁入模板、成片和导出输出位置。
5. 接入登记发布、删除剧集、立即清理。
6. 接入爆款素材复制、MD5 去重和复用。

每一步均先完成真实文件、数据库和 V2 界面的一致性验收，再进入下一步。
