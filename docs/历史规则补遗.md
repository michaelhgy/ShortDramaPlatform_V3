## 任务中心

- 任务上的按钮（重试/重新生成/重新导出）是"业务逻辑"不是界面装饰：资格来自真实适配器事实（hasValidDraft 有没有有效草稿、hasCompletedFirstExport 有没有完成过首次导出）；任务运行中或首次导出前，不显示任何动作按钮；Mock/演示数据不算生产状态。【待确认】
- 清理任务记录：只删任务记录，**不删账号、剧场、剧集、文件**；保留"任务→文件"的所有权链。操作顺序必须是：暂停 → 备份 → 事务 → 完整性检查 → 恢复 → 用真实界面复核。【待确认】

## 剪映自动化（高危区，碰之前必读）

- 离屏（看不见的）控件**禁止直接点**——会注入真实鼠标点击，可能点到别处。
- "调用成功"≠草稿真的打开了；草稿标题要按精确全名匹配。
- 导出参数对话框没有取消按钮：用窗口关闭方法，Esc 不可靠。
- 保存后草稿短暂"看不见"：等 3 秒，别急着重新生成。
- **草稿结构合法 ≠ 导出成功**：必须等导出完成 + ffprobe 验证视频文件。【待确认】

## 模板工厂（34 轨合同）

- 唯一业务规则源：T-031（34 轨合同）；T-036 是第一优先级资源门（历史"还有更多"≠收敛完成）。

- 不重写轨道、不降级补位。【待确认】

## 成片合成契约

- 一爆款 → 一成片；模板配对必须同 seed/草稿/账号日期；模板视频**只循环、不拉伸**。
- 账号 ID、"影视效果请勿模仿"、"内容由AI制作"——这些是**合成轨**，不是模板轨。【待确认】

## 队列与暂停

- 手动/自动 是全局导出调度策略；剪映 5.9 **严格一次只导一个**。
- 验收标准：导出确认按钮消失 + MP4 文件稳定 + ffprobe 通过。
- 排队顺序：等待中的按提交时间升序；历史记录按完成时间倒序。
- 暂停语义：当前正在做的做完，之后不再接新任务；"安全退出"只以暂停状态为准。【待确认】

## 内容侧（抖音硬规则，6 条）

- 视频号 ≠ 抖音，两套轨严禁串用。
- 星图/分销 6 死规：不超授权集数、单故事线、不剧透、≤3 分钟、不盗片、用官方挂载组件。
- **血泪案例（2026-06-22）**：《蛊镯新月》解说超出授权集数 → 被限流为仅自己可见；改成单线才通过。【已确认的教训】

## 工程坑（踩过，勿再犯）

1. 模板子进程必须强制 UTF-8 输出编码（默认 GBK 会把成功误判成失败）。
2. 仓库根目录跑测试会报找不到模块：要先切到 backend 目录或设置路径。
3. SQLite 外键约束关闭时**不保护数据**——删任务可能留下孤儿文件记录（差点删掉文件所有权）。
4. 本机改了一半的代码直接打包 ≠ 能交付（漏文件、依赖、首机配置都要验证）。
5. PyInstaller 的"可选依赖警告"不等于失败，要看运行时证据。
6. Ollama 视觉模型：请求超过 8192 上下文直接报错；尾巴检测限 3 张 320px 采样；每个检测器都要显式指定模型或禁用视觉（曾静默用错模型）。
7. 前端 dist 是旧的会让源码改动"看起来没生效"（桌面版用的是打包产物，不是源码）。
8. "页面有按钮 / 接口有地址" ≠ 功能完成（发布按钮曾调用未注册的接口，界面显示成功但实际没记录）。
