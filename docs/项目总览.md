# V3 项目总览

状态：当前有效｜最后确认：2026-11-13

V3 是短剧推广运营系统当前开发版本，覆盖账号、剧集资料、资源与模板、成片生产、平台发布、收益采集和运营分析。

V3 沿用现有业务数据目录和数据库。自动检查使用临时工作区；源码、开发版、安装包、真实运行和用户验收分开判断。

## 主流程

账号与剧集资料 → 资源处理与模板 → FFmpeg 成片 → 发布工作台 → 官方交付 → 收益与运营分析 → 过程清理。

当前新成片流程使用 FFmpeg，保留原声，模板缓存可复用；旧剪映链路只作历史兼容。官方接受定时可以计为交付完成，本地草稿、失败、未匹配和结果不明不计完成。

## 当前边界

- 业务数据库、原视频、素材、剪映草稿和正式导出文件不因源码整理自动移动或删除。
- 测试产物和发布证据不属于当前事实入口，统一放在项目外归档。
- 隔离检查不能替代正式桌面、真实平台、另一台电脑、长时间批量和用户观感验收。
- 当前行为以 `docs/当前/功能/` 为准；旧事项只用于追溯。
