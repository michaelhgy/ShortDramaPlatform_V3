# 数据与文件边界

状态：当前有效｜最后确认：2026-11-13

## 业务数据

- 默认业务目录：`D:\短剧推广运营系统`。
- 业务数据库和业务记录长期保留；测试使用临时工作区。
- 生产文件、内容资产、生成资源、剧集资料和系统数据按业务规则管理，不由源码整理脚本处理。

## 项目工作区

- `src`、`server`、`public`：当前源码和静态资源。
- `packaging`：构建脚本、安装器、发布基线和更新包。
- `tools`：工具源码及产品运行所需的固定资源。
- `local-test-output`：当前活动测试产物；结束后归档。
- `docs`：当前文档，不放视频、完整安装目录和测试副本。

## 清理顺序

盘点 → 分类 → 归档 → 验证 → 删除。未确认用途的文件先归档；缓存可以重建，正式业务文件不自动删除。
