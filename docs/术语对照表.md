## 业务流程

| 你的说法 | 系统里的名字 | 备注 |
|---|---|---|
| 剧场 / 子剧场 | theaters / sub_theaters | |
| 账号 | accounts | 六态：正常/限流/二限/实名/封禁/停用 |
| 剧集 / 计划剧集 | dramas / plan_dramas | 剧目库 ≠ 计划剧集，两码事 |
| 爆款素材 | materials（ViralMaterialService） | "已使用"目录的素材别搬回 |
| 模板草稿生成器 | template_engine | 生成剪映草稿，track01~11 轨道 |
| 成片 / 成片草稿 | final_engine | ffmpeg 合成、封面、黑边、尾帧检测 |
| 剪映导出 | v2_exporter + windows_automation | 模拟键鼠 + UIAutomation，高风险区 |
| 收益采集 | v2_revenue_service | 青柠/顶好/触摸/花生；定时任务 revenue_auto_scheduler |
| 发布登记 / 清理 | publish_records / 清理任务 | "删除剧集"（未发布）/ "立即清理"（已发布） |
| 人工检查 | awaiting_human_check | 成片要人看过才算数 |
| 微信指数 | wechat_index_*（V2 内置模块）；另有独立项目 wxindex-drama-analysis | ⚠️ 现在有两套 |
| 本地视觉 AI | local_vision_ai → Ollama qwen2.5vl 3b/7b | 尾帧/画面检测用 |
