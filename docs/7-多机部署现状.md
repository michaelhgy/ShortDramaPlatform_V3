## 另一台电脑怎么用

1. 把完整发布包复制到目标电脑。使用安装版时运行 V3 安装程序；使用便携版时先完整解压，再运行 `ShortDramaPlatformV3.exe`，不能只复制这个 EXE。
2. 第一次打开时选择业务数据盘，软件创建该盘的“短剧推广运营系统”目录；系统组件和业务数据分开。
3. 打开随包的“使用说明.html”，按“导入原始风景 → 裁切入库 → 模板参数 → 模板制作 → 选模板 → 批量合成”操作。
4. 先用测试素材生成一个短模板和一条带声成片，实际查看后再批量生产。

## 目标电脑环境

- Windows 10/11 64 位、WebView2 运行环境。没有 WebView2 时，先安装微软提供的运行环境。
- 推荐 NVIDIA 显卡及可用驱动，以使用硬件编码。程序会检测 NVENC，无法使用时主体编码退回 CPU；没有在无 NVIDIA 的目标电脑完成全流程实测，速度不能沿用本机结果。
- 不需要另装 Python 或 Node；新 FFmpeg 模板及成片链路不依赖剪映。
- 继续使用旧剪映兼容功能或本机 AI 时，需要按对应功能另外配置剪映或 Ollama，它们不随此包安装。
- 为软件及持续增长的模板缓存、视频留足磁盘空间。软件库的约 2.6 GB 不是业务缓存上限。

## 软件迁移和业务迁移分开

新机器可以从空业务目录开始，每台机器数据独立，不自动汇总、同步，也不会从本机网络自动读取素材。

若要继续本机任务和历史次数，需要在任务结束并关闭软件后另行备份、迁移完整业务目录。已完成模板需要 MP4、同名配方文件、系统数据内的模板包和使用账；只拷 MP4 无法合成。部分数据库和配方保存绝对路径，优先保持相同盘符和目录；跨盘符恢复没有在本次打包中实现。不要把原始素材与任务仍在写入的数据库直接当成稳定备份。

同机 V2/V3 保留同一数据盘设置和 8782 单实例护栏，轮流运行。独立的 V3 安装目录不代表共享数据库可以无风险退回任意旧版。升级前结束任务、退出软件并备份业务目录，安装时不自动停止用户程序。

## 后续重新打包

日常小修改优先制作轻量更新包，首次安装或依赖、固定素材变化时再制作完整包。更新程序、版本适用范围、失败恢复和两种构建命令见[软件发布与轻量更新](功能档案/04-跨模块规则/软件发布与轻量更新.md)。首个2026.10.25.1到2026.10.25.2更新EXE约30.28MB，独立真实安装升级及媒体运行通过；已经是2026.10.25.2的电脑无需重复更新。

先执行前端类型、测试、构建和相关后端检查，再用Windows CPython 3.12.10执行 `packaging/build_v3.py --version YYYY.MM.DD.N`。日期后的修订号用于同日更新，版本支持三段或四段。构建目录必须是新版本，拒绝覆盖已存在发布。V3专用定义为 `packaging/v3_portable.spec`，资源闭包来自 `packaging/v3_resources.py`，每个文件保存哈希；安装定义为 `packaging/v3_installer.iss`。

`build-metadata.json` 记录版本、实际构建工具版本和包含未提交改动的源码摘要，不能仅用 Git 提交号判断包内代码。`ffmpeg-runtime.json` 及许可证随包保留。发布版本的 SHA-256 用来核对复制是否完整。
