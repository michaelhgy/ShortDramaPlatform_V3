# V2 Windows 桌面窗口测试

> ⚠️ **启动步骤已过时（2026-09-17 标注）**：下面第一步要求先启动 **V1 的 API（127.0.0.1:8765）**，但 **V1 已停用**、V2 已自建后端。
> 现行开发启动方式请用 `tools/start_v2_desktop.bat`（V2 服务 8782 + 前端 3000）。
> 下方的**验收清单仍然有效**（窗口 1440x920 / 最小 1100x720、显示缩放 100/125/150%、顶部导航、独立滚动）。

此入口仅用于 V2 UI 的 Windows 桌面窗口测试。它复用 V1 当前使用的 `pywebview` 和 Edge WebView2 引擎，以及 V1 的窗口基线：默认 `1440x920`，最小 `1100x720`。

它不会修改或启动 V1 业务逻辑，不修改数据库、API、文件系统或剪映流程。V1 API 与 V2 开发服务器仍由开发者分别启动。

## 启动

终端一：

```powershell
cd D:\ShortDramaPlatform\backend
python run_v1_api.py --port 8765
```

终端二：

```powershell
cd D:\ShortDramaPlatform_V2
npm run dev
```

终端三：

```powershell
cd D:\ShortDramaPlatform_V2
python tools\run_v2_desktop_test.py
```

若 Vite 使用了非默认端口，例如 `3002`：

```powershell
python tools\run_v2_desktop_test.py --url http://127.0.0.1:3002
```

## 验收清单

- 默认窗口：确认打开时为 `1440x920`，缩小不能低于 `1100x720`。
- 页面缩放：Windows 显示缩放为 100%、125%、150% 时检查文字、按钮和图表不重叠、不裁切。
- 导航：当前 V2 设计为顶部导航栏，不是左侧导航栏；确认工作台、生产中心、数据分析、资料中心和系统设置入口完整可点。
- 数据分析：在“收益”页确认筛选、趋势图、汇总卡片、贡献表可见；未接入子页显示“暂无真实数据”。
- 弹窗与抽屉：打开“采集收益”和自定义日期，确认遮罩层、定位、关闭按钮和内容滚动正常。
- 滚动：在数据分析页、采集抽屉和窄窗口下确认主页面与抽屉各自滚动，不发生背景穿透或内容截断。

桌面窗口实测仅验证 UI 容器和布局，不代表 V1 业务写入、剪映调用或导出链路已经验收。
