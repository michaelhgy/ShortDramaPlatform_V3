# V2 文件系统与资源生命周期规则

更新日期：2026-08-25。本文是 V2 后续生产能力迁移的产品合同；当前已实现 V2 工作目录和素材扫描、重命名的最小基础，其他生命周期操作仍须按本文逐项接入。

## 基本原则

- 默认工作目录为 `D:\短剧推广运营系统`。文件服务启动时自动建立五个一级目录；用户不需要维护大量路径。后续系统设置接入后，才能由用户更换工作目录。
- 产品流程和文件规则以 V2 为准；V1 的扫描、文件校验、任务、导出和清理保护能力按需迁入。
- 所有路径计算、文件创建、扫描、重命名、复制和删除只能由后端执行。V2 页面不拼接路径、不猜测文件状态、不模拟清理结果。
- 生产文件删除不等于删除系统数据。已发布任务的生产、发布、定位、收益和清理记录必须保留。

## 根目录

```text
短剧推广运营系统
├─ 生产文件
├─ 内容资产
├─ 生成资源
├─ 剧集资料
└─ 系统数据
```

开发时可通过 `V2_WORKSPACE_ROOT` 覆盖默认工作目录；`V2_SYSTEM_DATA_ROOT` 默认是工作目录下的 `系统数据`。两个变量仅用于指定 V2 新目录，绝不能指向 V1 的旧目录。

## 生产文件

每次生产任务按创建日期、账号、剧集归档。日期显示格式使用 `8月25日`，由 V2 文件服务在首次创建生产任务当天写入；不能使用 V1 的计划制作日期或计划发布日期。发布日期变化不移动既有目录。

```text
生产文件
└─ 8月25日
   └─ 账号
      └─ 剧集
         ├─ 素材
         ├─ 模板
         └─ 成片
```

- 素材：本次生产的原始短剧输入文件。
- 模板：本次生产的专属模板文件、模板视频和配对参数。
- 成片：本次生产导出的最终视频。
- 剪映草稿由剪映管理，不移动到上述目录；系统仅保存经任务记录证明的关联。

## 内容资产

内容资产只保存人工确认的长期爆款素材。

```text
内容资产
└─ 爆款素材
   └─ 剧集名称
      └─ 20260825_账号A_剧集名称_素材001.mp4
```

- 人工标记爆款时，后端将原素材复制一份到对应剧集目录；原素材仍按原生产任务的清理规则处理。
- 使用 MD5 判断是否为同一内容。资产池已存在相同 MD5 时不再复制物理文件，只建立关联。
- 爆款素材不自动清理，可被后续生产任务复用。

## 生成资源

```text
生成资源
├─ 真人视频
├─ 真人图片
└─ BGM
```

- 真人视频和真人图片由用户直接放入对应目录，保留原下载名称。
- 生成器按文件顺序领取，跳过文件名包含 `已使用` 的文件。
- 使用后在原目录改名为 `已使用-日期-账号昵称-剧集名称-R版本-序号`；同一模板重新生成时递增 R02、R03，保留每次领取记录，不覆盖之前的文件。
- 真人视频和真人图片是一次性生产资源，不建立长期资产记录；系统仅保存该任务的临时领取清单，以便安全清理。
- BGM 是长期复用资源，不改名、不自动清理；可记录使用次数和最近使用时间。

## 剧集资料

```text
剧集资料
└─ 剧集名称
   └─ 封面
      ├─ 主封面.jpg
      └─ 备用封面.jpg
```

- 剧集封面等资料属于剧集，不属于某次账号生产任务。
- 长期保留，不自动清理。
- 同名剧集由系统内部剧集编号区分，页面继续显示正常剧名。

## 系统数据

```text
系统数据
├─ 数据库
├─ 配置
├─ 任务运行
├─ 清理记录
├─ 日志
└─ 剪映关联
```

- 保存账号、剧集、生产任务、发布、收益、爆款关联、配置、运行和清理记录。
- 数据库业务记录长期保留；运行缓存和普通日志按独立规则清理。
- 不存放用户需要管理的原素材、成片、真人资源或 BGM。

## 登记发布与清理时间

“登记发布”界面必须记录：

- 实际发布时间；
- 省；
- 市；
- 区或县；
- 详细地址。

所有清理时间只按登记的实际发布时间计算，不使用任务创建时间、计划发布时间、下载时间、文件创建时间或文件修改时间。

系统设置提供以下可修改的默认值：

| 文件类别 | 默认保留期 |
| --- | --- |
| 生产过程文件：模板、成片、已使用真人视频、已使用真人图片、任务临时文件 | 24 小时 |
| 原素材 | 7 天 |
| 爆款素材、BGM、剧集封面 | 不自动清理 |

登记发布时应把当时设置计算出的实际清理时间写入任务文件记录。之后修改设置不改变已登记任务的清理时间。

## 生产中心危险操作

| 页面状态 | 页面按钮 | 后端行为 |
| --- | --- | --- |
| 未登记发布 | 删除剧集 | 删除当前生产任务的生产文件、临时资源、经证明归属的剪映草稿及该任务记录；不保留未发布任务历史。 |
| 已登记发布 | 立即清理 | 后端预览后清理可清理生产文件；保留生产任务、发布定位、收益关联、爆款资产与清理记录。 |

两种操作都必须遵循：后端生成真实预览 -> 用户确认 -> 后端执行 -> 返回真实结果。

无论哪种操作，都不得删除内容资产、BGM、剧集资料、其他生产任务或归属不明的剪映草稿。

普通原素材的提前删除是已确认的后续能力；具体入口待资料中心或系统设置 UI 确定后再实现。
