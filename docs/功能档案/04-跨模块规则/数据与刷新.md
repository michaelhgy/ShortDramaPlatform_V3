# 数据与刷新

> 界面上的数据从哪来、多久更新一次、读不到时怎么表现。
> **他会这么说**：「刷新」「数据不更新」「切页签又要重新加载」「转圈很久」「数据对不上」「收益是 0」
> 最后核对：2026-09-19 ｜ 状态：已整理

## 一、它做什么

所有页面共用**一个数据层**（`src/services/dataHub.ts`）向后端要数据；页面只订阅、自己不设计时器。
数据层按"数据种类"分成若干**区域**，每个区域有自己的节奏。

## 二、怎么用

- 你**不需要手动刷新**：数据按自己的节奏更新，右上角显示"更新于 xx:xx"（只在新数据到达时前进）。
- 切走页签再回来，**页面不会重建**（筛选、选中的剧都还在），也不需要重新加载。

## 三、业务规则

### 数据从哪来（固定数据流）

```
页面 → service（服务层）→ adapter（适配层）→ api（接口层）
     → V2 本地服务（127.0.0.1:8782）→ SQLite / 文件系统 / 剪映
```

页面**不得跳过任何一层**去直接访问本地服务或本机资源。

### 多久更新一次

| 数据 | 节奏 |
|---|---|
| 生产中心、任务中心 | **3 秒** |
| 资料中心的磁盘素材 | **30 秒** |
| 参数中心、设置、资料 | **打开时读一次 + 改完立刻刷**（不定时轮询） |
| 数据分析的收益 | 跟着筛选条件走；采集完成时刷新 |
| 微信指数 | **只在采集运行时** 1.5 秒轮询（属于"干活时的进度显示"） |

### 读不到数据时

保留最后一次有效数据 + 显示更新失败。**不把页面变空白，也不把真实数字改成 0。**

### 数据语义（不许自己猜数值）

- 不存在的字段**保持"未提供"**，不补造数值。
- 收益的「无记录 / 采集失败 / no_data / 不确定」与「**零收益**」**不是一回事**。
- 未知状态**保留原始值**，标为待核对，不显示成 0 或已完成。
- 同一接口已有请求在跑时，后续请求**复用前一个**；旧响应晚到**不得覆盖**新数据。

### 青柠收益明细

1. 明细的**唯一键 = 数据日期 + 账号 + 平台视频 ID**；同一天再次采集同一条视频是**更新**，不新增。
2. **不同日期保留为独立记录**，才能看同一视频在不同日期的变化。
3. 收益中心按你选的**日期范围**读明细，不把全部历史明细一次传给页面。
4. 平台返回的剧名对不上本系统剧集时，显示「**待匹配剧集**」，不猜、不强归。
5. 「**已匹配剧集**」只表示剧名匹配上了，**不等于**已关联到内部成片或素材。
6. 采集尝试日志与业务明细是**两类数据**：前者排错、后者分析；日志清理**不能**删掉收益明细或日收益汇总。
7. 「首次观测日期」= 本系统最早采到该视频的日期，**不是**平台返回的发布时间。
8. 推测命中生产任务后，**只列出候选原素材供人工预览**；人工确认后才建立正式关联，
   关联结果按账号 + 平台视频 ID 保存，并复用于该视频后续各日收益。

## 四、可调参数

没有用户可调的项：数据层的区域与节奏都写在代码里（见下）。

## 五、改动须知（动这个功能前先看这段）

1. **刷新调度统一在数据层**：页面要数据就注册一个"区域"，**不要自己在组件里写 `setInterval` 或自建缓存**。
2. **区域与节奏在同一处**：`src/services/dataHub.ts` 里的 `areaIntervals`（0 = 不自动刷，只在打开/改完后按需刷）。
3. **写完立刻刷**：用 `client.ts` 的 `publishV2DataChange`，配合 `refreshArea()`。
4. **页面通过 `useDataArea` 订阅**，不要绕过它直接调 api。
5. **改 DDL 必加 `SCHEMA_VERSION` +1**（见《界面与开发规范》）。

### 代码入口

| 干什么 | 文件 |
|---|---|
| 数据层核心（区域、节奏、去重、失败处理） | `src/services/dataHub.ts` |
| 页面订阅钩子 | `src/hooks/useDataArea.ts` |
| 唯一的 HTTP 入口（超时 / 错误处理） | `src/api/client.ts` |
| 各业务域接口 | `src/api/v2*.ts` |
| 适配层（后端结构 → 页面展示模型） | `src/adapters/*.ts` |
| 本地服务 | `server/v2_file_service.py`（127.0.0.1:8782） |

### 改完怎么验

1. **一定先跑**：`tools\一键验证.bat`（前端单测覆盖数据层：`src/services/dataHub.test.ts`）。
2. **改刷新相关必须实机看**：改一个参数或跑一次扫描，确认界面**几秒内自己变**、**不卡不闪**、
   右上角"更新于"只在新数据到达时前进。
