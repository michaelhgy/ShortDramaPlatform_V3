## 一、它做什么

数据盘 `D:\短剧推广运营系统` 下固定五个一级目录；**所有路径计算、创建、扫描、改名、复制、删除都由后端执行**，
页面不拼路径、不猜文件状态。文件服务的启动会自动建好这五个目录。

## 二、怎么用

- 你只需要往两个目录放东西：`生成资源\原始风景视频`、`生成资源\真人图片`（**保留原下载文件名**）。
- 其余目录由软件自己维护。

## 三、业务规则

### 五个目录

```text
短剧推广运营系统
├─ 生产文件     每次生产任务按 日期\账号\剧集 归档
├─ 内容资产     人工确认的长期爆款素材
├─ 生成资源     风景视频 / 真人图片 / 引流视频（旧真人视频、BGM 保留原位）
├─ 剧集资料     剧集封面等（属于剧集，不属于某次任务）
└─ 系统数据     数据库 / 配置 / 任务运行 / 清理记录 / 日志 / 剪映关联 / 剧照缓存
```

### 生产文件

```text
生产文件\8月25日\账号\剧集\{素材, 模板, 成片}
```

- 日期目录用 `8月25日` 这种格式，**在首次创建生产任务当天写入**，之后发布日期变化**不移动**已有目录。
- 任务彻底清完后**不留空壳**：系统会回收空的 `素材`／`模板`／`成片`，以及跟着空的 `账号`／`日期` 目录；
  下次建任务时整条链自动重建（判定与时机见《清理系统》）。
- FFmpeg过程文件和任务专属缓存由V3管理；历史外部草稿只保存经任务记录证明的关联。

### 人工删除单素材（2026-11-05源码）

- 素材管理及原素材预览提供删除确认，直接删除选中原文件、对应本地成片、对应专属合成缓存和合成/导出任务；不移入回收区或备份视频。
- 读取精确记录及历史归属后展示范围，确认后再次核验。排队任务可一起删除，执行中或共用文件、外部发布引用、归属异常时阻止删除。
- 保留其他素材、公共模板、共享缓存及成功使用计次。只保留小型编号标记和JSON删除结果，不把标记计为可用素材或可执行任务。
- 文件删除失败时停止并保留可重试记录，已删文件不恢复。该功能是人工逐条删除，不改变既有定时清理或整剧删除规则。

### 内容资产（爆款素材）

```text
内容资产\爆款素材\剧集名称\20260825_账号A_剧集名称_素材001.mp4
```

- 人工标记爆款时，后端把原素材**复制一份**到对应剧集目录；原素材仍按原生产任务的清理规则处理。
- 用 **MD5** 判断是否同一内容：池里已有相同 MD5 时**不重复存物理文件**，只建立关联。
- 爆款素材**不自动清理**，可被后续生产任务复用。

### V3 公共模板

- `内容资产\公共模板` 保存独立复用的成品模板，不属于某个账号或剧集的生产过程目录，不进入旧任务的 24 小时清理清单。
- 当前支持该目录第一层的成品 MP4；扫描只读源文件。模板改名后按内容身份保持使用记录，缺失或内容变化会标记不可用。
- `系统数据\database\v3_template_library.db` 保存模板索引、任务选择及成功成片记录。选择本身不计次，成功记录按成片 ID 去重。
- 模板预览可人工删除，排队或运行中的引用阻止删除；达到使用次数上限退出可选列表，保留历史。删除生产剧集不等于删除公共模板，也不退回成功成片已消耗的次数。
- `系统数据/tg` 中的模板复用缓存属于公共模板，随账号×剧集生产任务清理时保留。

### 生成资源

| 子目录 | 规则 |
|---|---|
| `原始风景视频` | 人工下载的待处理原片；不能直接用于模板；按新规则输出无声短片，整条原片全部结果入库并核对后删除对应原片 |
| `风景视频` | 处理后自动编号素材；仅实际排入成功模板时间轴的素材计次，同条循环/部分播放计1次，未播到不预留、不计次；用满且无预留时清理文件、保留计次。旧目录未入库文件作为待处理原片 |
| `真人图片` | 新真人叠层按成功模板计次，排队预留，用满且无占用后校验并删除，保留历史用量；历史任务的领取与清理仍按原记录处理 |
| 旧 `真人视频` / `BGM` | 文件、索引及缓存保留原位；V3 不扫描、展示或自动迁移到风景视频，BGM 界面入口撤下 |

2026-10-25源码版的真人叠层图片归属于公共模板制作：同模板生成多条成片不重复计次，失败/取消/中断释放名额，删除模板不返还图片次数。原图片使用上限可在参数中心修改，调低即时生效；删除失败或文件变化时保留并显示原因。图片已合入公共模板缓存，原图片用满删除不影响完成模板继续合成；不会把这些公共模板图片作为某个账号×剧集的24小时过程文件重复领取。具体见[全屏叠层事项](../../事项档案/2026-10-25-V3全屏贴纸与真人叠层.md)。
| `引流视频` | 中插 / 尾插共用，**由文件名区分用途**；不改名、不自动清理 |

### 剧集资料

- `剧集资料\<剧名>\封面\主封面.jpg`、`备用封面.jpg`：属于剧集、长期保留、不自动清理。
- 同名剧集由系统内部剧集编号区分，页面照常显示剧名。

### 系统数据

- 保存账号、剧集、生产任务、发布、收益、爆款关联、配置、运行与清理记录。
- 数据库业务记录**长期保留**；运行缓存与普通日志按各自规则清理。
- **不放**用户要管理的原素材、成片、真人资源或 BGM。
- `系统数据/fg/<成片任务编号前12位>` 保存该成片各次尝试的配方、日志及中间文件；属于生产任务过程文件，进入删除剧集、立即清理和到期过程清理清单。只按已登记的任务编号确定目录，保护公共模板缓存及其他任务。
- 剧照缓存放在这里（`系统数据\剧照缓存\<账号>__<剧集>\<素材指纹>\`）：它是**派生数据**，
  可从素材重算，因此不属于生产文件、也不放进用户手工维护的 `生成资源`；具体规则见《模板生成器》。

### 自动发布完成与清理时间

自动发布只有在小V猫任务全部成功、官方作品全部出现并已匹配本地生产记录后，才算发布完成。系统保存官方作品 ID 和实际发布时间；发布失败、结果不明或无法匹配时不进入清理周期，直接使用「删除剧集」。

**所有清理时间只按官方确认的实际发布时间算**——不用任务创建时间、计划发布时间、下载时间或文件时间。

| 文件类别 | 默认保留期 |
|---|---|
| 生产过程文件（FFmpeg模板、成片、已使用真人视频/图片、任务临时文件、缩略图缓存、任务专属缓存和已记录的历史导出残留） | **24 小时** |
| 原素材 | **7 天**（只保留素材登记信息，不保留原视频和缩略图） |
| 公共模板及复用缓存、爆款素材、BGM、剧集封面 | **不随生产任务自动清理** |

官方发布全部确认时把**当时设置算出的实际清理时间写进任务记录**；之后改设置**不改变已登记任务**的清理时间
（旧任务只有在缺这个字段时才允许一次性补齐）。

### 生产中心的两个危险操作

| 页面状态 | 按钮 | 后端行为 |
|---|---|---|
| 发布未完成、失败或无法匹配官方作品 | **删除剧集** | 删除该任务的生产文件、临时资源及该任务记录 |
| 官方发布已确认并匹配本地记录 | **立即清理** | 预览后清理可清理的FFmpeg生产文件；**保留**生产任务、官方作品关联、收益分析、爆款资产与清理记录 |

两者都必须走：**后端生成真实预览 → 用户确认 → 后端执行 → 返回真实结果**。
两类操作都**不得**删内容资产、BGM、剧集资料、其他生产任务或归属不明的外部文件。

任务删除或过程清理成功后，同时移除独立模板库中的 FFmpeg 队列与模板选用关系，任务监控的记录和计数同步更新；成功成片使用账继续保留。有等待或运行的 FFmpeg 成片时阻止人工清理、跳过定时清理；文件删除失败则保留记录供重试。历史残留的启动修复只清理数据库记录，不猜测删除历史文件。

### 三类清理共用同一份"任务专属文件清单"

- **删除剧集**：删该任务生产目录、已记录且归属明确的历史外部草稿、已使用真人资源、缩略图缓存、已记录的导出残留及任务记录。
- **立即清理 / 24 小时到期清理**：删同一批过程文件，**保留**原素材视频、素材名称与校验信息、发布记录、作品关联、收益分析、爆款关联、清理记录。
- **7 天原素材清理**：删原素材视频与其缩略图缓存，**保留**素材名称、MD5、时长等登记信息，并把素材标记为"原文件已清理"。
  **若过程清理仍有失败项，必须先重试过程清理，不得提前删原素材。**

## 五、改动须知（动这个功能前先看这段）

1. **五目录的名字与层级是合同**：改目录名或层级要同时改后端、扫描、清理与所有引用它的地方。
2. **"已使用"前缀是领取标记**：改名格式 `已使用-日期-账号昵称-剧集名称-R版本-序号`；生成器按此跳过已领取文件。
   同一模板重复生成时**递增 R 序号，不覆盖**。
3. **清理时间只能用实际发布时间算**：改这里时不要引入任务创建时间或文件时间。
4. **三类清理用的是同一份文件清单**：加一类要删的文件，三处一起加，否则会出现"删了一半"。
5. **过程清理没成功就不能删原素材**：这是顺序约束，不能并行。
6. **改 DDL 必加 `SCHEMA_VERSION` +1**（见《界面与开发规范》）。
