# 文件与资源生命周期

> 磁盘上五个目录各放什么、素材怎么改名、什么时候删。
> **他会这么说**：「数据盘」「目录」「素材放哪」「已使用」「保留期」「删了没」
> 最后核对：2026-09-19 ｜ 状态：已整理

## 一、它做什么

数据盘 `D:\短剧推广运营系统` 下固定五个一级目录；**所有路径计算、创建、扫描、改名、复制、删除都由后端执行**，
页面不拼路径、不猜文件状态。文件服务的启动会自动建好这五个目录。

## 二、怎么用

- 你只需要往两个目录放东西：`生成资源\真人视频`、`生成资源\真人图片`（**保留原下载文件名**）。
- 其余目录由软件自己维护。

## 三、业务规则

### 五个目录

```text
短剧推广运营系统
├─ 生产文件     每次生产任务按 日期\账号\剧集 归档
├─ 内容资产     人工确认的长期爆款素材
├─ 生成资源     真人视频 / 真人图片 / BGM / 引流视频
├─ 剧集资料     剧集封面等（属于剧集，不属于某次任务）
└─ 系统数据     数据库 / 配置 / 任务运行 / 清理记录 / 日志 / 剪映关联 / 剧照缓存
```

### 生产文件

```text
生产文件\8月25日\账号\剧集\{素材, 模板, 成片}
```

- 日期目录用 `8月25日` 这种格式，**在首次创建生产任务当天写入**，之后发布日期变化**不移动**已有目录。
- 任务彻底清完后**不留空壳**：系统会回收空的 `素材`／`模板`／`成片`，以及跟着空的 `账号`／`日期` 目录；
  下次建任务时整条链自动重建（判定与时机见《清理系统》）。
- 剪映草稿由剪映自己管理，不搬进这些目录；系统只保存"经任务记录证明的关联"。

### 内容资产（爆款素材）

```text
内容资产\爆款素材\剧集名称\20260825_账号A_剧集名称_素材001.mp4
```

- 人工标记爆款时，后端把原素材**复制一份**到对应剧集目录；原素材仍按原生产任务的清理规则处理。
- 用 **MD5** 判断是否同一内容：池里已有相同 MD5 时**不重复存物理文件**，只建立关联。
- 爆款素材**不自动清理**，可被后续生产任务复用。

### 生成资源

| 子目录 | 规则 |
|---|---|
| `真人视频` / `真人图片` | 生成器**按文件顺序**领取，**跳过文件名含"已使用"**的文件；用后在原目录改名为 `已使用-日期-账号昵称-剧集名称-R版本-序号`；同一模板重新生成时递增 R02、R03，**不覆盖**之前的文件。属于**一次性资源**，不留长期资产记录 |
| `BGM` | **长期复用**：不改名、不自动清理；可记使用次数与最近使用时间 |
| `引流视频` | 中插 / 尾插共用，**由文件名区分用途**；不改名、不自动清理 |

### 剧集资料

- `剧集资料\<剧名>\封面\主封面.jpg`、`备用封面.jpg`：属于剧集、长期保留、不自动清理。
- 同名剧集由系统内部剧集编号区分，页面照常显示剧名。

### 系统数据

- 保存账号、剧集、生产任务、发布、收益、爆款关联、配置、运行与清理记录。
- 数据库业务记录**长期保留**；运行缓存与普通日志按各自规则清理。
- **不放**用户要管理的原素材、成片、真人资源或 BGM。
- 剧照缓存放在这里（`系统数据\剧照缓存\<账号>__<剧集>\<素材指纹>\`）：它是**派生数据**，
  可从素材重算，因此不属于生产文件、也不放进用户手工维护的 `生成资源`；具体规则见《模板生成器》。

### 登记发布与清理时间

「登记发布」必须记录：**实际发布时间 + 省 + 市 + 区/县 + 详细地址**。

**所有清理时间只按登记的实际发布时间算**——不用任务创建时间、计划发布时间、下载时间或文件时间。

| 文件类别 | 默认保留期 |
|---|---|
| 生产过程文件（模板、成片、已使用真人视频/图片、任务临时文件、缩略图缓存、任务专属剪映草稿、已记录的剪映默认导出残留） | **24 小时** |
| 原素材 | **7 天**（只保留素材登记信息，不保留原视频和缩略图） |
| 爆款素材、BGM、剧集封面 | **不自动清理** |

登记发布时把**当时设置算出的实际清理时间写进任务记录**；之后改设置**不改变已登记任务**的清理时间
（旧任务只有在缺这个字段时才允许一次性补齐）。

### 生产中心的两个危险操作

| 页面状态 | 按钮 | 后端行为 |
|---|---|---|
| 未登记发布 | **删除剧集** | 删除该任务的生产文件、临时资源、经证明归属的剪映草稿及该任务记录 |
| 已登记发布 | **立即清理** | 预览后清理可清理的生产文件；**保留**生产任务、发布定位、收益关联、爆款资产与清理记录 |

两者都必须走：**后端生成真实预览 → 用户确认 → 后端执行 → 返回真实结果**。
两类操作都**不得**删内容资产、BGM、剧集资料、其他生产任务或归属不明的剪映草稿。

### 三类清理共用同一份"任务专属文件清单"

- **删除剧集**：删该任务生产目录、已证明归属的外部剪映草稿、已使用真人资源、缩略图缓存、已记录的导出残留及任务记录。
- **立即清理 / 24 小时到期清理**：删同一批过程文件，**保留**原素材视频、素材名称与校验信息、发布登记、收益、爆款关联、清理记录。
- **7 天原素材清理**：删原素材视频与其缩略图缓存，**保留**素材名称、MD5、时长等登记信息，并把素材标记为"原文件已清理"。
  **若过程清理仍有失败项，必须先重试过程清理，不得提前删原素材。**

## 四、可调参数

| 参数 | 在哪调 | 默认 |
|---|---|---|
| 工作目录（数据盘） | 设置页 | `D:\短剧推广运营系统` |
| 生产过程文件保留 | 设置页 →「文件清理周期设置」 | 24 小时 |
| 原素材保留 | 同上 | 7 天 |

## 五、改动须知（动这个功能前先看这段）

1. **五目录的名字与层级是合同**：改目录名或层级要同时改后端、扫描、清理与所有引用它的地方。
2. **"已使用"前缀是领取标记**：改名格式 `已使用-日期-账号昵称-剧集名称-R版本-序号`；生成器按此跳过已领取文件。
   同一模板重复生成时**递增 R 序号，不覆盖**。
3. **清理时间只能用实际发布时间算**：改这里时不要引入任务创建时间或文件时间。
4. **三类清理用的是同一份文件清单**：加一类要删的文件，三处一起加，否则会出现"删了一半"。
5. **过程清理没成功就不能删原素材**：这是顺序约束，不能并行。
6. **改 DDL 必加 `SCHEMA_VERSION` +1**（见《界面与开发规范》）。
