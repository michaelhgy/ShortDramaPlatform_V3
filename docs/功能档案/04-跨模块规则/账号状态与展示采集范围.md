# 账号状态与展示采集范围

生效于2026-11-06本次源码修改。依据用户确认的各界面账号显示表；替代2026-11-01“注销账号从业务统计和任务列表整体隐藏”的旧规则。安装版需另行发布，不表示已完成正式运行验收。

## 账号状态含义

沿用正常、观察、限流、二限、实名、封禁、停用、注销八种状态，不新增账号状态或迁移数据库。停用表示暂时不使用，可恢复；注销通常在次月收益结算后进行，但本次不新增结算登记、结算判断或自动注销。

所有状态保留已有账号、流量、收益、作品、发布和任务历史。状态切换不删除媒体或记录，不修改已保存金额，不自动中断已开始的渲染/导出。

## 界面默认范围

| 界面 | 默认账号范围 | 历史查看方式 |
| --- | --- | --- |
| 经营总览 | 全部状态 | 可切换未停用未注销、停用、注销；金额、走势、排行、明细同步筛选 |
| 账号矩阵 | 正常、观察、限流、二限、实名、封禁 | 可切换停用、注销、全部状态 |
| 作品表现、账号优化 | 正常、观察、限流、二限、实名、封禁 | 可切换停用、注销、全部状态；作品数量、标签数量和分页同步 |
| 数据导出 | 全部状态 | 同样可选择账号状态范围，导出使用当前范围 |
| 资料中心账号管理 | 全部状态 | 保留既有账号状态筛选与编辑 |
| 新安排的账号选择 | 正常 | 停用、注销及其他非正常状态不参与新安排 |
| 历史生产、发布和任务 | 全部状态 | 原记录继续可查，不再按注销隐藏；本次未新增折叠设置 |

“未停用、未注销”包含实名和封禁等异常状态，不等同于可以发布。各页面分别记住本次挂载期间的状态范围，切换矩阵不会改变经营总览。历史剧场可在筛选中选择，剧场停用不抹除关联历史。

## 历史收益

按收益所属期间查询，账号当前停用或注销不删除其历史贡献。已结算且有有效金额的历史期间仍参与对应日期分析，即使原 `include_in_analysis=0` 是因已结算退出当前未结算流水；不是把结算日当收入日。

查询完整月份时，同账号月累计与其覆盖的日收益只计一次；仅查询一天时使用该天日收益，不把整月金额拆分到某一天。原始金额、结算标记、查询记录均不改写，失败、缺失和明确零继续区分。

## 采集范围

- 剧场收益：默认范围包含正常至封禁及停用账号；注销不采集。仍须有有效采集器配置，账号平台登录不决定收益采集资格。
- 账号日数据、账号总量、作品流量、作品分析：推荐范围排除停用和注销；停用可通过状态筛选后手动勾选。混合采集推荐选入的停用账号默认只采收益，账号行可勾选“本次也采集平台数据”。
- 统一请求的 `account_ids` 是全部本次账号；可选 `platform_account_ids` 只限制平台类别，必须是前者的子集。后端保存范围，重试沿用，不因混合勾选而扩大平台请求。
- 注销档案可在采集面板状态范围中查看，显示不可采集及原因，直接提交也拒绝。历史采集记录继续可查。
- 自动优化检测排除停用、注销、登录失效；手动平台采集保留本地登录重新核对，核对失败跳过，不以零覆盖已存结果。执行前复核账号注销状态，停止后续平台请求。
- 打开页面、切换范围、小刷新只读已保存数据，不触发平台采集。
