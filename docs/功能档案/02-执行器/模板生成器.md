# 模板生成器

> 把素材拼成一个剪映 5.9 能打开的**模板草稿**（背景铺底：真人窗口 + 照片墙 + 贴纸 + 文案）。
> **他会这么说**：「模板」「模板草稿」「照片墙」「剧照」「贴纸」「花字」「祝福语」「引导语」「文案」「180 秒」
> 最后核对：2026-09-19 ｜ 状态：已整理

## 一、它做什么

- **入料**：1 条竖屏真人视频 + 10 张 3:4 剧照 + 贴纸库 + 花字库。
- **产出**：一个剪映草稿目录（核心文件 `draft_content.json`）。
- **之后**：交给《成片生成器》做出成片，再由《视频导出器》导出。
- **它只写草稿文件，不启动剪映。**

## 二、怎么用

1. **生产中心 → 账号×剧集卡片 → 生成模板草稿**（进度在任务中心看）。
2. **文案要改**：参数中心 →「文案」卡（祝福语池、引导语池）。

## 三、业务规则

### 模板里有什么

| 轨道 | 里面是什么 | 必须有吗 |
|---|---|---|
| `T01_OUTER_VIDEO` | 中央真人视频窗口（矩形蒙版，羽化固定 1） | 必须 |
| `T02_BOTTOM_PHOTO_WALL` | 底部照片墙：10 张剧照左右滚动 | 必须 |
| `T03_TOP_PHOTO_WALL` | 顶部照片墙（同上） | 必须 |
| `T09_STICKER_SKIN_01` ~ `_16` | 16 条贴纸，**全部来自同一个皮肤** | 必须 |
| `T10_TEXT_BLESSING` | 祝福语（花字） | **看文案池** |
| `T11_TEXT_DRAMA_PROMPT` | 引导语（花字） | **看文案池** |

- 模板时长固定 **180 秒**。
- 真人视频**只有 1 条**：中央窗口 T01。
- 照片墙（T02/T03）是**宽幅、剧照滚动**；用户口语里的"轨道 2、3 真人视频"指的是另一类**窄条镜面视频带**（已不用，见归档件）。

### 文案池（在参数中心调）

- 生成时从池里**随机挑一句**（保留"每次不同"的感觉）。
- 池里**没设置过** → 用内置默认池（各 10 条）。
- 把池**清空** → **不生成那条文案轨道**。
- 字数**不限**：超出原来的 6–9 字档位时，按**最接近的字数档位**取字号。

### 照片墙：恰好 10 张，而且必须凑满

模板端有三道硬校验：**恰好 10 个文件**、路径不重复、**内容（SHA256）不重复**。
所以选图**只降级、不报错**：**宁可 10 张里有几张质量差，也不能少于 10 张**。

| 档位 | 门槛 |
|---|---|
| `strict`（最好） | 正面分 ≥0.75、脸宽 ≥90px、睁眼、不喊叫、同一位演员 ≤2 张、同一集 ≤3 张 |
| `relaxed_frontal` | 正面分 ≥0.55 |
| `relaxed_size` | 脸宽 ≥60px |
| `relaxed_all` | 只要有人脸、画面各不相同 |
| `duplicates` | 允许同一位演员反复出现，画面仍要不重复 |
| `variants`（最差） | 画面都不够时，对同一画面做**极轻微二次裁切**凑出不同文件 |

用了哪一档会记进 `剧照准备清单.json` 的 `selection_stage`，任务日志里也会写明。

其它选图规则：**以人脸为中心**裁切；输出统一缩到 720px 宽以内的**精确 3:4**。

### 选图的判断依据

- 画面去重只做**画面级**：**画面不重复**是硬要求；同一位演员最多出现 2 张。
- 正面判断看的是**头部朝向 + 眼睑开合**。
- **只检测人脸**；没有可用人脸的画面按**中心裁切**。
- 人脸模型读不到时：按中心裁切 + 用原有的质量打分，并在剧照清单里记一笔。

### 剧照缓存（按"账号 + 剧集"复用）

- **单位 = 账号 + 剧集**：账号 A + 剧集 A，与账号 B + 剧集 A，是**两个不同的模板**，剧照不共用。
- 放在 `<系统数据>/剧照缓存/<账号__剧集>/<素材指纹>/`。
- **指纹** = 全部素材的「路径 + 大小 + 修改时间」：素材一变，指纹就变，**自动重做**。
- 每个单位只留最近 **3** 份。

## 四、可调参数

| 参数 | 在哪调 | 默认 | 说明 |
|---|---|---|---|
| 祝福语池 / 引导语池 | 参数中心 →「文案」 | 内置默认池各 10 条 | 清空 = 不要那条文案轨道 |

写死在代码里的：模板时长 180 秒；照片墙 10 张；采样密度 **24 窗 × 6 帧**；正面分 0.75、脸宽 90px 门槛；缓存保留 3 份；贴纸 16 条。

## 五、改动须知（动这个功能前先看这段）

1. **照片墙永远凑满 10 张**：模板端三道硬校验（数量 / 路径 / SHA256），少一张或重复一张都会直接报错。
   **加任何筛选条件时，必须同时给它一条降级出路。**
2. **改采样密度或门槛前，先跑探针脚本**（`tools\probe_candidate_density.py`、`tools\probe_photo_wall_thresholds.py`）——
   这两个值是实测扫出来的；直接收紧会把可用帧降到凑不满。
3. **比例一律整数推导**（`height = width * 4 // 3`），不要用四舍五入的浮点。
4. **缓存命中先校验尺寸**，否则一个坏缓存会让任务永远以同一个文件名失败。
5. **诊断脚本调用真实流程的函数**，不要自己复刻取数逻辑；造样本时"必须互不相同"的字段（画面指纹、身份向量）要**真的不同**。
6. **改 DDL 必加 `SCHEMA_VERSION` +1**（见《界面与开发规范》）。

### 改完怎么验

1. **一定先跑**：`tools\一键验证.bat`（文案：`server/tests/test_v2_template_copy.py`；选人与 3:4：`test_v2_photo_wall_faces.py`）。
2. **改选图或门槛后必须实跑**：`py -3.12 tools\verify_photo_prep_real.py`，逐张核对尺寸 / 比例 / 正面分 / 脸宽 / 闭眼度 / 演员序号。
3. **改轨道结构后必须实跑一次 `final` 生成**，再打开 `draft_content.json` **核对轨道名**（单测测不出轨道结构）。
4. 环境要求：`pyJianYingDraft`、`PIL`、`ffmpeg`；花字写入还需要剪映字体目录存在 `zh-hans.ttf`。
