# V3 FFmpeg 模板制作

2026-10-19制作记录规则：任务快照过滤“已完成但视频文件缺失”以及“已人工删除”的模板，完成数量同步扣除，数据库中的任务、配方和素材用量保留。运行、等待、失败、取消记录保持可见；视频仍存在但用量已满的模板保留制作历史，标记“使用次数已满”，不提供预览。记录使用模板短名称，排队和运行优先，采用与任务中心相同的队列组件。


2026-10-19：V3已接入参数保存、公共模板批量制作、后台队列、预览与自动入库；后续同日已接入[FFmpeg成片合成](FFmpeg成片合成.md)及公共模板生命周期。V2源码只读，当前入口为V3源码开发版。

## 操作入口

- 参数中心 → **模板生成参数**：读取和保存一整套模板规则，每项附用途、建议区间和基本规则。祝福语、引导语文案卡已移除；插片保留原兼容入口。
- 生产中心 → 公共模板区域 **制作模板**：打开完整模板制作弹窗，含生成数量、参数入口、本批与历史队列、结果预览。顶部制作方式切换已移除。模板仍不绑定账号、剧集，无生产任务时空态也有制作入口。弹窗关闭保留当前任务；ESC先关内部生成/预览窗口，再关外层。关闭后已提交后台任务继续按原队列运行。
- 生产中心当前任务：模板区域提供“制作模板”弹窗入口；成功入库后区域自动读取新模板，保留既有预览、选用、取消、同剧跨账号限制及成功成片计次口径。
- 现有任务中心：显示同一份 FFmpeg 模板队列，可暂停后续任务、继续、重试失败项或取消等待项。顶栏执行/等待/完成/异常数字包含新任务。
- 暂停采用“当前模板完成后停止取下一份”；不把中止 FFmpeg 进程当作可无损继续的暂停。旧剪映任务继续保留原管理方式。

## 参数与默认值

分辨率固定1080×2400、30fps，界面直接显示支持规格。此轮不提供尚未验证的任意画幅选项。

| 配置 | 初始值 | 行为 |
|---|---|---|
| 模板时长 / 正负误差 | 600秒 / 30秒 | 每模板随机，减去误差后至少1秒；10—1800秒为建议，不限制自定义更长时长 |
| 每个模板使用上限 | 20部剧 | 同剧多条成片计一次；首次成功计次、排队预留剧集名额。用满后其他剧不可选，同剧补做可继续 |
| 上下合计风景候选条数 / 正负误差 | 6 / 0 | 先抽取并分组，每轨至少2个候选，上下不共用；播放到模板时长停止，不保证全部出现 |
| 每条风景使用上限 | 5 | 只给实际排入时间轴的风景预留；成功后同条计1次，循环及部分播放不加计，未播到不占次数 |
| 两组初始时长差 | 15%—70% | 差值相对于较长组；无法满足时提示调整或补料 |
| 大 / 小区域高度 | 28%—33% / 20%—25% | 各抽一个，随机分给上下 |
| 蒙版位置 / 羽化总宽 | 本区域40%—55% / 55%—80% | 上下独立抽取，整数像素；尺寸和羽化宽取偶数 |
| 贴纸整体系数 | 80% | 31系列670单素材；新模板重新抽16个，上下各8个，保留已确认动画 |
| 特效类型数 | 3—5 | 短片会按实际段数减少 |
| 单段特效时长 | 30—60秒 | 精确覆盖模板总帧数 |
| 特效强度 | 基准90%—100% | 对完整效果结果调节，包含背景处理 |
| 双特效时长占比 | 15%—30% | 120秒以上按规则安排，优先预合成双特效；短片不强制 |
| 切换过渡 | 1—2秒 | 兼容效果交叉淡变，否则经未加特效的底片过渡 |
| 左右边条 | 各5—10像素 | 抽1个整块素材，左右独立取景；位置固定、原速、随机相位 |

表中为默认值和建议范围，可以输入区间外的合理值，前端与后端均不以建议范围拒绝或夹回数值。保留整数、正数、百分比、上下限顺序、实际时长至少1秒、上下各2条风景轮换等生成所必需的规则。羽化0表示硬边；特效过渡可以超过1—2秒，实际长度自动收短到相邻两段中较短的一段；边条可设1—1080像素，5—10为建议。25项参数用途、调整影响和全部基本规则见[参数中心逐项说明](../01-界面/参数中心.md)。

画面配置用于新建批次，批次保存参数副本，每份保存独立随机配方，失败重试不重新抽素材。风景、真人图片和模板使用上限保存后立即生效；减少素材使用上限可能清理已用满文件，已有排队预留受保护。

## 后台处理

1. 只读取[风景处理](风景素材处理.md)成功入库的可用素材，校验文件并按内容去重。原始风景及旧目录中未入库文件不参加新模板抽取，原有排队任务按保存的配方执行。
2. 批次创建先按候选条数校验可用库存，保存完整候选分组与时间轴；只对时间轴中帧数大于0的风景预留使用额度。同条跨片段、循环按身份去重，未播到的候选不预留，因此可以作为其他模板候选。库存不足时整批不提交；同一请求编号重复提交只返回原批次。
3. 每轨固定组员，后续每组重新排列；组间也禁止相同素材相接。两轨各自覆盖总时长，最后超出部分截断。风景片段统一为30fps、有限色彩范围及精确到帧的MP4时间刻度，同一素材的相同长度只处理一次；末尾不足整段的部分单独处理。按原随机顺序直接复制视频流拼接，不再次编码整条风景轨道。上下时间轴立即核对尺寸、帧率、精确帧数和完整解码，任何一条不足模板时长都停止，不能进入特效预合成。
4. 准备上下风景、当前模板贴纸动画和窄边条后，按完整特效时间表预合成固定效果，保存压缩画面和透过比例缓存。成片直接循环和截断，新模板不再额外制作按成片结尾调整的备用画面。用同一份完成缓存叠加灰色示意背景生成预览，预览无主素材原声。普通/滤色缓存保留4:4:4目标8 Mbps，通过实际GPU编码、解码及合成能力检查时使用HEVC，否则使用H.264；素材相关滤镜缓存保持原格式。预览与成片仍为H.264目标2500 kbps，依据用户旧成片实测校准。
5. 检查1080×2400、30fps、精确帧数及完整解码；成功后发布预览，更新公共模板索引，再提交实际播放风景的使用次数。结算从保存的时间轴取身份，忽略旧任务的多余候选预留；实际播放素材缺少预留时保留已发布结果并报错，重试幂等结算，避免漏计。
6. 失败保留原配方、日志和中间文件，释放用量预留；重试仅重新检查实际播放风景的额度及源文件，未播到候选的文件变化、缺失或被其他任务用满不会阻止本模板；复用同一配方已完成且校验一致的贴纸缓存。软件退出时运行中的任务标为中断，可手动重试；等待任务在正常重启后继续。

风景处理、模板效果预合成及成片合成的FFmpeg命令按实际输出帧监控：连续120秒没有新增输出帧（包括尚未生成第一帧、反复发送相同帧的心跳）时，只停止该命令的子进程，报告卡住的位置并保留现场。不会主动重启软件、恢复暂停队列或重试失败任务。独立的贴纸素材库准备流程仍沿用其原有执行器，不将这次保护描述为覆盖所有外部工具。

### 实际播放计次兼容规则（2026-10-25源码修复）

候选抽取数量、初始分组时长差、随机配方、播放顺序、末尾截断和最终画面保持既有规则。只调整预留、文件依赖检查、重试和成功记账的素材集合。60秒模板、20条候选，如果实际上下合计只播放6条，则只预留和计次这6条；其余14条不占本模板次数。同条只播到一部分也计1次。

源码启动时自动释放旧等待任务多预留的未播到候选，不重抽配方。历史已成功用量保留，不追溯退款或恢复已经删除的文件。此次修复已纳入2026.10.25.2更新构建，2026.10.25.1安装包不包含，见[修复记录](../../事项档案/2026-10-25-V3风景按实际上屏计次修复.md)。

### 效果预合成的计算复用

2026-10-19优化：同一效果段计算固定画面和透过比例时，相同输入参数的素材只解码一次；完全相同的裁切、缩放、透明度准备结果通过分流共享。不同起点、循环方式和效果动画保持独立，带切换指令的滤镜不合并。被截成部分区间的过渡（例如周期末尾的半段切换）保留原整幅处理和独立输入顺序，保持原有渐变指令的执行路径。每段保存`*.sharing.json`记录实际减少的输入和准备步骤。

上下风景和贴纸先在各自实际占用区域按原顺序合成，再拼回完整画幅；中部未占用区域不重复执行透明混合。区域发生重叠的特殊旧配方继续使用原来的整幅处理。贴纸从保存的动画起点就近读取，有限尾段与从头循环分成两个输入，避免快进与无限循环组合造成末尾错帧。

该轮保持缓存格式、画幅、帧率、码率、混合顺序、羽化、贴纸透明度、特效切换及边条规则，只优化模板首次制作；耗时与画面对照见[效果预合成优化记录](../../事项档案/2026-10-19-V3模板效果预合成优化.md)。

2026-10-20源码增加GPU合成及HEVC 4:4:4缓存选择，新缓存版本为`rgb-transfer-hwdecode-v3`；继续读取旧`rgb-transfer-h264-8m-v2`完整缓存。旧模板不重写、不自动迁移。只有设备真实通过GPU合成与HEVC解码检查才新建HEVC普通/滤色缓存，原H.264输出规格与素材相关滤镜保留。详见[成片GPU合成规则](FFmpeg成片合成.md)及[本轮事项](../../事项档案/2026-10-20-V3成片GPU合成优化.md)。用户确认修正显示比例后的样片后，本次改动纳入2026.10.20.1更新包，见[更新发布记录](../../事项档案/2026-10-20-V3成片优化更新发布.md)。

处理后的风景达到次数上限后停止抽取；无排队/运行预留且所属原片处理事务已完成时自动删除该处理文件，保留素材身份和成功使用账。模板完成、取消等待、参数保存及风景刷新会尝试清理；被占用或文件变化时保留并显示错误。原始下载文件不进入用满清理。模板内部风景组重复不额外计次，取消或失败不计成功次数。

## 输出与后续成片接口

### 全屏贴纸与真人图片叠层（2026-10-25源码版）

参数中心新增两个独立开关，默认关闭；各自配置每模板数量下限/上限及可见程度（数值越小越淡，默认2%）。全屏贴纸从独立383个素材库抽取，默认24—48个，1—64仅为建议数量，与原上下16个装饰贴纸不共用素材。真人图片从现有真人图片目录抽取，默认6—6张，1—30仅为建议数量；6张按2列3行铺满，保持比例裁切，不拉伸。数量可以超出建议，实际建批次时需要库存和剩余名额充足。两层为静态排布，制作模板时合入效果缓存，成片直接复用。素材库在同日由71个扩充至383个，已有素材保留，见[扩充记录](../../事项档案/2026-10-25-V3叠层贴纸库扩充.md)。

真人图片另设每张使用上限，默认5个成功模板。排队先预留，成功入库后各计1次，失败/取消/中断释放名额；同模板合成多条成片不重复计次。用满且无任务占用后，校验身份并自动删除图片文件，历史用量保留，已生成模板继续可用。删除失败或文件变化保留并显示原因，后续刷新/结算重试；降低上限即时生效，可能清理已用满图片。删除模板和重新导入同内容图片不重置使用账。排布配置用于新建批次，旧模板不自动重做。

源码和实际媒体验证、独立素材来源及入口见[全屏叠层事项](../../事项档案/2026-10-25-V3全屏贴纸与真人叠层.md)。上述功能已纳入[2026.10.25.1发布构建](../../事项档案/2026-10-25-V3模板叠层与参数更新发布.md)，用户观感待实际生成模板确认。

每份模板对用户显示为一个视频卡片，实际由下列内容组成：

- `内容资产/公共模板/模板_日期_编号.mp4`：中间灰色示意区的效果预览，供现有卡片播放。
- 同名 `.template.json`：模板任务身份、预览指纹、完整模板包位置。
- `系统数据/tg/<模板短编号>/a<尝试次数>/`：模板配方、上下风景时间轴与灰度蒙版、透明贴纸缓存、窄条缓存、特效配方、过程日志和检查。
- 效果与原生素材库位于 V3 的 `tools/ffmpeg_overlay_lab/`；不在运行时读取 V2。

普通 MP4 承担预览，模板包的 `precomposed/<配方指纹>/manifest.json` 索引实际可复用效果。普通透明/滤色预合成完整画面，素材相关滤镜另存准备好的像素输入及必要混合规则。模板只准备自身时长的一个完整周期；成片较长时直接重复这一段，贴纸、特效和边条也一起循环，最后截断，不追加效果帧。预览采用与成片相同的完整周期读取方式。缺少配套文件的普通视频可预览，但不能走这条合成链路。详细缓存、时长和进度规则见[FFmpeg成片合成](FFmpeg成片合成.md)。

新生成文件名改为“模板MMDD-序号.mp4”（例如“模板1019-001.mp4”），遇到已有同名文件或已分配名称会顺延；旧生成文件只缩短卡片显示名，磁盘文件不批量改名。所有卡片标题单行省略，悬停显示原文件名。

刷新后不展示缺失或变化的旧记录，历史计次保留。预览中的人工删除把视频及同名配方移至`系统数据/template_trash`，保留分层缓存、成片与计次；排队/执行中的成片正在引用该模板时禁止删除。达到成片使用上限只隐藏卡片，调高上限后仍在的模板可以重新出现。

## 正式代码与验证

- `server/ffmpeg_templates/config.py`：默认值与范围验证。
- `server/ffmpeg_templates/service.py`：独立持久化任务、用量预留、重试、串行制作和发布。
- `server/ffmpeg_templates/renderer.py`：真实媒体处理、特效切换、缓存和完整解码。
- `server/ffmpeg_templates/http.py`：V3模板生成接口。
- `src/components/templates/`：参数卡、制作页面、共享任务进度。
- `server/tests/test_ffmpeg_templates.py`：参数、额度、去重提交、固定配方重试、暂停取消、输入变化与时间轴测试。

自动检查、真实运行及用户观感分开记录，初次接入见[模板生成事项](../../事项档案/2026-10-19-V3FFmpeg模板生成接入.md)，当前发布验证见[2026.10.20.1更新记录](../../事项档案/2026-10-20-V3成片优化更新发布.md)。打包程序已在本机独立工作目录实际完成模板制作、GPU及CPU兼容成片；另一台机器的实际性能与批量生产仍待验证。
