# V3 FFmpeg成片合成

2026-10-19：用户授权将生产中心“批量合成”接入新素材与模板合成，替换界面中的剪映草稿和导出操作。当前为源码开发版基础合成链路。

## 用户入口

1. 生产中心选择账号×剧集，扫描素材，在模板区域选用新生成的分层模板。
2. 点击“批量合成”，对当前任务未提交、未完成的有效素材一次提交。一条素材对应一条成片，已完成或已排队项跳过。
3. 现有任务中心新增“成片合成 · FFmpeg”，显示阶段、进度、耗时及错误，支持暂停后续、继续、取消等待项、按原配方重试失败/取消项。
4. 完成后原成片区域显示视频，可播放和打开目录；任务合计及单条耗时统一为“生成耗时”，不含排队时间。原有已完成成片继续显示，历史记录中的草稿与导出执行时间合计为生成耗时。

## 卡片优先级与自动合成

生产中心的卡片顺序是新成片执行顺序的统一来源。未登记任务按手动位次优先，其后按计划日期、开工时间、任务编号稳定排序；登记任务沉底。手动位次使用原业务表`production_tasks.manual_order`保存，长按拖动接口按目标卡片前/后移动并一次保存未登记任务位次。等待队列与每次领取均读取同一规则，同一部剧内部继续按原提交顺序；已在运行的一条不被排序打断。

“自动合成”开关保存到本机软件数据目录的library_settings.final_automatic。首次无记录默认关闭，之后恢复上次开启或关闭状态；正常启动沿用既有队列启动路径。开启后由后端循环检查已经选模板并有有效素材的未结束任务，按卡片顺序提交尚未提交的素材；未选模板或无素材时等待后续就绪，不替用户选模板或扫描素材。沿用既有模板归属/名额、文件指纹、工作区边界、幂等跳过及防覆盖检查；失败/取消项不自动重试，其他可执行任务可以继续。

自动提交在配方中标记`automatic`，不增加数据库结构版本。关闭时不打断当前成片，等待自动项保留并提示“等待开启自动合成”，暂停执行；手动项不受开关影响。人工点击某任务“批量合成”可将其已有等待自动项接管为手动执行，人工重试也按手动处理。重启后旧等待自动项按记住的开关状态处理：关闭继续等待，开启按卡片顺序继续领取；中断/失败项仍须人工重试。原任务中心暂停仍有优先权，不因开启自动而绕过。

接口：`POST /api/v3/final-composition/automatic`设置开关，`POST /api/v3/final-composition/order`保存源卡片相对目标的位置；原快照补充`auto_enabled/auto_error`及自动等待标记。花字、发布草稿、封面选择不参与此调度。

实现入口为`server/production_order.py`、`server/ffmpeg_finals/service.py`和`src/components/production/useLongPressReorder.ts`。本轮隔离调度及界面验证见[卡片排序与自动合成事项](../../事项档案/2026-10-26-V3卡片排序与自动合成.md)，视频画面和编码仍沿用下面的既有合成规则。

## 合成内容

- 原素材按比例放大至覆盖1080×2400，再居中裁取，30fps；保留原时间范围及速度，最多因帧率对齐补足不足一帧。
- 读取所选模板的上下风景时间轴和羽化蒙版、透明贴纸动画缓存、特效顺序与强度、动态边条缓存。不会重新抽取贴纸或风景。
- 模板较短时直接重复读取已完成的原始模板周期，按成片总帧数截断；风景、贴纸、特效和边条随整段模板一起循环。主素材和原声保持连续，不参与循环。特效过渡使用模板制作时保存的画面，成片不重算衔接。
- 保留素材第一路原声音轨，编码AAC；插片期间播放插片第一路声音，无声段补静音，所有片段均无声时输出无声视频。视频完成后校验分辨率、帧率、帧数、音轨存在性与时长，并执行完整解码。
- 当前范围是原画原声、已确认模板层及中插/尾插合成。参数中心插片卡已接入本流程；片头片尾识别、BGM、账号移动字和固定文字仍未迁入。

## 模板预合成、复用与进度

- 新模板生成时，提前计算固定风景、羽化、贴纸动画、特效时间轴和边条，保存压缩的预合成缓存；预览也通过这份缓存生成。普通 MP4 继续供模板卡片播放，实际效果数据在模板包中。
- 普通透明和滤色效果合并成“画面贡献＋RGB 透过比例”。滤色的透过比例按三个颜色通道分别保存，避免用单一透明度造成颜色变化。每条成片只读取这些完成的画面，与主素材做必要的像素组合并编码一次。
- 加法限幅、柔光、叠加、雪花变色和泡泡颜色 LUT 必须结合主素材颜色运算。它们的固定底层、动画取样、缩放和遮罩画面提前准备；成片只保留必要的原混合/颜色运算，不重新摆贴纸、计算羽化、缩放原始特效素材。非线性特效不会被强行作为普通透明层处理。
- 模板制作准备一个完整周期；成片只读检查这一个周期并循环文件引用，不扩展缓存，也不为整批最长素材提前准备更多效果帧。旧队列配方中的 `template_prepare_frames` 字段忽略，新提交不再保存它。
- 已经被旧版本扩展的缓存仍可用，只选其原始第一个完整周期，后面的扩展文件保留但不继续追加。缺失或不完整的预合成缓存明确提示重新制作模板，成片阶段不会自动修补或制作模板。
- 普通/滤色整条成片用一个 FFmpeg 编码过程完成。包含素材相关滤镜时分段编码，每帧仍只编码一次，段间直接复制视频流拼接。1080×2400、30fps及素材原声保留。
- 成片末尾直接截断模板画面，不随素材长度调整模板已保存的特效过渡。模板预览也使用同一完整周期，与实际循环内容一致。
- 2026-10-19读取用户9月23日旧成片后修正编码标准：旧成片视频实际约2300 kbps、总码率约2500 kbps。成片和模板预览默认H.264、视频目标2500 kbps、峰值4000 kbps、AAC 192 kbps；不再默认cq19不限制大小。普通/滤色预合成缓存保留4:4:4，目标8 Mbps、峰值12 Mbps，颜色和透过信息并排保存。2026-10-20起，实际通过HEVC编码、Vulkan解码及合成能力检查的设备，新缓存使用HEVC；其他设备继续H.264。素材相关特效缓存保持原格式。缓存版本隔离，旧完成缓存保留并直接复用。
- 成片进度读取 FFmpeg 的实际处理帧数，显示检查模板、复用模板编码、完整解码校验和保存；不再出现模板制作阶段。保存前停在99%，登记完成后100%。处理帧数是工作量，并非剩余时间预测。
- 每次保存命令、日志、逐阶段耗时、缓存命中状态和 `progress.jsonl`。一次性准备耗时与缓存复用后的成片耗时分开记录。
- 缓存保留完整分辨率、帧率和效果配方，使用有损视频压缩控制体积；允许与旧成片相近的正常压缩差异，不承诺逐像素一致。缓存大小包含透明信息、切换备用帧和可能的素材相关特效输入，不能直接等同成片大小。达到使用上限仍只隐藏模板，本轮不自动清理缓存。

## GPU 合成与兼容路径（2026-10-20 源码）

- 实际运行小样检查设备能力，结果在同一程序进程复用；不只检查FFmpeg是否列出编码器。支持时，普通/滤色模板的主素材解码、缩放、RGB像素合成和颜色转换使用Vulkan，最后继续按既有H.264标准输出。画面贡献与RGB透过比例仍按原整数乘法、加法和限幅组合。
- 旧H.264 4:4:4模板继续CPU解码，可使用GPU缩放及混合；新HEVC 4:4:4模板在支持设备上同时使用GPU解码。成片阶段不转码、不重建旧模板；已有模板不必重做。
- 当前GPU路径限8位、普通色彩范围、方形像素、无旋转的逐行SDR视频，以及整条输出均可预合成的普通/滤色效果。HDR、10位、未知色彩、非方形像素、旋转/隔行素材、静态预览及含素材相关滤镜的成片继续使用原合成路径。未实现所有特效的GPU迁移。
- GPU设备或滤镜初始化失败时保留失败输出和日志，再用原CPU合成路径处理；普通素材损坏不作为显卡失败忽略。`check.json`记录实际路径，`hardware_check.json`记录能力检查，发生回退时保存`acceleration_fallback.json`。
- CPU兼容路径对低于30fps的素材先缩放真实画面，再补到30fps，避免重复缩放同一帧；高于或等于30fps及未知帧率保持原顺序。任务领取与渲染复用同一文件指纹检查，文件大小或时间戳变化后重新校验。
- 完整成片检查继续CPU解码视频和音轨，核对精确帧数，并对解码错误停止。没有取消完整检查；本机对照显示GPU执行这一阶段反而更慢。
- GPU合成结束后明确恢复方形像素，输出检查同时要求像素比例1:1及显示画幅9:20。分辨率为1080×2400但显示比例异常时停止保存，避免播放器横向拉宽。
- 分辨率、30fps、裁切规则、特效时间表、透明度、羽化、贴纸、边条、原声及最终输出码率标准不变。GPU与CPU缩放/颜色转换及不同缓存编码器可能产生细小像素差异，不能把同配方当作逐像素相同。
- 用户已确认比例修复后的对照样片，并授权纳入2026.10.20.1版本打包。性能、视觉证据及目标机未验证范围见[GPU合成优化事项](../../事项档案/2026-10-20-V3成片GPU合成优化.md)；发布状态以[更新发布记录](../../事项档案/2026-10-20-V3成片优化更新发布.md)为准。

## 模板次数与删除

使用上限位于参数中心“每个模板使用上限（剧集数）”，默认20，范围1—1000。同一部剧使用同一模板，无论生成多少条成片，只占一个名额；该剧首次成功产生成片时记一次。预览、单纯选用、全部失败或全部取消不计成功次数。排队按尚未成功的不同剧集预留名额，首条成功后预留转为已用，后续条不重复扣次。已有使用或预留的同剧补做/重试不再申请名额。

现有 `outputs` 成功明细按 `template_id + drama_key` 去重统计，保留每条成片的明细和幂等性；已有历史无需清空或重新生成。剧集主档及别名归一到剧集编号，没有主档时沿用名称身份。删除生产剧集、发布后清理、删除模板均不删除成功使用账。同剧重新建立生产卡片仍按同一身份计数，不再增加次数。

达到上限后，新剧不再显示可选模板；已经使用的同剧仍可查看、继续补做。模板文件和历史保留。人工删除仍检查所有排队/运行成片，而不是只检查未计次的剧集预留，避免首条成功后误删同批后续正在用的模板。

当前同一账号×剧集的一批素材仍统一使用所选模板。已有成功成片或排队/运行中的任务时不允许直接换模板。保留同剧跨账号选用限制。

## 文件、队列及恢复

- 新后台位于`server/ffmpeg_finals/`。队列`final_jobs`与使用记录`outputs`同在`系统数据/database/v3_template_library.db`，业务库`production_video_tasks`投影为`ffmpeg_`状态，旧剪映调度器不领取这些新任务。
- 输出进入当前任务既有成片目录，沿用素材编号命名；已存在成片绝不覆盖。中间文件与日志进入`系统数据/fg/<任务短号>/a<尝试次数>`。
- 提交时固定原素材与模板缓存内容指纹。素材或缓存被替换后报错并保留配方，不静默换料。
- 重启后正在执行的任务转为“合成中断”，可人工重试；等待项正常恢复。失败重试使用新尝试目录；已经发布且回执指纹一致的视频直接补登记录，不重复渲染或计次。
- 同一任务有等待/运行中的FFmpeg合成时，禁止删除剧集以保护输入。模板人工删除保留已经生成的成片。
- 删除剧集、已发布任务立即清理与到期过程清理，均包含 `系统数据/fg/<任务短号>` 的各次尝试目录。文件清理成功后删除 `final_jobs` 和任务 `selections`，保留 `outputs` 成功使用账、公共模板和 `tg` 缓存，不退回次数。
- 队列提交、选用、任务投影和清理共用数据目录级锁；清理同时检查真实队列中的等待/运行状态。清理失败保留队列以便重试；新投影不能重建已完成过程清理的成片明细。
- 启动恢复后核对父任务：删除父任务已不存在或已完成过程清理的队列/选用记录；历史文件和成功使用账不自动删除。快照和领取任务也检查父任务有效性，避免历史残留重新出现或运行。
- 成片队列单独暂停/继续，与模板队列分别控制；暂停在当前份结束后生效。

## 验证边界

独立工作区已验证21秒带声素材和6秒无声素材，复用10秒模板；21秒版本跨两次模板循环，完整解码、原声数值对照、卡片入库、额度隐藏和实际播放检查通过。详见[事项档案](../../事项档案/2026-10-19-V3模板管理与FFmpeg成片合成.md)。尚未完成正式用户观看、数百份长视频耐久、安装包和另一台机器验收。

2026-10-19完整素材性能验证：同一468.067秒素材由787秒降至405.625秒（减少48.46%）；原缓存和素材未改动，音频数据一致，14个时点和两次模板循环对照通过。进度由实际帧数更新。详见[性能优化事项](../../事项档案/2026-10-19-V3成片合成性能优化.md)。这是本机这一组实测，用户连续观看、其他模板的大规模长期运行及其他机器仍需区分验收。


## 中插、尾插与分层覆盖（2026-11-02）

- 参数中心原“成片插片（中插 / 尾插）”卡设置全局默认，原两栏、取材选择、保存及主轨结构预览保留。新增“视频短于”和“中插位置下限/上限”，均输入分:秒，例如5:00、3:00至5:00。门槛严格小于时跳过，等于门槛可插；位置下限须大于0且不超过上限。区间相同为固定位置。
- 主视频时长以30帧对齐的时间轴为准。与视频内部合法帧取交集，排除第0帧和结束帧；无交集跳过。区间内每条确定一个插入点，随成片配方保存；失败重试沿用原点，不重新抽取。
- 生产中心素材区标题旁“本剧集插片”针对当前账号×剧集设置。每个插片位可跟随全局、不要或单独设置时间和取材；仅中插覆盖时尾插继续继承。素材卡左上角“⋯”设置本片中插/尾插的跟随、不要、要插；启用时仍遵守继承的时长条件。卡片底部显示覆盖状态。两处均可恢复跟随。
- 逐字段按全局→当前账号×剧集→单素材合并，未保存字段继承。设置只用于后续新提交；未主动重新生成时，已排队、运行、完成和技术失败重试保留当前配方。已有已完成视频不会自动重做；2026-11-03新增主动重新生成，见下节。未结束且有效的原素材可改设置，已完成发布或清理的任务不能修改。
- 未保存过全局插片配置的V3保持原来FFmpeg无插片行为，界面明确提示保存后启用。已经保存过的旧全局选择会参与新提交；旧时间字段缺失默认门槛2:00、位置2:00至2:00。
- 按原“生成资源/引流视频”取材，跟随最新序号或锁定某文件。短片/无合法中插位置不检查中插资源；实际启用且应插入时缺资源明确报错，整批不留下部分任务。广告路径、内容指纹、插点、帧数、音轨状态和继承后的规则随配方冻结；执行时文件变化则停止，禁止静默换片。
- 原画面与原声暂停，中插播放后从原位置继续；尾插接在主素材结束之后。主画面和插片均按原1080×2400、30fps流程合入模板，模板时钟沿最终总时间轴连续循环。直接加入最终编码图，不先压整段中间视频。普通缓存路径与特效分段路径均接入；插片使用CPU处理时间轴和像素，仍按现有选择使用NVENC或CPU编码器。
- 成片列表按提交配方显示总时长、插点或跳过原因与尾插状态；业务详情也读取配方总帧数，避免退回原片时长。修正插片资源/规则后自动合成可重新检查尚未提交素材，已失败/取消任务仍需手动重试。
