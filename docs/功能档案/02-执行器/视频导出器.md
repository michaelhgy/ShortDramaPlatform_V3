# 视频导出器

> 把生成好的**成片草稿**通过剪映自动导出成 mp4（模拟键鼠操作剪映 5.9）。
> **他会这么说**：「导出」「导出器」「剪映导出」「双 ESC」「人工检查」「卡在导出」
> 最后核对：2026-09-19 ｜ 状态：已整理

## 一、它做什么

- **入料**：一条成片草稿（剪映 5.9 原生草稿目录）。
- **产出**：一个验过的 mp4 文件，落在正式目标位置。
- **它怎么干**：打开剪映 → 找到草稿 → 触发导出 → 等文件出来 → 校验媒体 → 安全替换到正式位置。
- **注意**：它模拟键鼠，属于**高危区**，所以有一整套"停下来"的保护（见业务规则）。

## 二、怎么用

1. **生产中心 → 卡片 → 导出**（成片草稿就绪后进入导出队列）。
2. **人工检查模式**（剧集级开关）：导出前会**自动打开草稿然后松开键鼠**，等你在剪映里看一眼，按**回车**继续。
3. **想紧急停下**：**双击 Esc** —— 立刻释放键鼠，本次尝试按失败处理。

## 三、业务规则

### 每次导出 = 一次"导出尝试"，不可变

- 每次导出新建一次**导出尝试**；**重试和重新导出都从头开始**，不在旧尝试里恢复。
- 失败、超时、双 Esc 都是**终态**；只有新建一次尝试才能再导。

### 双 Esc = 紧急终止

- 立刻释放键鼠；本次尝试按普通失败处理，记录"用户双 ESC 紧急终止"。
- **不提供继续或场景恢复**。

### 人工检查模式

- 自动打开**正确的那条草稿**后**释放键鼠**，等你在剪映里检查。
- 按回车后**重新接管**并**直接进入导出**——**不回首页、不重复搜草稿**。
- 等待期间**同样可以双 Esc 终止**。

### 提交之后就不再碰剪映

- 最终导出提交后，V2 **不再自动控制剪映**。
- 即使你自己取消、改草稿、再手工提交，系统**只看第一次记录的那个输出路径**和统一超时。

### 什么算"真的导出成功"

必须**全部**满足：新视频出现 → 相对提交前的基线有变化 → 文件大小稳定 → `ffprobe` 校验通过 → 原子替换/移动成功 → 数据库收口成功。

- 正式目标位置已有旧文件时，允许在新视频验收后**替换它**；**不允许先删旧文件**。

### 连续失败才会暂停

- 连续失败/超时计数属于**任务中心的执行器管理层**（三个执行器共用），**导出器自己不判**。
- 达到**连续 3 次**才暂停；**人工重启后清零**。
- 软件重启时正在跑的尝试**直接记失败**，不自动恢复。

### 状态怎么走

```
queued → preparing → awaiting_human_check? → submitting → observing_output → finalizing → completed
```

- 普通失败 / 超时 / 双 Esc → `failed`（终态）。
- **未知页面**、**最终提交是否生效无法确认** → 也要**结束当前尝试**，**绝不允许重复点击最终导出**。

## 四、可调参数

| 参数 | 在哪调 | 默认 | 说明 |
|---|---|---|---|
| 人工检查模式 | 剧集级开关（生产任务上） | 关 | 开了才会在导出前停下来等你按回车 |
| 导出超时 | 设置页 →「生产与任务设置」 | 20 分钟 | 超时按失败处理 |

写死在代码里的：连续失败阈值 3 次；媒体校验项（分辨率 / 编码 / 帧率 / 时长）。

## 五、改动须知（动这个功能前先看这段）

### 一句话：这是高危区，任何"再试一次"的改动都可能造成重复点击

1. **提交后的"无法确认"必须算失败，不能重试**。未知页面、或提交是否生效无法确认 → **结束本次尝试**。
   **绝不允许**在这里加"再点一次最终导出"的兜底——那是重复导出。
2. **不许先删旧文件**：正式目标位置要**原子替换**（新文件验收通过后再替换）。
3. **导出器只报告"这一次"的结果**，不决定"连续 3 次后暂停"——那是 `ExecutorManager` 的职责。
   改暂停逻辑要去 `server/executor_management.py`，别写进导出器。
4. **双 Esc 必须在任何阶段都能立刻释放键鼠**。加新的等待/轮询时，必须保留这个逃生口。
5. **V1 只能按接口迁低层能力**（剪映进程发现、UIA 控件识别、草稿名搜索、文件观察、ffprobe 校验）。
   **不要搬 V1 的双状态机 / 旧 monitor / 大 worker 编排**。
6. **改 DDL 必加 `SCHEMA_VERSION` +1**（见《界面与开发规范》）。

### 代码入口

| 干什么 | 文件 | 关键函数 |
|---|---|---|
| 一次真实导出尝试 | `server/v2_exporter/runner.py` | 领取任务、模拟键鼠、观察输出 |
| 状态机 | `server/v2_exporter/core.py` | 状态定义与转移（`queued` → … → `completed`） |
| 提交前基线 / 文件稳定 / 媒体校验 / 安全替换 | `server/v2_exporter/runtime.py` | 这些在代码里是**函数**（不是独立组件，别按设计文档里的组件名去找） |
| 连续失败与暂停 | `server/executor_management.py` | 计数、暂停、人工重启清零 |
| 真实导出入口 | `tools/run_v2_real_export.py`；接口 `POST /api/v2/exporter/jobs`、`POST /api/v2/exporter/jobs/{job_id}/start` | 只接受用户明确指定的任务和**已存在的**真实草稿目录 |
