# V3 风景素材处理

2026-10-19，按用户确认的“原片人工裁切，成功后删除；处理结果独立使用”接入资料中心。

## 入口与目录

资料中心 → 生产资源 → 风景视频。可用风景与原始风景分开查看。顶栏“资源 · 风景 N 条”显示同一可用口径，点击直达可用风景页；入库、删除及有效性/剩余额度变化同步刷新资源库存。

- `生成资源/原始风景视频`：原名任意，人工放入后刷新，可独立播放预览、多选批量裁切，也可逐条精细调整。
- `生成资源/风景视频`：处理后自动编号的素材。旧目录未经过本功能入库的文件出现在原始风景页，不参与新模板抽取；不自动移动或删除旧文件。旧模板排队/运行仍引用某原片时阻止处理删除。
- `系统数据/scenery_processing/library.db`：加工队列、连续编号、处理后素材身份；用量继续读取模板制作账本。
- `系统数据/scenery_processing/jobs/<编号>`：未完成任务的暂存结果。成功后回收临时目录并清空原片身份、路径、裁切配方和结果关联。

## 人工处理

打开原片可播放、拖动时间。1/2/3份快捷布局生成裁切框；拖动移动、右下角调整大小，或输入偶数像素。各份有动态局部预览，可去掉不需要的区域。框必须在画面内、宽大于高，最小32像素。新建任务按下面的时间规则输出30秒以内短片，全部无声、30fps、H.264。横屏自动模式保留完整画面；符合快速封装条件的整段横屏保留原分辨率及视频画面，不重新编码。需要裁切或转码时通常输出宽度不超过1080、保持取景比例，不强行拉伸小源。

确认按钮明确显示“生成 N 份，成功后删除原片”。对应一个原片的一次处理作为一组：

1. 固定原片内容、画面区域及时间分段配方，按画面区域数×时间段数预分配 `风景000001.mp4` 等不重复短编号。
2. 符合规格的整段横屏快速封装并去声音；其他素材将画面裁切与时间分段一起完成，同一时间段的多块取景共享一次解码。检查每份实际帧数、尺寸、30fps、方形像素、无音轨、时长上限及完整解码，保存结果指纹。已验证部分可供失败重试复用。
3. 全部成功才发布到风景目录并登记可用，不把未完成结果交给模板抽取。
4. 删除前再核对全部入库文件及原片内容；确认无旧运行引用后删除这一条原片。其他原片不受影响。
5. 完成后删除原片列表记录、清除来源关联。入库素材独立管理，不按原片分组。

入库前失败保留原片，重试不重新制作已验证部分。入库后原片被占用导致删除失败时，保留已入库文件和未完成状态；重试只核验结果、删除原片。若任一结果缺失/变化，原片仍保留。重启后未完成执行标为中断，人工重试；排队可继续，暂停状态独立保存。

## 批量裁切

原始风景卡片勾选或全选待处理原片 → 批量裁切 → 查看区域预览、按需单独调整 → 一次提交队列。已有等待、运行或失败任务的原片不重复勾选，失败项通过现有任务重试。

- 自动布局为竖版三块横向取景、横版保留完整画面；方形沿用一块横向取景。仍可手动选择1/2/3块画面区域。横屏单块默认使用完整偶数像素画面，不套用原75%高度裁切；多块和方形继续按原横向取景规则生成，极小源提示调整或移出。
- 批量窗口分别展示画面区域数、时间段数、实际段长范围及最终短片数，总数按区域数×时间段数计算；“预览并单独调整”复用可播放的裁切编辑器，保存只更新本条待提交方案，不提前开始处理。
- “应用到本批全部”明确覆盖单独调整；“移出本批”只移出当前选择，不删除原片。
- 单次提交1—200条，每条独立入队、独立反馈。参数或读取错误不阻止其他合法原片入队；执行中失败也不阻止后续原片。保留既有队列暂停状态。
- 每条使用固定提交标识；网络响应丢失时保留同一请求并提供“确认提交结果”，不重复创建已接收任务。成功入队项从待提交列表移除，失败项留下原因供调整或移出。
- 每条原片的全部结果成功后才自动删除。重试继续复用已验证部分，完成后仍不保留来源关联。

## 时间切段与快速入库（2026-10-25最新源码）

- 原片视频时长不超过30秒时保留整段；超过30秒时，在30fps时间轴上连续随机划分，长片每段15—28秒，硬性不超过30秒。先选择合适段数，再随机分配各段帧数并平衡末尾，不使用固定30秒或反复对半切。
- 每个画面区域完整覆盖同一条时间轴，分段不重叠、不留下短尾；原片时长按30fps取整存在半帧以内的时间精度差异。声音始终去掉，视频不会为满足随机段长而变速。
- 预览读取时计算稳定时间方案，提交时保存到任务原有`source_meta`的`processing_plan`中；不新增数据库字段。重试沿用原配方，不重新随机，按片段指纹和帧数复用已验证结果。
- 只有整段、完整横屏、H.264/yuv420p、30fps、方形像素、无旋转且尺寸不需调整时，直接复制视频流并去掉音轨、章节和原媒体元数据；可以保留1920×1080等原分辨率。快速封装检查不通过时回到转码流程。音频去除原本已经存在，本次速度改善来自省掉视频重编码和共享解码。
- 长片随机切点为保证按帧准确，需要转码；每段从切点附近预读一小段，统一帧率后精确截取，避免反复从头解码。相同时间段的多块竖屏取景共享解码，直接输出最终短片，不先输出长文件再二次转码。
- 旧已入库素材不重切、不重命名；没有新分段配方的旧等待或失败任务继续原完整时长规则。新规则从新建任务开始生效，已有旧素材可能仍超过30秒。
- 全部结果成功入库且逐一核对后才删除对应原片，失败、源文件变化或任一结果缺失均保留原片。处理中断保留配方与已验证部分，不自动重试；单命令连续120秒没有新增输出帧时停止该子进程并保留现场。

此规则用于2026.10.25.3轻量更新及最新源码；2026.10.25.2完整包和.1→.2轻量包不包含此修改。实现与实际媒体验证见[横屏快速入库与随机短片](../../事项档案/2026-10-25-V3风景横屏快速入库与随机短片.md)。

## 预览与人工删除

原始风景与可用风景卡片都提供独立播放预览和删除按钮，预览窗口也可删除当前视频。删除对话框显示文件名、永久删除说明与取消按钮，确认后才执行。

- 原片：正在处理或等待任务、旧模板仍引用时阻止删除。允许删除未排队原片及失败原片；清理其失败/已取消处理记录与暂存结果，已经正式入库的结果保留并独立管理。文件自扫描后发生变化时要求刷新后重新确认。
- 可用风景：模板任务已预留时阻止删除；原片入库删除事务未完成时需先完成处理或处理原片。删除前核对目录、文件状态与内容，避免删除被替换的文件。删除文件后退出素材列表，身份与历史使用账保留，已完成模板不受影响。
- 删除失败显示实际原因，界面不伪报成功；成功后刷新风景列表、资源库存及任务中心。

## 使用与清理

只有入库素材进入随机池，按内容身份去重、沿用上下不共用及既有排布、蒙版、羽化规则。同一原片的不同切片各自为独立素材，本轮不增加同源避让条件。

- 一条素材实际排入成功模板的播放时间轴（帧数大于0）计1次；同条循环或只播一部分均计1次，后续成片复用不计风景次数。抽中但未播到的候选不计次，不因本模板触发用满删除。
- 等待和运行模板仅为实际排入时间轴的风景预留；未播到不占名额，失败/取消/中断释放。卡片显示成功次数、占用次数、剩余次数。
- 达到当前上限后停止抽取；无预留且原片处理事务已完成时，删除处理文件、保留身份与使用账。清理失败显示原因，下次清理入口重试。文件内容被替换时不自动删除替代文件。
- 清理入口为模板完成、等待取消、参数保存、风景刷新与新模板抽取。原片不走用满清理；已完成模板缓存继续复用。

2026-10-25源码兼容处理：旧等待模板释放未播到候选的多余预留，原配方保留；旧成功使用账不追溯改写，过去已删除文件不会恢复。参数中的风景数量是创建时的候选数量，仍需对应库存，不保证全部播到。详见[实际播放计次修复](../../事项档案/2026-10-25-V3风景按实际上屏计次修复.md)，此次修复纳入2026.10.25.2，2026.10.25.1安装包不包含。
