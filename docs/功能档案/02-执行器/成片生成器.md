# 成片生成器

> 一句话：把爆款素材 + 中插/尾插拼成一条完整成片（草稿 → 导出由《视频导出器》接手）。
> 最后核对：2026-09-19 ｜ 状态：✅ 在用

---

## 1. 这是什么（人话）

模板是"铺子"（背景、文案、照片墙），**成片才是要发出去的最终视频**。
生成器把三样东西拼在一起：

```
爆款素材（主内容）  +  中插（可选，插在中间）  +  尾插（可选，放最后）
```

生成的是一条**剪映草稿**（`v2` 成片草稿），随后由《视频导出器》自动导出成 mp4。

---

## 2. 怎么用（点哪里 → 看到什么 → 出什么结果）

| 步骤 | 在哪 | 你会看到 |
|---|---|---|
| 1 | 参数中心 →「**成片插片**」卡 | 中插一行、尾插一行：左边开关（要/不要）、右边下拉（跟随最新序号 / 指定某一条）；卡片下方直接显示"**这次成片主轨会是什么样**" |
| 2 | 设置页 →「生产与任务设置」 | 「成片启用原素材视频处理」开关（默认开） |
| 3 | 生产中心 → 某个账号×剧集的卡片 | 生成成片草稿；卡片上三层进度里的"成片"那一层 |
| 4 | 任务中心 | 看排队/执行中/完成；可手动调整整部剧的顺序（见《任务中心》） |

## 3. 规则与逻辑（每条带出处）

### 3.1 主轨结构：**四种组合**（用户 2026-09-18 拍板）

| 中插 | 尾插 | 主轨长什么样 |
|---|---|---|
| 要 | 要 | `爆款前段 → 中插 → 爆款后段 → 尾插` |
| 不要 | 要 | **`爆款整条 → 尾插`（爆款不拆段）** |
| 要 | 不要 | `爆款前段 → 中插 → 爆款后段` |
| 不要 | 不要 | 只有爆款一条（**允许，且不弹窗提醒**），模板视频循环铺满 |

- 用户原话（2026-09-18）：**"爆款不用再剪成2段吧？"** —— 只有要插中插时才拆段。
- 校验在 `server/final_engine/jianying59_final/composition.py:371 validate_plan()`；结构在 `:206 _main_sections()`。

### 3.2 中插的插入点：素材必须**长于 120 秒**

- `composition.py:35`：`MIDROLL_INSERT_US = 120 * US`（120 秒）。
- `composition.py:225`：素材时长 **≤120 秒**时 → `inserts_midroll = False`，
  记为 `skipped_short_source`（`:338-344`，同时回报 `threshold_seconds: 120`）。
- 也就是说：**素材太短 → 中插自动跳过**，成片降级（不影响生成成功）。

> ❓ **【待用户拍板】这里与规则文档冲突，尚未解决：**
> `docs/V2参数中心规则.md` 写的是"**人工设置优先于'素材太短自动跳过中插'的自动判断**"（用户 2026-09-17 拍板），
> 但代码 `composition.py:225` 是"素材太短 → 自动跳过"，**自动判断压过了人工设置**。
> 两种解释：① 代码漏了"用户明确指定时要插"的分支 → 是缺陷；② 素材短到没有合法插入点，物理上插不了 → 文档该改口径。
> **未修、未猜**，记在《待做需求清单》与 `docs/决策日志.md`。

### 3.3 成片时长上限：**900 秒**

- `server/final_engine/scripts/run_jianying_composition_batch.py:25`、`run_ffmpeg_composition_batch.py:18`：
  `MAX_FINISHED_SECONDS = 900.0`。

### 3.4 原素材处理开关（用户 2026-09-17 拍板）

- 设置页「成片启用原素材视频处理」（默认**开**）：
  - **开**：做四项分析（片头 / 片尾 / 黑边 / 剧名）+ 清理代理。
  - **关**：**整个处理都关**（不掐头去尾、不裁黑边、不去标），但**仍按 900 秒上限截断**。
- 用户原话："E3 需要有一个是否启用……现在不是全部视频都是需要做这个处理了。"

### 3.5 素材怎么选（中插 / 尾插）

- 入口：`server/final_engine/runner.py:177 resolve_insertion_media()`。
- **"跟随最新序号"** = 每次生成时**重新**在 `生成资源/引流视频/` 里找序号最大的那条（动态跟随）。
- **"指定某一条"** = 锁定那一条，不再跟随。
- **两层配置**：参数中心设**全局默认**；单个生产任务可**单独覆盖**
  （字段 `production_tasks.midroll_endroll_strategy`，空 = 跟随全局）。
  ⚠️ 任务级的「跟随全局默认」**开关界面还没做**（引擎与接口已就绪）。

### 3.6 真人组合图片（容易被误解，单列）

- 成片里有 **6 张"真人组合片段"图片**，来自 `生成资源\真人图片\`，**透明度 0.02（画面上几乎看不见）**。
- 它们**不是**照片墙那套（照片墙属于《模板生成器》），是**另一套素材、另一个流程**。改照片墙时不要碰它。
- 出处：`server/final_engine/jianying59_final/visual_layers.py:19`（alpha 0.02）；
  数量不足 6 张会报错（`server/v2_file_service.py:4084`）。

## 4. 可调参数

| 参数 | 在哪调 | 默认 | 范围 |
|---|---|---|---|
| 中插 要/不要 | 参数中心 →「成片插片」 | 要 | — |
| 中插 用哪一条 | 同上（跟随最新 / 指定） | 跟随最新 | — |
| 尾插 要/不要 + 用哪一条 | 同上 | 要 / 跟随最新 | — |
| 原素材视频处理 | 设置页「生产与任务设置」 | 开 | 开 / 关 |
| 成片时长上限 900 秒 | **代码写死** | 900 | ❓ 是否要变成可调未确认 |
| 真人图片张数 6 / 透明度 0.02 | **代码写死** | 6 / 0.02 | ❓ 未确认 |
