# 生产中心

> 核心页面：左边列出所有「账号 × 剧集」，右边是选中那部剧的**生产工作区**（素材 / 模板 / 成片）。
> **他会这么说**：「生产中心」「卡片」「素材」「模板」「成片」「登记发布」「一键清理」「删除剧集」「扫描素材」
> 最后核对：2026-09-19 ｜ 状态：已整理

## 一、它做什么

- **左栏（窄）**：一部剧一张卡，卡上显示计划发布时间、三个数字和一条进度条。
- **右栏（宽）**：选中那部剧的工作区，从上到下是**素材 → 模板 → 成片**三段。
- 状态全部由后端算，前端只显示（见《三层状态》）。

## 二、怎么用

| 你想干什么 | 在哪 |
|---|---|
| 看某部剧 | 点左栏它的卡片，右栏切到它 |
| 让软件认新放进素材目录的文件 | 卡片上的「**扫描素材**」（悬停说明：同步本地素材目录与有效素材记录，序号不重复复用） |
| 生成模板 / 看成片 | 右栏的模板区、成片区 |
| 打开剪映草稿看 | 模板区的「打开草稿」 |
| 只重跑导出（不重做草稿） | 模板区/成片区的「重新导出」 |
| 重做草稿 | 「重新生成（重做草稿）」 |
| 登记发布 | 右栏「登记发布」→ 填**实际发布时间 + 省 / 市 / 区县 + 详细地址** |
| 清掉这部剧的文件 | 未登记发布 →「删除剧集」；已登记发布 →「一键清理」（都会先给预览，确认才执行） |

## 三、业务规则

### 左栏卡片

- 显示**计划发布时间**；已超期且未完成时会变红。
- **三个数字 + 一条进度条**（口径与《任务中心》组头完全一致）：

  | 颜色 | 含义 |
  |---|---|
  | 绿 · 视频 | 视频已导出 |
  | 蓝 · 草稿 | 草稿已生成（还没导出） |
  | 灰 · 素材 | 素材总数（进度条总长） |

- **异常单独显示**，不混进正常进度。
- 还没扫描的新素材**不计入分母**，另行标出。

### 右栏工作区

- **只有点开的剧才读详情**（列表用的是摘要）。
- 详情会**自己静默刷新**（当前打开的这部剧每 5 秒校验一次），所以数字不会长期停在旧值。
- **模板草稿写出后会自动进入视频导出队列**，不需要手动提交导出。

### 人工检查模式

- 卡片上的开关，说明原文就是它的行为：**打开成片草稿 → 等待用户人工核对 → 确认继续 → 自动导出 → 进入下一条**。
- 这是**剧集级**设置：设置页那个值只作为新建剧集时的默认值（生效边界见《三层状态》）。

### 两个删除操作的区别

| 页面状态 | 按钮 | 会删什么 |
|---|---|---|
| 未登记发布 | **删除剧集** | 该任务的生产文件、临时资源、经证明归属的剪映草稿、该任务记录 |
| 已登记发布 | **一键清理** | 可清理的生产文件；**保留**发布登记、收益关联、爆款资产、清理记录 |

两者都必须：**后端先给真实预览 → 你确认 → 后端执行 → 返回真实结果**。
详细边界见《文件与资源生命周期》和《清理系统》。

## 四、可调参数

| 参数 | 在哪调 | 默认 |
|---|---|---|
| 人工检查模式 | 卡片上的开关（剧集级） | 关（设置页的值作为新建剧集默认） |

## 五、改动须知（动这个功能前先看这段）

1. **卡片三个数字必须与《任务中心》组头同口径**（绿=视频已导出、蓝=草稿已生成、灰=素材总数），
   而且要与任务快照同一次取到——分两次查就会出现两处数字对不上。
2. **详情是"点开才读"**：列表只用摘要。加新字段时先想清楚它属于摘要还是详情，别把详情塞进列表。
3. **右栏详情有自己的 5 秒轮询**（页面级计时器，不在数据层里）。改刷新相关代码时不要重复再挂一个计时器。
4. **人工检查开关是剧集级**，导出器在真正开始该剧导出前重新读一次；已进入等待人工检查的那条不跳过。
5. **两个删除操作都要先预览、后执行**，且都要走《清理系统》里那份"任务专属文件清单"。
6. **状态不许前端推断**（见《三层状态》）；卡片上的进度与异常数都由后端给。
7. **改 DDL 必加 `SCHEMA_VERSION` +1**（见《界面与开发规范》）。

### 改完怎么验

1. **一定先跑**：`tools\一键验证.bat`（`server/tests/test_v2_file_service.py`、`test_v2_task_center.py`）。
2. **改左栏数字或状态**：同一时刻对比《任务中心》组头，两边的「视频 / 草稿 / 素材」必须完全一致。
3. **改工作区按钮**：实机走一遍——同步素材 → 生成模板 → 草稿自动进导出队列 → 预览成片 → 登记发布，
   确认每一步的按钮状态与提示都跟着变。
