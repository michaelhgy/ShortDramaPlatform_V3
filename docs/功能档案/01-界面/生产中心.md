## 一、它做什么

- **左栏（窄）**：一部剧一张卡，卡上显示计划发布日期、三个数字和一条进度条。
- **右栏（宽）**：选中那部剧的工作区；桌面宽窗口下，**素材与公共模板左右并排，成片在下方**。窗口较窄时素材与模板上下排列。
- 状态全部由后端算，前端只显示（见《三层状态》）。

## 二、怎么用

| 你想干什么 | 在哪 |
|---|---|
| 看某部剧 | 点左栏它的卡片，右栏切到它 |
| 让软件认新放进素材目录的文件 | 卡片上的「**扫描素材**」；保留已有编号，新文件从最大编号续接，优先衔接尾部类型；羊头保留「羊-」标记 |
| 看公共模板 | 模板区域 → 模板卡片；按名称或使用次数排序 |
| 预览模板 | 点击卡片画面；在弹窗播放真实视频并可拖动进度 |
| 为本任务选模板 | 卡片或预览弹窗 →「选用」；一批素材统一使用一个模板 |
| 生成与看成片 | 素材扫描、选模板后点“批量合成”；完成后在成片区预览或打开成片目录 |
| 自动发布 | 右栏「自动发布」→ 通过MCP提交并同步小V猫、官方作品状态 |
| 清掉这部剧的文件 | 发布未完成 →「删除剧集」；官方发布已确认 →「一键清理」（都会先给预览，确认才执行） |

## 三、业务规则

### 左栏卡片

- 显示**计划发布日期**（YYYY-MM-DD），不显示时分；当天不算逾期，跨过该日后未完成才标逾期，未设置日期不逾期。
- **三个数字 + 一条进度条**（口径与《任务中心》组头完全一致）：

  | 颜色 | 含义 |
  |---|---|
  | 绿 · 视频 | 视频已导出 |
  | 蓝 · 草稿 | 草稿已生成（还没导出） |
  | 灰 · 素材 | 素材总数（进度条总长） |

- **异常单独显示**，不混进正常进度。
- 还没扫描的新素材**不计入分母**，另行标出。

### 右栏工作区

- **只有点开的剧才读详情**（列表用的是摘要）。
- 详情会**自己静默刷新**（当前打开的这部剧每 5 秒校验一次），所以数字不会长期停在旧值。
- 生产中心内容最大宽度为 1840px，左侧任务栏在 1280px 及以上窗口固定为 320px，其余空间交给右侧工作区；其他页面维持原宽度。
- 窗口宽度达到 1280px 时，素材区与模板区按约 2:3 并排，各自横向滚动；不足 1280px 时上下排列。两区共用标题与卡片起始行，底部不设置常驻说明条。预览框使用 110px 宽、9:20 的竖图比例，图像等比完整显示；卡片数量不增加区域高度。
- 公共模板选择单独保存，选用不创建剪映草稿、不提交导出任务。

### V3 公共模板区域

- 模板锁定说明显示在模板卡片列表下方，仅在已有成片或队列锁定等条件满足时出现；位置调整不改变选用/锁定判断。

- 模板独立于账号和剧集，默认目录为 `内容资产\\公共模板`；本阶段读取该目录第一层已制作完成的 MP4。点击「模板目录」打开或创建此目录，点击「刷新模板」读取新文件及缩略图。
- 生产中心显示 128px 固定宽度的横向卡片，缩略图框为 110px 宽、9:20 比例；卡片含缩略图、名称、时长和单独的选用按钮。模板名称前用深色圆形数字标记显示实际使用次数，悬停可见完整次数含义，卡片不另放“累计使用”或可选状态说明行。点击画面打开预览，不再另放重复的文字预览按钮；播放图标仅在悬停或键盘聚焦画面时出现。长名称最多显示两行，完整名称和不可用原因可悬停查看，也可在预览弹窗查看。
- 筛选与排序放在顶部标题和目录/刷新按钮之间，宽度不足时自然换行。默认显示全部模板，可切换「当前可用」，并按名称或使用次数从少到多排序。当前已选模板保留展示。
- 可用模板显示可点击的「选用」按钮；不可选时按钮仍显示「选用」，按「批量合成」同样的灰色禁用样式显示，悬停或进入预览查看原因。已选模板通过卡片高亮、画面上的「已选用」标记和按钮状态表示，不另设底部汇总条或独立取消按钮。选择存入公共模板数据库，切换任务、刷新页面和重启后保留。
- 同一账号同一部剧的一批素材统一选一个模板。其他账号已经为同一部剧选用或成功使用的模板不可选，但仍可预览。其他剧集可以继续使用同一模板。
- 剧集现名和历史别名解析为同一剧集身份，避免通过改名绕过复用限制。
- 未产生成片时可点击「选用」选择模板；再次点击同一卡片的「已选用」直接取消，按钮恢复「选用」并清除高亮，取消状态也会保存。预览弹窗中的已选按钮采用相同操作。成功产生成片、任务发布登记或结束后不能直接改变选择。任务删除后释放其临时选择，成功成片使用记录继续保留。
- 累计使用次数按成功成片记录计算，同一成片记录只计一次。预览、选用、取消、刷新和失败均不增加次数。当前合成器尚未接入，正式新增模板从零开始；供后续合成器调用的计次入口是 `TemplateLibrary.record_output`。
- 模板内容哈希作为身份，改名重扫保留身份及历史；文件被替换、移动出目录或缺失时显示不可用。原文件不因扫描被改名、消费或删除。
- 没有真实模板时显示空列表和目录入口；加载失败显示错误和重试，不显示示例模板或把未知统计显示为零。
- 模板制作和透明效果层配套文件的正式生产约定，等待制作端成果后再接入；本阶段的选用不代表已经具备成片生产能力。

### 人工检查模式

- 卡片上的开关，说明原文就是它的行为：**打开成片草稿 → 等待用户人工核对 → 确认继续 → 自动导出 → 进入下一条**。
- 这是**剧集级**设置：设置页那个值只作为新建剧集时的默认值（生效边界见《三层状态》）。

### 两个删除操作的区别

| 页面状态 | 按钮 | 会删什么 |
|---|---|---|
| 发布未完成或官方作品无法匹配 | **删除剧集** | 该任务的生产文件、临时资源及该任务记录 |
| 官方发布已确认并匹配本地记录 | **一键清理** | 可清理的FFmpeg生产文件；**保留**发布记录、作品关联、收益分析、爆款资产和清理记录 |

两者都必须：**后端先给真实预览 → 你确认 → 后端执行 → 返回真实结果**。
V3 的清单包含任务专属 FFmpeg 临时目录；成功后同步移除对应成片队列、模板选用关系，并刷新生产区、任务小窗与全局任务中心。公共模板、模板复用缓存和已消耗使用次数保留。还有排队或合成任务时显示阻止原因，确认按钮禁用。已发布的一键清理按原有期限保留原素材与发布/收益记录，成片属于可清理的过程文件。
详细边界见《文件与资源生命周期》和《清理系统》。

## 五、改动须知（动这个功能前先看这段）

1. **卡片三个数字必须与《任务中心》组头同口径**（绿=视频已导出、蓝=草稿已生成、灰=素材总数），
   而且要与任务快照同一次取到——分两次查就会出现两处数字对不上。
2. **详情是"点开才读"**：列表只用摘要。加新字段时先想清楚它属于摘要还是详情，别把详情塞进列表。
3. **右栏详情有自己的 5 秒轮询**（页面级计时器，不在数据层里）。改刷新相关代码时不要重复再挂一个计时器。
4. **人工检查开关是剧集级**，导出器在真正开始该剧导出前重新读一次；已进入等待人工检查的那条不跳过。
5. **两个删除操作都要先预览、后执行**，且都要走《清理系统》里那份"任务专属文件清单"。
6. **状态不许前端推断**（见《三层状态》）；卡片上的进度与异常数都由后端给。
7. **改 DDL 必加 `SCHEMA_VERSION` +1**（见《界面与开发规范》）。

## 成品主动重新生成（2026-11-03源码版）

- 已生成、合成异常、已取消的 FFmpeg 成片均显示原有旋转箭头小图标，悬停为“重新生成（立即删除旧成品，读取当前中插、尾插设置）”。单条不增加新弹窗，点击即重新生成本条；等待及执行中不显示此单条入口，已登记发布的剧集不开放。
- 成片区“批量合成”左侧新增“全部成品重新生成”，使用原白色圆角描边按钮和旋转箭头。弹窗确认前不提交，默认焦点为取消，支持取消、ESC和点遮罩关闭；提交期间防重复点击。说明本账号×剧集、条数、耗时、当前设置继承；明确确认后立即删除旧成品，生成失败不恢复，保留原素材和原模板。
- 整剧范围为本制作任务已提交的全部 FFmpeg 成片，含完成、失败、取消及等待项；未提交素材仍用“批量合成”，不隐式新增或改动其他账号×剧集。
- 每次确认重新读取已保存的全局→剧集→本素材中插/尾插规则与当前指定/最新序号广告，重新生成配方；仍按短片门槛、合法插点区间执行。原主素材和原模板不变，不重复制作模板或增加该剧的模板使用次数。
- **2026-11-04修订：单条点击、整剧确认后，全部前置检查通过即删除对应旧成品，再排队生成；暂停队列也先删除。生成失败不恢复旧视频。** 重新生成沿用原素材对应的标准成片文件名，不加 `_R02` 等版本后缀。清除该任务历史尝试中的 `final.mp4` 成片副本和旧发布凭据；已记录的旧版本成片一并删除，不按通配符删除无关同名文件。原配方、状态与失败信息仍以JSON归档，不备份旧视频。浏览器预览版本随文件修改时间和大小变化，避免同名文件继续显示旧缓存。
- 本剧集有正在合成的一条时不允许整剧重做，提示在任务中心暂停后续并等当前条结束。重做不会绕过原全局暂停，继续合成须手动恢复；其他剧集的正在执行项不打断。已登记/清理任务、原素材变化或缺失、原模板不可用或缺必需广告时明确失败，整批前置校验失败不删文件、不提交部分队列；若删除遇到文件占用等错误则停止，将已触及记录标为失败，已删除的视频不恢复，解除占用后可再次重新生成。
- 已经交给小V猫的发布任务和旧草稿不会自动替换为新版，重新生成期间不要继续发布；本功能不操作小V猫或重新发布。
- 任务中心“重试”继续表示按当前保存配方恢复失败/取消项；要更新插片设置应使用本节生产中心“重新生成”，不再使用旧配方重试。
