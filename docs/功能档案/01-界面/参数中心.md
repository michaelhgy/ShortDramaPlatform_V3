# 参数中心

> 一个页签：把"经常要调"的参数集中在一处，**改完单独保存、立刻生效**。
> **他会这么说**：「参数中心」「文案在哪改」「中插尾插在哪设」
> 最后核对：2026-09-19 ｜ 状态：已整理

## 一、它做什么

- 只放**你经常要调的"生产参数"**（装完机就不动的系统设置留在设置页）。
- 页面是**一栏一张卡**（一张卡叫一个"参数组"）。**每张卡自带「保存并生效」**，不做整页大保存。
- 位置：顶部导航**最后一个**（资料中心之后）。

## 二、怎么用

1. 顶部导航 →「**参数中心**」。
2. 找到要改的那张卡。
3. 改完点**这张卡自己的**「保存并生效」。

## 三、业务规则

- **一栏一卡、各自保存**：改一组不会误伤别组。
- **卡里那些参数的具体规矩，写在那个功能自己的档案里**，不在这里重复：
  中插 / 尾插怎么选素材 → 见《成片生成器》；文案池怎么算 → 见《模板生成器》。
- 以后加参数 = **往页面里加一张卡**，已有卡片不重排。

## 四、可调参数

| 卡 | 能调什么 | 参数规矩详见 |
|---|---|---|
| **文案** | 祝福语、引导语两个**文案池**：增、删、改、上下移 | 《模板生成器》§文案池 |
| **成片插片** | 中插、尾插**各自**：要 / 不要；"跟随最新序号"或"指定某一条" | 《成片生成器》§素材怎么选、§中插插在哪 |

## 五、改动须知（动这个功能前先看这段）

1. **加一张新卡 = 往参数组注册表里加一项**，不要改动已有卡片的结构或顺序。
2. **每张卡自己保存自己**：新增参数时沿用"卡片级保存"，别做成整页保存。
3. **界面元素复用设置页那套写法**（卡片 / 行内编辑 / 增删 / 上下移），见《界面与开发规范》。
4. **参数的规矩写在所属功能档案里**：新参数属于哪个功能，就写到那份档案的「业务规则」和「可调参数」里，这里只登记"有这么一张卡"。
5. **任务级覆盖**走 `POST /api/v2/production-tasks/{id}/insertion-strategy`；任务级字段为空 = 跟随全局。
6. **改 DDL 必加 `SCHEMA_VERSION` +1**（见《界面与开发规范》）。

### 改完怎么验

1. **一定先跑**：`tools\一键验证.bat`。
2. **改文案卡**：改一句 → 保存 → 看服务端读到的值变了；再清空池，确认草稿里那条轨道不再出现。
3. **改插片卡**：关掉尾插 → 卡片下方的结构预览要跟着变。
