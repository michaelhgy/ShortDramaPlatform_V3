# 剧集获取与挂载来源

当前规则：2026-11-05。入口为工作台的“安排今天任务／安排账号”，使用居中弹窗，ESC先关闭关联或新增剧集子窗，再关闭主窗。关闭主窗不停止后台获取。

## 新建制作任务

顺序为挂载方式、运营账号、剧集、计划日期：

1. 必须先选“小程序”“视频号”“插件”，不默认替用户选择。
2. 同次可选多个同剧场的正常账号。账号卡片每行64像素、行间距8像素，最多显示3行（208像素），更多账号在账号区内滚动；账号名称与剧场单行省略。使用剧场ID校验，未选账号时不能先选剧；改变账号后剔除不属于当前剧场的已选剧。后端创建任务再次核对所属剧场。
3. 剧集区保留“现有剧集”“小程序短剧”“视频号剧集”三个并列页签。“现有剧集”只按所选剧场和搜索词显示完整本地剧库，不按账号挂载关系、挂载方式或获取范围隐藏条目；同剧场账号看到的列表一致。“小程序短剧”“视频号剧集”按当前查看账号×来源展示挂载目录，默认只看可挂载。线上页签可以浏览其他来源，勾选时必须与本次挂载方式一致；插件从现有剧集选择，不要求在线挂载编号。
4. 小程序／视频号任务要求每个账号都有可用的对应挂载资料。多个候选时在任务清单逐条选择，不把一个账号的权限套给其他账号。
5. 计划日期直接按设置中的日期偏移带出，支持统一日期与逐条调整。只保存`YYYY-MM-DD`，没有“暂不设置计划日期”开关，也没有制作任务时分设置。历史空日期仍兼容读取；实际发布时刻由自动发布单独设置。
6. 提交失败保留弹窗与已选项。已成功创建的相同任务重复提交不重复创建；同一账号、剧集、开工日已有不同挂载选择的任务时明确报错，不静默改挂载。

## 获取范围和分页

- “获取可挂载”：分页查询该账号当前来源，只为明确`usable=true`的条目自动新建或关联本地剧集。其他条目的平台资料及不可用原因仍保存在目录缓存，可在“获取全部”范围查看，不自动创建本地剧集；当前范围的列表只显示可挂载条目。
- “获取全部”：分页返回的全部有效条目均自动新建或关联，包括明确不可挂载的条目，界面展示原因并禁止选入该来源的制作任务。
- 勾选剧集只决定安排制作任务；入库不依赖勾选。
- 获取作用于当前线上页签；在“现有剧集”页时作用于所选小程序／视频号方式。同次对所选账号逐个查询。
- 后台显示已获取、新建、关联、更新、补封面、当前页及当前目录报告总数。接口可能报告数千部；报告总数不是已获取数或可挂载数，不同账号目录可能重合。
- 短页继续翻页；空页、达到报告总数时结束。重复页、异常或1000页保护上限停止该来源并提示，成功批次保留，后续账号／来源继续。界面默认每页24条，可选24/48/96条，搜索针对已获取的目录。
- 只允许一个目录获取任务同时执行。停止保留已获取资料；重新获取从首页重新核对，靠来源编号去重，不承诺断点页恢复。服务重启不自动重跑获取。
- 网络失败、登录失效、停止、重复页、总数变化、返回条目缺少有效编号/剧名、总数缺失或未获取齐全部目录时，不移除上次已获取条目；已读到的成功批次仍保留。搜索无结果仅改变本次显示。
- 每个账号×来源完整读取且去重后的数量与平台明确报告的总数一致后，将这次目录缺失的旧条目标记为不在当前目录、不可挂载；从线上两个范围和可用候选中隐藏，不删除本地剧集、封面、素材、任务快照或关联资料。明确报告总数0且返回空列表是有效空目录，会隐藏该账号该来源全部旧条目；不完整的空页不执行此操作。
- 可挂载状态与目录在架状态均按账号×来源×外部编号记录，不扩散给其他账号或来源。后来重新返回该编号时恢复在架状态，并按当次可用性重新判定，沿用本地关联。
- “现有剧集”始终展示该剧场全部匹配剧集，包括未获取挂载资料、仅其他账号可挂载和已掉链接但保留在本地的剧。卡片保持可读并标明挂载资料状态；采用小程序/视频号方式时，只有所选全部账号都有对应可用挂载资料的卡片可选，插件无需挂载资料。候选刷新剔除已失效勾选，后端创建任务再次检查在架与可用状态。
- 后台获取任务不阻止选剧和创建：已有或本轮新获取并确认可挂载的剧集均可立即选择、保存。按获取进度变化更新本地剧库、线上目录和挂载候选；候选后台刷新期间继续使用当前账号×来源已确认的有效资料，不全局锁住卡片或保存按钮。正在读取另一页的旧线上结果仍禁止选择；切换账号/来源不套用其他范围的挂载资料。关闭窗口或保存成功不停止后台获取。

## 选剧卡片、分页与封面显示（2026-11-05）

- 选剧区固定4列，采用左侧72×100放大封面、右侧剧名和状态的信息卡片。剧名最多换行显示2行，所有标题统一预留32像素，右侧文字区统一72像素；集数与挂载状态各占16像素，间距4像素，使长短剧名的集数、挂载状态逐行对齐。超长标题截断，悬停查看完整剧名。
- 默认每页24部，可选24/48/96部；当前页全部卡片自然展开，取消剧集区内部滚动，内容较长时使用弹窗主区域滚动。分页栏在全部卡片之后，显示总数及当前条目范围、每页数量选择、前后页、连续数字页码与省略号；当前页高亮，首尾页可直接点击。非空目录按所选每页数量预留整页最小高度，末页不足也保留占位。翻页不卸载原卡片，只在顶部显示读取状态，成功返回后替换，保留主区域滚动位置；越界页自动归到最后一页。
- 改变每页数量回到第1页，前端和目录接口使用相同page_size。读取失败在列表内明确提示原因和“重新读取”，不显示成无匹配结果；获取部分失败也显示“获取未完成，原有目录已保留”，不显示成功勾选。
- 账号/来源/搜索条件不同的旧结果不混入新范围；读取新页期间禁止点击旧线上结果和重复翻页。
- 在任意本地或线上选剧卡片（含不可挂载卡片）上右键一次直接复制完整剧名，只提示复制结果，不弹操作菜单，不改变勾选。
- 全软件共用的剧集封面组件：有有效图片时只显示图片，不再叠加软件生成的剧名文字或原来的文字遮罩；没有图片或图片加载失败时仍显示带剧名的占位。图片换成新地址后可重新尝试加载。不修改封面图片本身或封面编辑器内人工设计的文字。

## 自动新建、关联和差异更新

稳定身份为来源类型与外部挂载编号，本地关联还包含账号所属剧场。先沿用已有关联，再按同剧场的现名、历史名和已关联平台名称进行唯一规范化匹配；均不匹配则新建。存在多个匹配时保留平台条目并提示手动关联，不猜测合并。

原系统的本地剧名全局唯一规则保留。其他剧场已有同名剧时，新建名称附本剧场名，必要时再加序号，避免中断批量获取；原有记录、目录及历史名不改动。平台挂载名保持原值，不受本地名称后缀影响。平台名称含Windows路径非法字符时，仅新建的本地名称清理非法字符。

每次成功获取比较返回的平台字段，有变化才更新。未返回或为空值的字段不作为删除旧资料的指令。相同剧集允许多个平台挂载对象，两个来源均完整保留。平台字段在资料中心的剧集资料库“平台挂载资料”区域展示。

| 字段 | 规则 |
|---|---|
| `name` | 对应来源的挂载剧名，本地当前名不随平台刷新改名 |
| `mediaCount` | 官方总集数；与本地原片文件数分开。不同来源有差异时分别展示，不选一个来回覆盖 |
| `coverUrl` | 保存来源地址；仅补齐缺失原始封面 |
| `miniAppName`、`miniAppIconUrl` | 保存小程序／平台名称和图标，例如绿泡泡短剧，暂不派生其他业务行为 |
| `srcMiniAppName`、`srcMiniAppIconUrl` | 保留接口实际返回的原始平台信息 |
| `questFlag` | 保留原值，业务含义尚未确认，不解释为权限或类型 |
| `usable`、`unusableReason` | 按账号、来源、外部编号分别保存；不把不可挂载状态扩散给其他账号 |
| 最近获取／资料更新时间 | 可用状态每次成功获取刷新；平台资料仅内容变化才更新 |

## 封面和账号头像

没有封面的剧集自动下载平台图片并设为剧集原始封面，小图也先使用，用户后续可手动替换。已有原始封面、花字修改版、选用版本和羊头独立设置均不覆盖。首次尚无羊头原图和修改版时，从剧集原图初始化羊头原图，继续遵循[封面花字与双封面](封面花字与双封面.md)。

下载前与落盘提交前两次检查是否仍为空；人工替换优先。下载失败只影响该图，下次获取重试；不阻止剧集资料入库。按图片实际内容解码，限制20MB及像素尺寸，不只相信HTTP类型或文件后缀。并发下载最多4张，不下载原片或剧情视频。

账号按平台UID匹配本地账号。同步所有本地可匹配的小V头像，下载后本地缓存，在资料中心、安排弹窗及生产任务卡使用；头像地址变化时更新，缺失或失败保留旧头像，再失败用姓名首字回退。昵称、剧场、报白信息、分成与业务状态不随头像同步改动。账号头像在生产任务卡、安排弹窗和资料中心统一采用40×40像素圆形显示，不叠加视频号角标；生产卡片账号名称下方显示账号所属剧场，采用10像素灰色小字，长名称省略、悬停看全，无归属时隐藏；名称与剧场组成文本区，与头像及状态居中对齐。资料中心将账号昵称与平台ID作为同一文本区放在头像右侧，ID为昵称下方的单行小字，不另起到头像下方，过长省略并可悬停查看。

## 自动发布接续约定

2026-10-26发布来源适配已完成隔离验收：94项发布/目录后端、79项前端及6组真实HTTP/界面检查通过。默认带入、具体ID保留、切换/重开/切回、两类参数与插件无原生组件路径均验证；小V猫客户端为测试夹具，未新增真实草稿或发布。实现与边界见[来源带入与切换事项](../../事项档案/2026-10-26-V3自动发布挂载方式带入与切换.md)。

目录与新建任务保存创建时的挂载快照，自动发布按自身当前任务设置解析有效来源。每个新任务保留以下资料：

| 任务字段 | 值及用途 |
|---|---|
| `mount_source` | `mini_drama`小程序、`channels_drama`视频号、`plugin`插件；旧任务为空，沿用旧行为 |
| `mount_external_id` | 本次选择的具体挂载编号，插件为空 |
| `mount_snapshot` | 创建任务时平台资料的副本；目录刷新不改已有任务快照 |

数据存储在`v3_catalog_task_mounts`，任务摘要／详情响应包含上述字段。自动发布接入时应读取它们，从对应账号和来源重新获取、核对完整候选，再构造挂载参数；任务快照用于保留创建时的选择，不能代替发布前的账号资格验证。

另一事项已完成两类本地草稿参数验证，详见[小程序与视频号挂载参数验证](../../事项档案/2026-10-26-V3小程序与视频号挂载参数验证.md)：小程序外层`CAT_extReading.type=5`、内部`component.type=4`，同时保留`urlType=12`；视频号内外类型均为8。小程序外层与内部类型不同，不能统一写5。插件方式仍由自动发布流程定义，不能猜测映射为5或8。参数验证成功不代表当前业务发布器已经支持这些来源，也不代表实际发布成功。

自动发布来源适配代码现已由另一会话接入：当前发布设置的`mount_source`优先，其次使用新建任务的来源快照，旧任务无记录时兼容视频号方式。发布工作台可切换来源并保存到本任务发布设置；创建时的快照不因此被改写。小程序和视频号按来源分别查询与构造挂载参数，插件仅生成不附加原生短剧挂载的本地草稿，具体插件处理及真实发布另行验收。

`server.drama_catalog.guard_legacy_drafts`现已改为校验有效来源，由发布器验证按类型保存的挂载关联，不再使用目录接入初期对小程序／插件一律拦截的旧规则。相关实现见`server/publishing/mounting.py`、`server/publishing/service.py`与`src/components/production/PublishingWorkbench.tsx`。本次文档核对确认代码已有适配，不代替另一事项的最终检查、真实插件运行或实际发布验收。

结构版本7只增补五张目录／头像／任务挂载表，保留原有业务表结构。源码启动时增量建表，不批量改写旧剧集、账号、任务、封面或原素材。
