# 任务中心

> 一个弹窗：在一个地方看**三个执行器在干什么**，以及**每部剧做到哪一步**；顺序可以手动调。
> **他会这么说**：「任务中心」「优先级」「排序」「置顶」「执行器」「队列暂停」「今天做哪部先」
> 最后核对：2026-09-19 ｜ 状态：已整理

## 一、它做什么

- 它是**弹窗**（不是页签），从顶部状态区的入口打开：「展开全局任务中心」。
- 列表按 **账号 × 剧集** 分组：一部剧一个**组头**，组头下面才是它的每条素材。
- 组头带 **视频 / 草稿 / 素材** 三个数字和一条三色条，和《生产中心》左侧卡片口径一致。
- **默认全部收起**，一次只展开一个组——9 部剧的组头一眼能看完。

## 二、怎么用

1. **打开**：顶部状态区 →「展开全局任务中心」。
2. **看某部剧的素材**：点它的组头展开（再点收起）。
3. **调顺序**：组头右侧的 **置顶 / 🔼上移 / 🔽下移**（已做完的剧不显示这三个按钮）。
4. **暂停整个队列**：头部「暂停执行队列」/「恢复执行队列」——**只停止领取新任务，正在执行的不中断**。
5. **暂停单个执行器**：执行器卡片上的按钮；「错误暂停」时点它 = 启动并**清除连续失败计数**。
6. **对某一条素材动手**：鼠标悬停在该行，才会出现动作按钮（重新生成 / 重新导出 / 重试 / 诊断 / 文件路径）。

## 三、业务规则

### 显示哪些剧

显示范围＝**已开工的剧**（有模板任务、或有成片记录的）。

### 顺序怎么排（唯一规则）

```
1. 已做完的整部剧 → 沉到最后
2. 手动调过的 → 按手动位次，从小到大
3. 没调过的 → 计划发布时间早的在前；同一天则开工早的在前
```

组内素材按**序号升序**。

### 手动调整 = 最高调度优先

置顶/上移/下移**不是只改界面**：三个执行器（模板、成片、导出）真的按这个顺序取任务。
点「置顶」时按钮上的说明就是："让三个执行器下一个就做这部剧"。

- 手动调整只在**未完成的剧**之间进行；对已完成的剧点置顶会明确报错（已完成的会自动沉到最后）。

### 组头三个数字

- **绿** = 视频已导出，**蓝** = 草稿已生成未导出，**灰底** = 素材总数。
- 还没扫描的新素材**不计入分母**，另外单独标「新素材 +N」。
- 异常数量**单独显示**，不混进正常进度。

### 执行器卡片

每个执行器显示当前状态：待机就绪 / 排队等待 / 正在执行 / 正在暂停 / 人工暂停 / 错误暂停。
点按钮可以暂停或恢复：

- 「正在执行」时点暂停 → **当前任务结束后**才生效。
- 「错误暂停」时点启动 → 恢复并**清除连续失败计数**。

### 头部

- 显示已完成的数量；有孤儿记录时，顶部会出现橙色提醒条（可一键清除）。

## 四、可调参数

没有需要在这里调的参数——队列暂停、执行器暂停都是**操作**，不是配置项。

## 五、改动须知（动这个功能前先看这段）

1. **排序键只有一处**：界面显示的位次与执行器派单用的排序，必须共用同一个排序键常量
   （`server/task_center_service.py` 的 `MANUAL_ORDER_FIRST_SQL`）。各写一套 → 会出现"界面显示第一、实际最后跑"。
2. **手动位次只在"未完成"的单位之间排**：让已完成的参与会导致"点了置顶没反应"。已完成单位收到置顶请求要明确报错。
3. **组头三个数字必须与《生产中心》同口径**，并且**和任务快照在同一次查询里取到**——多查一轮就会出现两处数字对不上。
4. **任务卡查询用 `JOIN production_tasks`**（不是 `LEFT JOIN`）：父任务被删后留下的孤儿记录会自动不出现。
5. **队列暂停只管"领取新任务"**：不要改成中断正在执行的；执行器暂停在"当前任务结束后"生效这条也要保留。
6. **手动位次字段为空 = 从没调过**（`manual_order = 0`）；派单 SQL 要先检测该列是否存在，列还没有的库降级为不排序。
7. **改 DDL 必加 `SCHEMA_VERSION` +1**（见《界面与开发规范》）。

### 改完怎么验

1. **一定先跑**：`tools\一键验证.bat`（`server/tests/test_v2_task_center.py`、`tools/test_manual_order.py`、`tools/test_manual_order_dispatch.py`）。
2. **改排序必须验"执行器真的听"**：在**数据库副本**里造两部都有素材排队等生成的剧，
   先确认执行器做计划早的那部；把它**置顶**后，确认执行器改做它。
3. **改组头数字**：同一时刻打开任务中心和生产中心，两边的「视频 / 草稿 / 素材」必须完全一致。
4. **改前端后实机看**：默认是不是全收起、置顶/上移/下移点下去顺序有没有立刻变、刷新和重启后顺序是否保持。
