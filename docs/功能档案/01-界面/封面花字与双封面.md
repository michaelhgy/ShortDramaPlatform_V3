# 封面花字与双封面

更新：2026-10-26。状态：已正式接入 V3 源码和构建前端；生产中心、业务保存和发布准备选图已联通。

本文是封面功能当前有效规则的统一入口。功能规则修改时更新本文；历史方案、某次排查和当次验证过程保存在事项档案，按本文的当前约定继续开发。

## 已确认产品规则

### 两套封面与卡片显示

每部剧维护“剧集封面”和“羊头封面”两套独立封面。每套保留一张可替换的原图和最多三张可删除的修改版。羊头原图首次从剧集原图复制，以后独立；之后替换剧集原图不自动修改羊头原图。可以主动再次复制。

两套各有一个正在使用的版本。生产中心是否显示第二张，只按羊头当前选用项判断：选用原始封面时只显示一张剧集封面；选用羊头修改版时，在右侧显示羊头当前封面。即使存在自动生成或另存的羊头修改版，只要未选用仍不显示第二张；单独上传的羊头原图同样遵守这一显示规则。隐藏不删除羊头原图或修改版，也不改变发布使用的实际选用路径。查看版本不等于选用。替换本套原图后立即选用新原图，已有修改版保留。删除在用修改版前说明将回到本套原图并隐藏第二张，删除其他修改版不改变选用。

修改版保留生成图片、编辑文字参数和当时的底图，因此替换原图不会破坏旧版继续编辑的基础。达到三张后禁止静默淘汰，可删除后另存，或选中已有修改版通过“保存使用”更新。

### 软件界面中的封面缩略图（2026-11-05）

全软件共用的剧集封面缩略图组件，有有效图片时只展示图片，不再额外叠加缩略剧名或为该文字添加遮罩；没有图片或加载失败时仍显示带剧名的占位。剧名由卡片旁标题、列表字段或悬停提示提供。此规则不修改图片本身，不删除封面编辑器设计的文字，也不移除生产中心的剧集/羊头类型标记与编辑操作提示。

### 自动修改版与保存动作

有原图但没有修改版时，首次进入本套编辑器或在编辑器中上传原图，自动生成并持久保存“修改版1”，打开该版本编辑，默认一段文字“主页看全集”。已存在修改版则复用，不重复创建；新添文字也使用这一默认内容，已有文字不改。自动创建不改变本套正在使用的封面，用户点击“保存使用”后才切换。另一套未进入时不生成修改版。删除最后一个修改版后本次会话停留原图，不立即重新生成；下次进入没有修改版的该套编辑器时重新准备修改版1。

修改版显示“导出封面 / 另存新版 / 保存使用”，保留原有白底、黄色和深色按钮样式。“导出封面”只导出当前画面；“另存新版”总是新增修改版，不改变正在使用项；“保存使用”更新并使用当前修改版，不增加数量。原始封面只管理底图：隐藏文字、花字、模板、对齐、选框提示和删除修改版入口；显示替换原图，羊头原图另显示从剧集原图复制。原图可以导出，未满三版时可另存一个带默认文字的修改版；当前使用其他版本时显示“设为使用”，当前已用原图时隐藏该按钮。没有底图时只显示可用的底图管理操作。修改版隐藏替换和复制原图按钮。“导出透明文字”按钮已移除。保存失败不显示成功，不丢弃当前文字编辑。

### 文字编辑与通用模板

文本框四边、四角共八个调整点可改变宽高，字号单独控制，框过小时按比例缩小文字以容纳内容；文字按实际字形上下居中，也可选靠上/靠下。点击封面空白或“隐藏选框”可看干净画面，点击文字或“显示选框”恢复。另提供文本框在整张封面上的左右/上下居中。

通用模板最多五个，独立于剧集和两种封面保存。模板含文字、花字、排版和源画布尺寸，不包含原图或封面成品。套用时保留目标封面底图，位置和文本框尺寸按目标画幅比例适配，字号按宽高比例中的较小值适配。可继续微调；套用不修改模板本身。满五个不自动覆盖，删除后可继续保存。

### 入口与加载

入口为生产任务标题左侧，保留左键上传/替换原图，右键打开同一编辑弹窗，按点击的图片进入相应页签。只显示一张时，可右键进入羊头页签开始设置。主界面没有原图、图片丢失或不可读时，右键说明原因并提示左键重新选择。计划发布日期位于标题下方、封面右侧，只显示日期；生成耗时紧接着在日期下一行，同属顶部一组，不另放在整排封面下方。

打开时并行读取封面文档、模板和花字列表；准备完成前显示简洁加载提示，不显示未初始化的透明棋盘、默认按钮或空白文字区。已有修改版重开不复制图片、不新增版本、不保存文档。花字列表使用`compact=1`返回按需纹理URL，PNG从已入库定义读取，不改变原存储。打开只加载本封面文字使用的纹理，其余花字点选时加载；纹理URL含内容校验值并允许浏览器复用，花字库变化仍每次读取最新列表，避免过期缓存。

### 软件确认框与 ESC

封面编辑内的放弃修改、删除修改版、删除模板、套用模板、复制原图均为软件风格确认框。ESC取消最上层确认，保留编辑及底层窗口；花字管理内ESC只关闭管理窗，扫描/导入可在后台完成。编辑器无未保存改动时ESC关闭，有改动时先显示软件确认。焦点位于外层弹窗标题/关闭按钮时同样支持ESC。确认框限制Tab焦点在框内，关闭后恢复原焦点。真正关闭浏览器页面时的未保存保护仍由浏览器处理。

## 实现位置

- `src/coverEditor/model.ts`：版本、模板和文本框规则。
- `src/coverEditor/renderer.ts`：Canvas 文字绘制，支持多行、独立宽高、实际字形上下对齐、自动缩小容纳、描边、逐字渐变、多层投影、内嵌色层、旋转和可调透明度的文字底板。
- `src/coverEditor/simpleFlowerStyles.json`：读取本机剪映缓存得到的 15 款纯色/渐变样式，附资源原始预览图和参数 SHA256。原参数完整保留。
- `src/coverEditor/CoverEditorModal.tsx`：正式弹窗，复用已验收的编辑页面与绘制器；正式模式使用软件 API 保存，不依赖浏览器本地存储。
- `tools/cover-editor-preview/`：独立预览、构建和验证工具。`npm run build` 自动生成 `public/cover-editor.html` 并进入正式 `dist`；正式页面不附带测试封面。旧离线试用仍使用浏览器 IndexedDB，与正式业务分开。
- `server/cover_editor.py`：SQLite 封面/模板文档、修订号冲突检查、图片验证和不可变图片文件；兼容既有封面上传与资料中心。
- `server/flower_library.py`：按当前电脑扫描、选择导入、收藏与计次；轻量花字列表和按需纹理图片接口。
- `src/coverEditor/flowerLibraryUI.ts`：每页12款的选择侧栏、每页48款的缓存管理、多选及跨页全选。
- `src/coverEditor/dialog.ts`：软件确认框、ESC取消、焦点限制与恢复。

正式编辑以当前剧集真实封面为底图；独立验证使用隔离数据库与只读复制的封面。源码及正式前端已完成；安装包是否包含本功能以对应发布记录为准。花字读取和羊头显隐涉及后端更新，更新源码后需正常退出并重新打开V3开发版，才能完整生效。

## 正式存储与发布选图

结构版本6提供从既有版本5的增量补表，保留原业务记录；当前版本缺少功能表时，进程初始化也会补齐。任务标题封面使用独立context，不依赖发布设置是否完整。当前运行旧后端时兼容回退原context。原图片存在但界面占位时，先检查接口和表结构，不要求用户重传图片。

业务库新增 `v3_cover_projects` 和 `v3_cover_templates`，旧表不删除、不重建。封面以剧集ID关联，两套及版本共用一份文档；模板是全库共用的独立文档。每次更新检查修订号，过期编辑会提示重新打开，不覆盖其他窗口的新结果。

图片写入 `<数据盘>\剧集资料\_封面编辑\<剧集ID>\images\`，按内容校验值命名并复用；替换、覆盖修改版均不重写旧图片。`history\` 保存变更前文档，删除修改版只移除当前版本引用，不自动清理历史图片。旧封面按需引用，首次替换不会覆盖旧文件。当前剧集选用封面同步回 `drama_profiles.cover_path`，资料中心和原封面读取接口继续可用。

API 位于 `/api/v2/cover-editor/dramas/<ID>` 和 `/api/v2/cover-editor/templates`；图片通过当前文档内的受控资源编号读取，不能提交任意本地文件路径作为封面。

发布工作台新分组默认“使用对应封面”：普通视频读取剧集当前使用封面，文件名 `羊-` 的视频读取羊头当前使用封面。同一组包含两类视频也逐条分流；原有明确选择“不指定”的分组保留其选择。对应文件缺失时按不指定处理，不用另一套图片代替。既有草稿不自动覆盖；改变封面后的新参数继续遵守发布模块的草稿复查规则。

## 花字范围与限制

初始内置15款简单样式。花字区的“管理花字”可扫描本机剪映缓存，勾选后加入V3；不自动把全部缓存放进库。缓存页显示预览、名称/编号及“可加入 / 已加入 / 暂不支持”，支持搜索和每页48款。可逐项多选、“选择本页”、“全选可加入项”及“取消选择”；全选遵守当前搜索和筛选、跨越分页，跳过已加入或不兼容项。批量添加按100款分批，失败时保留未完成勾选。

统一读取TextStyle纯色、渐变及纹理参数；纹理按range的1至6个水平分格逐字取图，统一处理缩放、旋转、翻转、透明度、颜色混合、窄描边和宽装饰图层。实现不以花字名称、编号或本机路径分支。样例逐款出图用于验证通用实现，不维护单款修复列表。依赖剪映专用特效引擎、缺图或参数格式不兼容的款式显示原因并禁止勾选。没有名称元数据的真实缓存使用“缓存花字＋编号”，仍可按预览选择。

自动查找读取当前电脑的自定义缓存目录、V3剪映用户目录/草稿目录/程序路径及当前Windows用户的LOCALAPPDATA/APPDATA默认位置。可手动选择用户目录、Cache或artistEffect目录，并记在当前电脑的本地配置文件 `LOCALAPPDATA/ShortDramaPlatform/flower-cache-source.json`；不把这台电脑的路径作为其他电脑必须使用的路径。配置路径失效时忽略并继续自动查找。没有找到时说明原因，不自动下载或启动剪映。

重新扫描以实际文件为准，不依赖历史清单的缓存标记；同一编号优先取最新可用缓存包。读取剪映资源及rp.db时只读，重复导入不产生重复编号。导入将绘制参数、预览图和实际纹理PNG复制到业务库，之后剪映清缓存不影响已导入款式。“我的花字”可移出列表或重新加入，保留旧封面、模板所需样式定义。当前文字需要的纹理先加载完成再绘制及导出，点选另一款时仅加载该款，加载完成前暂缓保存/导出；切换版本会取消过期的样式选择。只读缓存并检查文件位于所选资源包内，单图限制10MB、1600万像素，入库PNG最长边1024。

花字区支持名称/编号搜索、收藏、最近使用和使用最多。侧栏每页12款，仅创建当前页卡片，上一页/下一页切换；搜索整个花字库，搜索或筛选变化回到第一页，各筛选结果也分页。此分页独立于缓存管理的每页48款，不改变缓存跨页全选范围。收藏与次数在业务库保存，全剧共用。成功保存新增/更新修改版、成功生成导出图片时计次；同次操作同款仅一次，预览点击、扫描、收藏和单纯切换已有选用不计次，重复事件不重复计数。次数从本功能接入后开始累计，不反推历史操作。独立离线预览可收藏，但扫描和正式计次需在V3软件内使用。

当前独立绘制使用系统微软雅黑；描边距离、投影距离及模糊量按字号换算，内嵌色层按资源预览校正。已验证本地输出，未在剪映生成相同文字作逐像素对照，因此不承诺与剪映完全相同。预设缩略图是剪映资源预览，实际大字由当前绘制器生成。

2026-10-26最新本机实际扫描识别172款缓存花字，其中85款可导入；85款均通过同一绘制器实际生成非空文字图片。金属、红黄纹理、火焰及纸张样例已查看出图，封面保存、导出和重新打开通过。数量随每台机器的缓存变化，不是固定支持编号清单。不同用户/盘符/草稿与安装路径已用隔离目录验证，其他电脑实机扫描仍待用户验证。独立绘制并非直接运行剪映引擎，装饰位置等细节不承诺与剪映完全一致。

每张封面最多六段文字、每段输入最多 120 字符，上传图片不超过20MB、2400万像素且边长不超过8192。正式弹窗保留预览版布局与样式，较小窗口内部滚动。保存中阻止重复保存、切换或关闭，失败时保留编辑内容。

```powershell
cd D:\ShortDramaPlatform_V3
python -B tools/cover-editor-preview/extract_styles.py
node tools/cover-editor-preview/build.cjs local-test-output/cover-editor-preview-20261026 "D:\短剧推广运营系统\剧集资料\一口铁锅走天下\封面\一口铁锅走天下-封面.jpeg"

```
