## 1. 一句话理解算法

抖音 2025-04 公开算法时说了句最本质的话【官方】：

> 推荐算法**几乎不依赖对内容和用户打标签**，而是通过神经网络计算预估用户行为……
> 其本质是数学模型的运算过程，只是在建立用户行为与内容特征之间的**数学统计关联，而非理解内容本身**。

**机器没有"看懂"你的短剧。** 它不知道这是霸总还是复仇，它只算出一个数：
"把这条推给这个人，他看完的概率是多少。"

→ **不存在"好视频"，只有"对这个人是好视频"。**
同一条素材，推给 A 是爆款，推给 B 是垃圾。所以"这条明明很好却没量"的真相通常是：
**不是内容不行，是机器没找到对的人群。**

## 2. 天量怎么才算得过来：筛漏斗，不是全量比较

【行业】腾讯技术团队公开的视频推荐架构（⚠️ **写的是腾讯看点体系，不是视频号内部实现**，仅作通行做法参考）：

| 层级 | 干什么 | 量级 | 大白话比喻 |
|---|---|---|---|
| **召回** | 从全站库里粗捞 | 千万级 → **数千条** | HR 从 1000 万份简历里按条件捞 3000 份 |
| **粗排** | 快速打个粗分 | 数千 → **数百条** | 30 秒扫一遍，淘汰大部分 |
| **精排** | 一条条算细账 | 数百 → **几十条** | 仔细面试，算得准但很贵 |
| **重排** | 打散、去重、加规则 | 几十 → **最终 10+ 条** | 老板拍板：别连着推 5 个同类型的 |

**几千万条视频从来没有被"挨个判断"过**，每一关都砍掉 90%~99%。

那为什么砍得这么快？【行业】+【推断】三个诀窍：

1. **不算全量算候选** —— 召回是**查索引**，不是遍历。像查字典你不会从第一页翻。
2. **提前算好** —— 视频上传时"特征档案"就离线算完了（画面、声音、作者、历史表现）。用户来的时候机器只做**最后一道选择题**，不是从头考试。
3. **重度缓存** —— 腾讯那篇写的多级缓存命中率 **95%+**，真正打到数据库的请求只有 **5%**。

> 另有【行业】数据：用户行为流水**每天上百亿条**，用 1 分钟滚动窗口聚合后再回写。
> → 这就是"实时反馈"为什么能快：不是每条都精算，是先聚合。

## 3. 打分到底看什么

抖音公开的公式【官方】，简单到反直觉：

> **综合预测用户行为概率 × 行为价值权重 = 视频推荐优先级**

两层：

- **预测概率** = 机器猜你会不会看完 / 点赞 / 转发（这是"猜"，不是"评价"）
- **行为价值权重** = 不同行为，平台给的分量**完全不同**。**转发 > 评论 > 点赞 > 完播**（转发能带来新用户）

抖音还加了组合目标【官方】：**收藏+复访、关注+追更、打开+搜索**，以及**原创性目标**。
→ 意思是：**看长期行为，不看一次性点击**；同质化内容会因"原创性目标"被压权重。

## 4. 新视频怎么"插队"：冷启动与小流量试探

新视频零数据，机器凭什么判断？靠**小流量试探**（业内叫"流量池"）【行业+推断】：

```
先给 200 次曝光 → 看数据 → 好，加到 2000 → 再好，加到 2 万 → 数据崩了，停
```

**⚠️ 这里有一个用户一定会踩的坑，微信官方原话【官方】：**

> **发表频次**：建议保持稳定的发表频次，频次不建议过高，
> **如果一个账号每天所发布的内容量异常过多会影响推荐分发**

**为什么**【推断】：每次试探 = 一次"考试机会"。一个号一天发 50 条，
等于 50 个考生抢同一间考场的座位，每条都拿不到足够曝光去证明自己，**最后一锅端**。
→ 这跟"多发就多机会"的直觉**是反的**。

## 5. 视频号真正特殊的地方：社交链是第二台引擎

微信珊瑚安全 2025-04-02 公布的视频号算法推荐原理【官方】：

| 官方明说的 | 含义 |
|---|---|
| 视频号**"主要依靠社交好友关系来进行推荐"** | 社交链是独立于个性化推荐的一条分发通道 |
| 有独立的 **"朋友❤️"** 标签页 | 好友赞过的内容有专门入口 |
| **"当某一内容被多位好友推荐时，其曝光优先级显著提升"** | 20 个好友点赞 → 排序实打实往上抬 |
| 有 **"朋友今天都在看"** 入口 | 社交圈热门单独展示 |
| 可**关闭个性化推荐**（关闭后仅按内容热度 + 社交关系展示） | 反过来看：正常状态 = 个性化 + 社交 + 热度【推断】 |

**⚠️ 注意分寸**：官方这句"主要依靠社交好友关系"是**面向普通用户的通俗解释**，
**不是技术白皮书**。视频号显然也有强大的个性化推荐（否则不会有人停留）。
**不要把公示话术当成权重表。**

**对用户业务的意义**【推断】：在抖音只能靠内容硬拼算法；在视频号多一条**熟人信任链**。
社群、朋友圈、企业微信在视频号里不是"站外引流"，而是**算法的一部分**。

## 7. 推广方视角的官方规则

> 来源：微信官方《微信小程序短剧 CPS 合作》。
> ❓ **但用户走的是不是这条路，见 §8 —— 先别当结论用。**

### 7.1 推广者怎么参与（官方写的路径）【官方】

```
发现页 → 视频号 → 我的 → 创作者中心 → 视频变现任务 → 短剧 tab
→ 选短剧任务 → 发表视频 → 获得现金收益
```

**参与门槛（官方原文）**：**满足有效关注人数 1000 及以上，并持续发表优质原创内容**。

### 7.2 钱怎么算【官方】

| 项 | 官方规则 |
|---|---|
| 分成结构 | 版权方 : 推广者 : 平台 = **30% : 60% : 10%**（默认推广者 60%） |
| 可调范围 | 版权方设置，**最低 60%，最高 70%** |
| **佣金归属** | **Last Click —— 记给"最新的一个推广者"** |
| **绑定窗口** | **7 天**。期内该用户消费都算这个推广者；7 天后解绑 |
| 换绑规则 | **7 天内该用户被新的推广者推广 → 绑定关系换给新的推广者** |
| **官方硬要求** | **"系统应记录每个用户-推广者绑定的起始时间和结束时间"** |
| 结算 | **T+3**；T+3 内支持线上退款 |
| 计划有效期 | 任务生效后 **1 年**；取消后 **T+7** 下线、链接失效 |

**Last Click + 7 天窗口这两条最要命**【推断】：
你辛苦引来的用户，7 天内被另一个推广者碰了一次，**佣金就归别人了**。
反过来，你也可以"截胡"别人的用户。**这是机制，不是道德问题，但要知道自己在什么局里。**

### 7.3 归因三件套【官方】

| 维度 | 参数 | 从哪取 |
|---|---|---|
| 账号归因 | `wxFinderId` | 视频号助手 → 首页 → 视频号 ID |
| 内容归因 | `wxExportId` | 视频号助手 → 对应视频 → 分享 → 复制视频 ID |
| 加热订单归因 | `wxPromotionId` | 加热平台 → 订单列表 → 加热详情 → 订单号 |

其他【官方】：视频号访问场景值 = **1296**；CPS 场景参数 `wxSourceType=finderCps`。

### 7.4 自营账号挂载的另一套规则（**版权方那条路，仅供对照**）【官方】

同一份官方体系里，**"短剧组件挂载"是给自营账号（版权方自己的号）的**：

- 短剧小程序管理员最多授权给 **50 个**视频号账号
- 30 天内最多解绑/新绑 **15 个**；365 天内最多各 **50 个**
- 自然流量成交：**视频号额外抽 10% 佣金** + 开放平台 10% 技术服务费；**加热带来的不抽佣**
- 归因窗口 **7 天**
- 男/女频建议**分账号分题材**；账号要"状态正常、观众画像清晰、自然流量稳定"
- 内容硬性要求：**无水印、无箭头引导**；"影视效果请勿模仿"别贴边
- 官方原话：**"达人合作请使用 CPS 任务能力"**（即：达人**不该**走自营挂载这条路）

## 11. 判重与原创判定机制（2026-09-18 补充）

### 11.1 先分清两种"指纹"

| | 文件指纹 | **内容指纹**（判重用的是这个） |
|---|---|---|
| 算法 | 对文件全部字节做 MD5 | 对**画面结构**算感知哈希 |
| 改 1 个字节 | **全变了** | 几乎不变 |
| 平台用途 | 秒传、同文件识别 | **判重、判搬运** |

### 11.2 内容指纹怎么算（【行业通用技术】，**不是视频号内部实现**）

```
① 抽帧      不逐帧看，每秒抽 1 帧 / 抽关键帧
② 缩图      压成 8×8 / 16×16 小图（丢掉细节，只留大结构）
③ 转数字    算明暗分布 → 一串 0/1（64 位 / 256 位）
④ 比距离    两条视频指纹串的"汉明距离"（数几个位置不同）
⑤ 判相似    差异小于阈值 → 判定为同一内容
```

**音频另有一套独立指纹**（原理同"听歌识曲"）。
→ **画面改了、声音没改 → 音频指纹照样命中。**

### 11.3 关键特性：它看"结构"，不看"像素"

| 改动 | 指纹变了吗 |
|---|---|
| 分辨率 / 码率 | ❌ 几乎不变 |
| 滤镜 / 调色 | ❌ 几乎不变 |
| 边框 / 水印 / 文字 | ❌ 几乎不变 |
| 裁边 / 轻微变速 | ⚠️ 部分变化 |
| **画面主体换掉** | ✅ 才真的变了 |

→ **"加个边框改个水印就能躲过去"= 错觉。**

### 11.4 三代演进：一代比一代难躲

| 代 | 技术 | 加 3 秒片头能绕过吗 |
|---|---|---|
| 第一代 | 全局哈希（整条视频一个指纹） | ✅ 当年有用 |
| 第二代 | **分段指纹 / 局部敏感哈希（LSH）** | ❌ 没用（**只匹配片段**，加片头不影响中段） |
| 第三代 | **深度特征 embedding**（映射到语义向量空间） | ❌❌ 改包装**彻底失效** |

**第三代是关键**：不再比对像素，而是看**高层结构**（内容类型、节奏、像不像）。
到这一步，"改包装躲检测"在原理上就断了。

> ❓ **视频号具体用哪一代，无人公开，AI 不知道。** 以上是行业公开技术演进。

### 11.5 ⚠️ 为什么"对抗指纹"是死路（四条）

1. **军备竞赛必输** —— 对面是团队 + 算力，手动剪追不上；一次模型更新就废。
2. **第三代技术上，改包装直接无效** —— 见 11.3 / 11.4。
3. **⚠️ 最硬的一条：视频号官方已把"技术手段规避"列为打击对象**（见 §12.1），处置含**封禁**。
4. **就算躲过判重，也拿不到流量** —— 流量最终由**用户行为**（完播率、停留时长）决定；
   一条观众看腻的内容，躲过判重照样完播率崩盘。

### 11.6 ⚠️ 与本项目直接相关的一条确认事实（**新**）

**✅ 2026-09-18 用户确认**：成片里那 6 张「2×3 排布、透明度 0.02、肉眼几乎看不见」的真人图片，
**用途是规避平台检测 / 防搬运**（此前 `docs/业务全景.md` §6 只记了做法，没记用途）。

**AI 不做评判，只把账算清楚：**

## 12. 平台治理红线与官方正路

### 12.1 ⚠️ 微信视频号《关于打击短剧黑灰产行为的公告》（2026-03-18）【官方 · **直接适用**】

**重点打击的行为（官方原文）：**

> 1. **通过人工方式或技术手段规避平台风控规则**，恶意刷单、刷量、刷粉，获取不正当流量、收益等行为
> 2. 扰乱平台计费结算秩序的行为：利用非法手段规避平台安全策略，套取平台激励、扰乱平台计费结算秩序的行为
> 3. 发布色情、低俗、盗版等不符合平台生态规范的行为

**处置措施（官方原文）：**

> - 扣除该主体的**非法收益**
> - **关闭、限制机构上传视频的能力**
> - **封禁机构及相关账号**
> - **限制剧目传播**等

**该公告已公布封禁案例**（多个机构与账号，含剧目下架）。

### 12.2 抖音体系的两份公告（**不直接适用**，行业风向参考）

> ⚠️ **用户 2026-09-18 明确："只做视频号"** → 以下两份**不直接约束**用户。
> 但**方向与视频号一致**，且用户若将来扩平台，这两份就是直接条文。

**A. 抖音短剧版权中心《关于内容原创度建议的公告》（2026-03-13）** —— 四类将被治理：

| # | 原文 |
|---|---|
| 1 | 同一部短剧/漫剧在**多个账号重复发布**（属违约行为） |
| 2 | **相同或相似素材**在多个账号重复发布 |
| 3 | 搬运/抄袭；带他人水印或**用马赛克等方式遮挡**；转载他人作品**即使获得原作者或版权方授权** |
| 4 | 外站非本人素材，直接发布或**简单加工（加特效、转场、配乐、文字、一句话解说等）后发布** |

**B. 巨量星图《关于打击违规短剧的公告》（2025-05-15）**：
- 不得"完整使用或**仅进行简单加工**发布，如仅添加水印/文字、更换滤镜、**局部模糊处理**、AI更换配音等"
- 处置：**下架违规剧集、账号权限管控**

> DataEye 解读（第三方，非官方）："用规则倒逼短剧行业从'**流量铺量**'向'**原创精品**'转型。"

### 12.3 ✅ 官方给的正路（**这才是答案**）

**巨量星图公告的最后一句【官方】：**

> 平台**鼓励提升内容原创度**，**语音解说、真人出镜**以及其他内容原创度高、
> 形式创新的二创短剧视频**有机会获得更多流量激励**。

**微信官方这边是同一个方向【官方】：**
- 《短剧组件发表指引》："原创：发布原创视频，记得使用**声明原创**功能"
- 视频号原创能力：开启原创声明可"**享受平台保护和优先推荐**"
- **允许**用剧集素材：官方原话"可用**短剧高潮片段或混剪素材**"

**→ 三条合起来的意思**：官方**允许**你用短剧片段，**鼓励**你有原创增量，
**反对**的只是"仅仅加特效/配乐/文字的简单加工"。

**心法一句话：**

> **不要问"怎么剪得跟原片不一样"，要问"这条视频里，有哪一部分是我自己的"。**

| ❌ 官方点名的"简单加工" | ✅ 官方明说能拿激励的 |
|---|---|
| 只是加特效、转场、配乐 | **语音解说**（你自己的声音） |
| 只是加字幕文字 | **真人出镜**（你的脸） |
| 只是换滤镜、调色 | 你的**观点与点评** |
| 只是把镜头重新排列 | **重新组织叙事**（重新起承转合） |
| 加遮挡 / 马赛克 / 局部模糊 | 系列化追更（同一部剧做成栏目） |

## 13. ⚠️ 国家法规：《微短剧发展管理办法》——**已于 2026-09-01 施行**

> **国家广播电视总局令第 16 号**，2026-07-30 公布，**自 2026-09-01 起施行**。
> 来源：https://www.nrta.gov.cn/art/2026/7/31/art_113_73785.html
>
> ⚠️ **这不是平台规则，是国家法规。**
> 用户"做短剧推广" = 法规里明确出现的"**推广者**"。

### 13.1 把"推广者"列为监管主体的条款【法规原文】

| 条 | 原文要点 |
|---|---|
| **第三十八条** | 播出单位应对内容提供者和**推广者**执行本办法情况开展**常态化巡查**，建立**分级管理制度和退出机制** |
| **第四十一条** | 微短剧**创作、推广、播出单位**应配合广播电视主管部门监督管理 |
| **第四十二条** | **创作、推广、播出单位**应组织所属从业人员培训 |
| **第四十三条** | **创作、推广、播出单位**应依法配合统计调查 |
| **第四十五条** | 违反本办法，制作、**推广**、播出含禁止内容的 → 责令改正、**可要求暂停节目内容更新**，情节严重依法处罚 |
| 第十条 | 与微短剧有关的知识产权受法律保护，**任何组织和个人不得侵犯** |
| 第三条 | 应当**尊重原创，保护著作权，公平竞争**，规范发展 |

### 13.2 ⚠️ 第二十八条 —— 与用户现有做法**直接相关**
