## 0. 一句话说明：这些插件和短剧业务无关

DSH 是**你和我对话用的工具（AI 助手界面）**，不是短剧推广软件。
本文件里的插件只改**这个对话界面**（加面板、加余额挂件）。

**它们不碰 `D:\ShortDramaPlatform_V2` 的任何业务代码、数据库、生产数据。**
如果哪天你发现短剧软件出问题，**先排除这里，99% 不是它造成的。**

## 3. 日常操作命令

DSH 是本地源码版，没有全局 `dsh` 命令，所以命令要写全。**在 `C:\Users\Michael\deepseek-harness` 目录下执行**：

```powershell
# 看当前装了哪些插件、版本是多少
node --import tsx/esm apps/cli/src/bin.ts plugin --profile web list

# 卸载 dsh-dock（卸完要重启 dsh web 才生效）
node --import tsx/esm apps/cli/src/bin.ts plugin --profile web remove dsh-dock

# 重新装上
node --import tsx/esm apps/cli/src/bin.ts plugin --profile web add dsh-dock

# 检查合成配置里插件有没有真的挂上（找 dsh-dock / dsh-whale-widget 两行）
node --import tsx/esm apps/cli/src/bin.ts web --dump-config
```

**重要**：插件分"宿主半部"和"浏览器半部"。改完插件**必须重启 dsh web**，只刷新浏览器不够。

**重启方法**（现成的脚本，会自动等 15 秒让你当前的对话结束）：
`C:\Users\Michael\.dsh\restart-dsh-web.ps1`

## 4. 安全边界（重点看）

### 远程访问 —— 默认关闭，别随手开

dsh 默认**只监听 `127.0.0.1`**（只有本机能访问）。「远程访问」一旦开启，会让 dsh 额外监听 `0.0.0.0`（**局域网里任何设备都能连**），靠账号密码拦截。

- 2026-09-19 安装后已实测：**没有出现 `0.0.0.0:8081` 监听**，仍是 `127.0.0.1:8080`。✅
- 要用手机连，先想清楚：这台电脑所在网络里有谁？密码强度够不够？

### 钉钉 / 飞书推送 —— 消息会离开本机

填 Webhook 后，任务完成/异常的消息会**由 dsh 直接发到群里**（浏览器关着也发）。**Webhook 地址等于一把钥匙**，填了就等于允许发消息，不要外传。

### 图片理解代理 —— 唯一会额外花钱的功能

默认关闭。开启后每次识图按所选视觉模型的价计费。

### 网络访问 —— 插件会主动联网

2026-09-19 日志显示：`dsh-dock` 启动时会去抓 `api-docs.deepseek.com` 的价目页（用于估算费用）。**这是它联网的已知行为，不是异常**。

## 6. 已知毛病（不影响使用，但要知道）

1. **费用估算不准 / 官网价抓取失败**
   2026-09-19 日志：`tokenlog parsed 0 models from pricing page — check page structure, using defaults`
   意思是：它去抓 DeepSeek 官网价目页**没解析出价格**（人家页面结构变了），于是**退回内置默认价**。它会扫描到本机 2562 条历史调用记录。
   **对策**：在「用量记录 → 单价设置」里**手动填你的真实单价**（人民币元/百万 tokens），填完立刻重算，不依赖官网抓取。

2. **小鲸鱼插件的本地改动会被升级覆盖** ⚠️
   `dsh-whale-widget` 被**手工改过**（让余额气泡常驻，不 5 秒自动消失），改动说明在
   `C:\Users\Michael\.dsh\whale-widget-本地修改说明.md`，原始文件备份在同目录的 `.orig-backup`。
   **一旦这个插件升级或被重装，改动会丢**，要按那份说明重新改（说明里有"插件升级后怎么重做"一节）。

3. **插件有本地改动时，不要用 `pnpm update` 一把梭**
   会同时升级两个插件并冲掉小鲸鱼的改动。要升级就一个一个来，升完检查小鲸鱼是否还在。

## 7. 出问题怎么办（决策树）

**症状：刷新浏览器后 dsh 界面打不开（8080 连不上）**

1. 先看日志判断是"装成功"还是"回滚了"：
   ```powershell
   Get-Content C:\Users\Michael\.dsh\install-dsh-dock.log -Tail 20
   ```
   - 看到 `SUCCESS` → 装好了，GUI 起不来是别的原因
   - 看到 `ROLLBACK OK` → 已自动退回装之前的状态，插件没装成
   - 看到 `ROLLBACK FAILED` → **找我**（这是需要人工介入的情况）
2. 手动重启一次：双击/运行 `C:\Users\Michael\.dsh\restart-dsh-web.ps1`
3. 还不行，就手动卸载插件再重启：
   ```powershell
   cd C:\Users\Michael\deepseek-harness
   node --import tsx/esm apps/cli/src/bin.ts plugin --profile web remove dsh-dock
   ```
   然后跑 `restart-dsh-web.ps1`。

**症状：功能坞按钮不见了 / 面板空白**

- 先**重启 dsh web**（不是刷新浏览器）——宿主半部没加载时面板就是空的。
- 再确认配置里有它：`--dump-config` 应输出 `- id: dsh-dock`。
- 还不行告诉我，别自己删文件。
