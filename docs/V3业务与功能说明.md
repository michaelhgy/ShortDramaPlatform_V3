## 1. 这次变化解决什么问题

V2 的主要生产方式是先生成剪映模板草稿，再套素材、生成成片草稿、交给剪映导出。V3 把新模板及成片生产改成 FFmpeg 本地处理：先做好可重复使用的模板效果，再替换每条主素材合成成片。

用户仍在同一个软件里管理账号、剧集、素材、生产和发布。改变的是模板来源、素材管理和视频制作方式。

| 事项 | V2 原流程 | V3 当前流程 |
|---|---|---|
| 模板 | 账号相关的剪映模板草稿 | 独立制作的公共模板，成片任务选用 |
| 风景 | 原资源目录中的视频 | 原始风景先人工或批量裁切，只有入库结果可以抽取 |
| 贴纸、特效 | 剪映资源及其轨道参数 | 随软件携带的单贴纸、特效变化版、动态边条库 |
| 制作成片 | 草稿生成，再剪映导出 | 主素材与已完成模板效果缓存直接合成 |
| 参数 | 旧文案、插片等参数 | 参数中心的“模板生成参数”控制新模板，“成片插片”控制FFmpeg新成片 |
| 进度 | 草稿、导出分阶段 | 风景处理、模板制作、成片合成各自排队和监控 |
| 耗时 | 总耗时、草稿耗时、导出耗时 | 成片显示“生成耗时”，不含排队 |
| 次数 | 容易按成片条数理解 | 风景按成功模板计次；模板按成功使用的剧集计次 |

旧资料、旧成片和兼容代码保留。新 FFmpeg 流程已接入全局、当前账号×剧集、单素材分层控制的中插/尾插，支持短片门槛和位置区间；详见[FFmpeg成片合成](功能档案/02-执行器/FFmpeg成片合成.md)。自动裁头尾、BGM、账号移动文字和固定文字仍未接入。真人图片可通过模板参数中的真人叠层开关参与新模板，按成功模板计次、用满清理；引流视频仍按对应功能的接入范围使用。

## 2. 日常操作顺序

1. **资料中心 → 生产资源 → 原始风景**：放入下载的视频，刷新。预览并选择单条或批量裁切。
2. **可用风景**：检查自动入库的视频。无需改名；这些才会参与新模板随机抽取。
3. **参数中心 → 模板生成参数**：设置时长、抽取条数、使用上限和允许范围。保存影响以后创建的批次，不修改已完成模板。
4. **生产中心 → 模板制作**：填数量并提交。任务中心显示处理进度，成功后自动进入公共模板区域。
5. **生产中心 → 成片制作**：选择账号与剧集，扫描主素材，选择一个公共模板，点击“批量合成”。
6. **成片区域**：成功视频自动显示，可预览、打开目录，继续原有发布管理流程。
7. **发布后的剧集清理**：按现有清理入口删除生产文件及相应任务记录；已经发生的模板使用次数保留。

新电脑首次验收建议先做 1 个短模板和 1 条短素材，确认画面、原声和速度，再开批量任务。电脑性能影响处理速度，不改变随机规则和计次口径。

## 3. 原始风景和可用风景

### 原始风景

原文件名可以任意。原始风景不能直接用于新模板。可以播放、拖动预览、人工删除，也可以选取多个横向画面区域。新建处理任务保留30秒以内整段，长片随机切成15—28秒短片，各段连续覆盖原视频的30fps时间轴。

批量裁切默认竖版三块横向取景，横版保留完整画面，方形沿用一块横向取景。画面区域数与时间段数分别计算，最终输出数量为两者相乘；例如3块取景、3个时间段会生成9份短片。可以统一改为一、二、三份，也可以预览后单独调整某条视频。裁切框必须在画面内、宽大于高；位置和尺寸使用偶数整数像素。批量一次最多提交 200 条原片，每条独立处理，某条失败不阻止其余原片继续。

### 成功后才删除原片

每条原片的所有裁切结果全部完成、解码检查通过、入库并再次核对后，才删除对应原片。结果自动命名为 `风景000001.mp4` 等连续编号，不覆盖已有文件。新任务输出无声、30fps、每份不超过30秒；符合条件的整段横屏直接复制视频流、去声音并保留原分辨率。需要裁切或转码时通常宽度最多1080，按取景比例缩放。竖屏同一时间段多块取景共享解码，不先生成长文件再处理。旧已入库素材和旧排队任务不自动重做；此规则自2026.10.25.3轻量更新及最新源码生效，.2安装版不包含。

失败时保留原片和已验证部分。重试尽量复用已验证结果；若只是删除原片失败，不重新制作全部切片。成功后清除原片与结果的关联，每个入库切片独立管理。

原始风景和可用风景都支持人工删除。等待或运行的任务正在引用时阻止删除。人工删除有确认提示；删除的媒体文件不能通过软件撤销。

### 可用风景的次数

- 一条风景实际排入 **一份成功模板的播放时间轴**（至少1帧），计一次；只播一部分也计一次，抽中但未播到的候选不计次。模板内部反复循环、以后合成多条成片，都不增加该风景次数。
- 排队和运行的模板仅为实际排入时间轴的风景预留额度，未播到的候选不占次数、不因本模板触发用满删除；防止同一批超抽；失败或取消释放预留，不计成功次数。
- 默认每条最多 5 次，可在模板参数里调整。
- 用满后停止抽取；没有等待或运行引用、原片处理事务也完成时，自动删除处理后视频，保留身份及使用账。
- 删除或用满某条风景，不影响已经做完的模板，完成模板有自己的缓存。
- 顶栏风景数量与可用风景列表使用同一口径。未知旧文件不会仅因放进风景目录就自动成为可用素材。

详细规则：[风景素材处理](功能档案/02-执行器/风景素材处理.md)。

## 4. 一份模板由什么组成

从画面看，模板由上下风景、上下贴纸、全屏特效、左右动态边条组成；中间留给主素材。分辨率固定为 **1080×2400，30fps**，当前不开放未经验证的其他规格。

2026-10-25最新源码修复了未播放候选也被预留、计次的问题。旧等待任务自动释放多余预留，历史成功使用账保留；此次修复纳入2026.10.25.2，2026.10.25.1安装包不包含。见[修复记录](事项档案/2026-10-25-V3风景按实际上屏计次修复.md)。

### 上下风景

先从可用库里抽取配置数量的一批风景候选，再分成上下两组。候选数量仍需要相应的可用库存，不保证每条都实际出现。两组不能使用相同素材，每组至少两条；初始总时长不一样，默认差值为较长组的 15%—70%。不要求原素材总时长凑够整条模板。两边各自播放到模板时长就停止，最后一段按剩余帧数截断。例如60秒模板、20条候选，若上下实际只排入6条，只为6条预留和计次，其他14条不占本模板次数。

每组固定成员，每轮重新排列，用多轮凑够模板时长；跨轮也不能同一条紧接自己。最后不足一整段时截断到准确帧数。宽度跟随模板画幅，不单独设置。

一侧使用大区域、一侧使用小区域，随机分给上下。以下为默认建议，可在参数中心自定义：

| 项目 | 默认建议与含义 |
|---|---|
| 大区域高度 | 全画面高度的 28%—33% |
| 小区域高度 | 全画面高度的 20%—25% |
| 蒙版位置 | 各自风景区域高度的 40%—55% |
| 羽化总宽 | 各自风景区域高度的 55%—80% |

上下的蒙版、羽化分别抽取，按实际像素精度取整。羽化0表示硬边。百分比以各自风景区域为基准；建议区间可以超出，基本规则与25项用途见[参数中心](功能档案/01-界面/参数中心.md)。祝福语和引导语旧文案卡已从源码版移除。

### 上下贴纸

当前可用库有 **31 个系列、670 个单素材**。每份新模板先抽系列，再重新抽取 16 个贴纸，上下各 8 个，沿用已确认的排布、动画和透明度规则。允许合理重叠。

全屏淡贴纸叠层另用独立383个素材库，数量及可见程度单独控制；不会与上下装饰贴纸混用。默认上下贴纸整体透明度系数为 80%，它作用在素材本身透明度之上。原有 93 套成品是历史参考，新模板不局限在这 93 套里抽取。每次新模板都重新组合；做好的整套动画只给这份模板及其成片复用。

### 全屏特效

当前库包含 23 种基础特效，共 104 个变化版及提前合成的双特效组合条目。随机性来自类型、变化样式、出现顺序、取样起点、强度以及切换安排，不只是调整透明度。

默认每模板选 3—5 类，单段 30—60 秒，强度为已确认基准的 90%—100%。短模板按实际长度减少段数；120 秒以上按规则安排双特效，默认占时长 15%—30%。能提前合成一层的组合优先。兼容特效交叉淡变，不兼容的经没有全屏特效的底片过渡，默认 1—2 秒。

这是经过查看确认的 FFmpeg 适配素材，不承诺完整复刻剪映内部引擎、人物分割等专用能力。

### 左右边条

当前有 10 段经过裁黑边、整理有效画面及循环衔接的动态纹理。一份模板随机抽一个素材，左右各自随机 5—10 像素宽，从有效画面不同位置取两条。等比缩放、局部取景；保持纹理原速、随机起点。整条模板的边条位置固定，内容持续运动。

详细规则：[FFmpeg 模板制作](功能档案/02-执行器/FFmpeg模板制作.md)。

## 5. 模板为什么还有 MP4 和缓存

用户看到的是一张模板卡片，但一份可用模板包含三部分：

| 文件 | 作用 |
|---|---|
| 模板 MP4 | 播放预览，中间是示意背景 |
| 同名 `.template.json` | 识别这个模板及其完整模板包 |
| `系统数据/tg` 内的模板包 | 保存配方、已经算好的画面、透过比例、必要的特效输入和日志 |

**只有 MP4 不够。** 成片不会把预览里的灰色背景叠到主素材上，而是读取模板包内已经准备好的效果数据。移动模板或换电脑时，不能仅复制 MP4。

模板生成时一次性完成风景、羽化、贴纸动画、特效和边条的固定计算。成片制作时直接复用，不重新随机排布，也不重新逐层制作模板。柔光、颜色变化等与主素材颜色相关的效果仍需做必要的像素混合，但其固定输入已经提前准备。

模板短于主素材时，直接循环这个完整模板周期，最后截断；不为成片长度扩建模板。主素材和原声连续播放，不跟模板循环。

目前预览和成片使用 H.264，目标视频码率约 2500 kbps、峰值 4000 kbps，有声素材编码为 AAC 192 kbps。效果缓存还包含颜色及透过信息，使用压缩的 4:4:4 视频，目标 8 Mbps；缓存体积不能按单个成片体积估算。

GPU 的 NVENC 负责编码，缩放、透明混合等仍有 CPU 工作。显卡总体占用不满不等于没用显卡。当前本机 3 分钟模板的同配方冷制作实测从约 368 秒降至 293 秒；这是 RTX 4080 SUPER 本机特定配方的记录，不是其他电脑的速度承诺。

## 6. 成片制作和模板次数

一个账号×剧集的生产任务统一选一个模板。一条主素材生成一条成片，按原素材编号命名；已有成片不会被覆盖。主素材等比缩放、居中裁取，保持原时长与原声，按 30fps 对齐。

扫描主素材时，普通文件命名为 `剧名-N`，文件名含“羊头”的新文件命名为 `羊-剧名-N`，两类共用数字序号。首次没有有效编号时先普通、后羊头；已有编号时旧名称固定，从最大有效编号后继续，新增先衔接尾部同类，再编另一类，同类不存在则直接编另一类。例如尾部是 `羊-剧名-10`，新文件为 `7.mp4`、`8.mp4`、`羊头.mp4`，就续成 `羊-剧名-11.mp4`、`剧名-12.mp4`、`剧名-13.mp4`，旧1～10不动。已有成片记录时也允许追加，重复扫描稳定。成片区及成片预览直接显示文件名，保留“羊-”和扩展名；已生成文件优先显示实际成片文件名。

模板默认上限为 **20 部剧**。同一部剧使用同一模板，做 1 条或 100 条成片都算一次：该剧第一条成片成功时记账。预览、单纯选中、全部失败、全部取消不计成功次数。排队先预留不同剧集的名额，成功后转为已用。

同剧身份按剧集主档和别名归一；没有主档时按名称身份。删除生产剧集、发布后清理、人工删除模板，都不清除已经发生的成功使用账。同剧重新建立生产卡片，按相同身份继续计数。

达到上限后，新剧不再看到可选卡片；已经使用的同剧可以补做。保留同剧跨账号的模板选用限制。已有成功成片或等待、运行合成任务时，不能直接更换这一生产任务的模板。

刷新模板会排除已缺失或变化的文件，不把旧索引当成仍可用。预览里可人工删除模板；文件及配方移入模板回收目录，保留完成缓存、成片和历史计次。正在被排队或执行成片引用时禁止删除。模板制作记录隐藏已人工删除或预览文件缺失的完成项，但底层历史账保留；用满但文件仍在的模板保留制作历史。

详细规则：[FFmpeg 成片合成](功能档案/02-执行器/FFmpeg成片合成.md)。

## 7. 任务、失败和清理

风景处理、模板制作、成片合成是三类队列，在全局任务中心和任务监控中统一查看，各自暂停、继续。暂停是当前份完成后不再开始下一份；取消等待项不会停止正在执行的 FFmpeg。

进度主要来自实际处理帧数，辅以准备、检查、保存阶段。成片状态显示如“合成中 22%”，完成登记后才到 100%。百分比表示工作进度，不是剩余时间预测。模板预处理和成片复用合成分别记录耗时。

运行时退出软件，执行项会标为中断，保留配方和日志，等待人工重试；等待项按保存的队列状态恢复。重试沿用原配方，不能静默换素材。发现原文件被替换、模板包缺失或缓存不完整会报错，不在成片阶段偷偷重做模板。

受监控的 FFmpeg 命令连续 120 秒没有新增输出帧时，停止该命令并保留现场。该保护没有覆盖所有旧工具和独立贴纸准备步骤，不应把它理解为所有卡住情况都能自动恢复。

删除生产剧集和发布后的清理同时清理关联成片任务及对应过程文件。有等待或运行合成时阻止删除。文件清理失败会保留记录供重试，不显示“删除成功”后仍让任务复活。公共模板、模板缓存及成功计次账不随剧集删除。

## 8. 其他已纳入 V3 的界面和业务调整

- 生产中心增加公共模板卡片与模板制作入口；卡片名称缩短为“模板MMDD-序号”，单行显示，完整名称可悬停查看。
- 资料中心的生产资源改为风景视频、真人图片、引流视频；移除 BGM 界面入口。
- 原始风景和可用风景都有预览、删除入口；顶栏风景数量可点击直达可用风景页。
- 全局任务中心、任务监控小窗和成片区域统一适配 FFmpeg 进度；删除剧集后清理相应任务记录。
- 账号批量导入要求昵称、账号 ID、剧场；其他约定字段可留空，状态空白默认“正常”，中间空列保留，不自动创建“通用剧场”。
- 新增剧场默认分成 40%、税率 6%；已有剧场保存值不被覆盖。
- 收益页面、任务中心等先前修复继续包含在 V3，旧账号、剧集、发布与收益管理没有另建一套。

## 9. 换电脑时什么跟着走

软件发布包携带界面、Python 运行环境、FFmpeg 和贴纸/特效/边条运行库。目标电脑不需要另外安装 Python、Node，也不需要为新 FFmpeg 流程安装剪映。

业务数据库、下载风景、短剧主素材、已生成模板及缓存、成片、账号数据、机器设置不会自动进入软件包，也不会自动同步。新电脑可以独立选择数据盘，从导入原始风景开始使用。

如果要接着使用原电脑的生产记录和模板，需要另行迁移完整业务目录；目前部分记录及模板配方使用绝对路径，不能假定换盘符后会自动修复。迁移前停止相关任务及软件、备份，优先保持相同盘符和目录。仅迁移软件包不是业务数据迁移。

同机 V2/V3 保留共用数据盘和单实例规则，只能轮流运行；V3 安装目录和快捷方式独立，不能据此推断共用数据库可以安全回退为任意旧版本。

安装步骤和本次实测范围：[多机安装与版本管理](7-多机部署现状.md)。
