02 / 首次准备

安装、启动与页面导航

在另一台电脑安装

  1. 复制交付目录。安装版运行 ShortDramaPlatform_V3_3.0.0_Setup_2026.11.03.2.exe，按向导安装；安装位置用于程序，不是业务视频存放位置。
  2. 便携版需完整复制 ShortDramaPlatformV3 文件夹，再运行 ShortDramaPlatformV3.exe；不要只复制 EXE 或漏掉 _internal。
  3. 使用 Windows 10/11 64 位，准备 WebView2 运行环境。新 FFmpeg 制作不需要另外安装 Python、Node 或剪映。推荐有正常 NVIDIA 驱动的电脑，实际速度以目标机短片测试为准。
  4. 打开 V3 后，点右上角齿轮进入设置，确认数据盘，再点“保存所有配置”。业务目录为所选盘的 短剧推广运营系统。
  5. 先完成第一条短片检查。软件安装完成不等于素材、账号和旧模板已经迁入。
更换数据盘不会搬迁数据

程序安装目录与业务目录分开。选了新盘，旧盘文件仍在旧位置。要继续旧任务及历史使用次数，按迁移与备份处理，不能只改盘符或只复制模板 MP4。

几个容易混淆的名称

剧集业务档案
资料中心保存的剧名、别名、所属剧场，是这部剧的身份。
生产任务 / 剧集卡片
某个账号制作某部剧的一次安排，包含主素材和成片。删除该卡片不等于删除剧集业务档案。
原始风景
下载来的未处理视频，名字可以任意，不能直接被新模板抽取。
可用风景
裁切成功、自动编号并入库的视频；仅在成功模板中实际播放才计次，未播到不预留、不计次。
主素材
在生产卡片的“素材目录”里放入的短剧视频；它决定成片内容、时长和原声。
公共模板
已经完成风景、贴纸、特效和边条准备的一套可复用效果；按成功使用的剧集数计次。
缓存 / 模板包
系统保存的已完成效果数据，成片合成需要读取。它属于模板，不能当普通临时垃圾手动清空。

数量或列表暂时没更新

先检查筛选条件、选中的账号剧集和数据盘，再用对应入口刷新：主素材用“扫描素材”，公共模板用“刷新模板”，风景用“刷新风景”。任务会自动更新；出现“任务状态暂未更新”时，屏幕保留的是上一次结果，不要把它当实时进度。顶栏风景数量可直接点击进入可用风景。

03 / 业务准备

维护账号、剧场与剧集

本版新增小V猫“获取账号”：按平台ID预览匹配，已有跳过，待新增可多选并手动关联剧场或在窗口内新建剧场；不会覆盖已有资料。安排任务支持小程序／视频号／插件，按来源获取可挂载或全部剧集并保存选择。

入口：资料中心 → 业务资料 → 对应列表

先建立剧场，再建立账号和剧集

  1. 切到剧场列表，点“新增剧场”，填写名称、默认分成、税率、状态。新建默认分成 40%、税率 6%，应按实际合作条件核对。
  2. 需要细分时再新增子剧场，选择所属剧场，设置是否覆盖分成。没有子剧场就留空，不需要创建“通用剧场”。
  3. 切到账号列表，点“新增账号”，填写昵称、账号 ID、所属剧场、状态；子剧场、报白时间、注册时间和备注可按实际填写。
  4. 切到剧集列表，点“新增剧集”，填写当前剧名、所属剧场，有历史名称时维护别名。之后安排任务应选这个既有档案。
  5. 保存后在列表搜索刚创建的名称，重新打开检查归属和状态。

账号 ID是平台识别账号的字段，不能用昵称代替。安排今天只提供正常账号；“观察、限流、二限、实名、封禁、停用”等状态会影响可安排名单。收益采集则跳过“停用”，两处筛选口径不同。

批量导入账号

  1. 点“批量导入账号”，从 Excel 或表格复制多行数据，粘贴到输入框。
  2. 按下表列顺序组织，推荐使用表格产生的 Tab 分隔。可包含表头。中间字段留空时保留空单元格，不要把后面字段左移。
  3. 点“解析数据”，核对每一行的昵称、账号 ID、剧场、状态与可选字段。解析失败先改输入，再解析。
  4. 确认预览正确后执行导入。重复账号会按后台校验跳过或返回说明；查看导入结果，不按粘贴行数推断新增数量。
列字段要求
1—3账号昵称 / 账号ID / 剧场必填，剧场名称核对已有资料。
4子剧场可空，空值保留。
5状态可空，默认“正常”。
6—8报白时间 / 注册时间 / 备注可空。日期和备注不要串列。

修改、停用、删除业务档案

临时不使用账号或剧场时优先调整状态，保留身份。已有生产任务的账号或剧集会被阻止删除；剧场关联账号或子剧场、子剧场绑定账号时，也不能直接删除。不要为了让删除按钮通过而随意删生产记录。

剧名变化使用剧集的改名入口并核对历史名称；历史别名参与识别，同一部剧不要反复新建档案来替代改名。删除业务档案不是清理成片的入口，生产文件清理去生产中心。

剧集资料库和其他资源如何使用

“剧集资料库”以已建业务档案为基础，选择剧集后可初始化资料库档案、打开原片或封面目录，并上传封面。它与生产任务的“素材目录”是两处：把整剧原片放进资料库，不会自动变成待合成主素材。

本版本的边界

剧情知识库、A+A 生产资料、部分标签与编辑资料入口仍为预留或前端状态；爆款资产的标记、应用到制作尚未形成完整持久化生产闭环。不要据此认为文件已永久归档或新任务已建立。真人图片和引流视频可在生产资源中管理查看，目前没有自动用于新 FFmpeg 模板/成片。

04 / 风景素材

把原始风景处理成可用素材

入口：资料中心 → 生产资源 → 风景视频 → 原始风景 / 可用风景

导入、预览原始风景

  1. 切到“原始风景”，点“打开原片目录”，把下载视频复制进去。原文件名可以保持不变。
  2. 回软件点“刷新风景”。确认原片数量和文件名；尚未加工入库的旧风景文件，也可能显示在原始风景中。
  3. 点原片缩略图进行播放预览，可以拖动时间。需要裁切时点“预览并裁切”。
  4. 判断横向取景能否覆盖整段：不能只看第一帧，应抽看开头、中段、结尾，避开黑边、字幕和大幅镜头移动造成的空区。

单条人工裁切

  1. 点“预览并裁切”。竖版默认三个横向取景，横版保留完整画面，方形默认一个横向取景；“布局 1 份 / 2 份 / 3 份”可重排。
  2. 选“第 1 份”等按钮，拖动裁切框改变位置，拖右下角改变大小。也可输入左侧、顶部、宽度、高度。
  3. 保持框在画面内、宽大于高、尺寸至少 32 像素；坐标与尺寸使用偶数整数像素。位置可以重叠，不要求每份必须无缝铺满原图。
  4. 播放原片或拖动时间，核对右侧各份预览。不要的区域点“去掉本份”。
  5. 确认份数和画面后点“生成 N 份，成功后删除原片”。它进入风景处理队列。
画面区域与时间段分别计算（最新源码规则）

30秒以内保留整段，长片随机切成主要15—28秒的时间段，全部无声、每份不超过30秒。竖屏若有3块取景、3个时间段，共输出9份短片；横屏默认保留完整画面。时间切法提交时固定，重试不重抽。全部结果入库并核对后才删除原片。此项用于2026.10.25.3轻量更新及最新源码，2026.10.25.2完整包和.1→.2轻量包不包含。

批量裁切：竖版三块取景、横版完整画面

  1. 勾选多条待处理原片，或点“全选待处理”。等待、正在处理或已有未完成任务的原片不能重复提交。
  2. 点“批量裁切（N）”。等待读取每条原片信息，查看预计输出份数；单批最多 200 条原片。
  3. 默认采用“竖版三块、横版完整画面”。也可统一每条1、2、3块取景，点“应用到本批全部”。重新应用会覆盖本批已经做过的单独调整。
  4. 特殊画面点“预览并单独调整”，修改后点“保存本条调整”回到批量页。不处理的原片从本批移出，文件本身仍保留。
  5. 核对“可提交 N 条原片，生成 M 份素材”，一次提交到队列。提交结果不明确时按页面“确认提交结果”检查，避免重新开批重复提交。
  6. 到下方风景处理队列或全局任务中心查看。某条失败保留原片，其他原片继续。

成功、失败与自动命名

情况软件实际处理你的下一步
一条原片的全部份成功完整检查、自动命名入库，再删除这条原片并清除关联。去可用风景抽看结果。
其中一份失败保留原片与已经验证的部分，后续其他原片照常处理。看失败原因，修复后点“重试制作”。
媒体成功，但原片删除失败记录未完成原因，不需要重新裁切所有结果。关闭占用原片的播放器，再重试。

可用结果自动命名为 风景000001.mp4 等连续编号，不覆盖已有文件。新任务输出无声、30帧、每份30秒以内。符合条件的整段横屏直接复制视频流并去声音，保留原分辨率；需要裁切或转码时按取景比例处理。分段完整覆盖原片时间轴，成功结果各自独立管理；旧素材和旧排队任务不自动重做。

可用风景的使用次数

一条可用风景实际排入一份成功模板的播放时间轴，计一次；只播一部分也计一次。模板内部重复播放不额外计次；该模板以后生成多少条成片，也不再增加风景次数。抽中但未播到的候选不预留、不计次，不因本模板触发用满删除。

卡片显示“已用 / 上限 · 占用 · 剩余”。例如上限 5、已用 2、排队预留 1，则当前剩余 2。排队和执行仅为实际播放素材预留额度，成功转为已用，失败、取消或中断释放占用。默认上限 5，在模板参数中配置。

用满后不再被抽取；无等待或运行引用且处理事务结束后，系统删除这个可用风景视频，保留使用账。已做好的模板仍有独立缓存，不因此失效。此项修复用于最新源码版与2026.10.25.2安装版；旧等待任务释放未播到候选的多余预留，历史成功用量保留，过去已删除文件不会自动恢复。

人工删除原片或可用风景

列表点“删除”，或预览点“删除此视频”，确认文件名后点“确认删除文件”。这是永久删除，软件内不能撤销。原片删除会清理相应失败处理记录，已入库结果保留；可用风景删除保留历史次数和已有模板。正在排队或执行的任务引用它时，软件拒绝删除，先处理队列。

05 / 模板规则

模板参数：调哪些、何时生效

入口：参数中心 → 模板生成参数；也可从模板制作点“生成参数”跳转

  1. 先读取现有数值。成对输入框分别是随机下限和上限；单个输入框是固定值。建议区间可以超出，基本规则与用途写在每项下面。数值使用整数。
  2. 只调整需要变化的项目，下限不能大于上限。首次试机使用时长 10 秒、误差 0，正式时长按实际需要设置。
  3. 点本模块的“保存模板参数”，等待成功提示。退出页面前确认已保存。
  4. “重新读取模板参数”从已保存配置重新加载，会放弃本页尚未保存的修改，不是恢复出厂默认。
生效时点

已创建的模板批次保留当时参数，修改画面参数不会改变正在制作或已经完成的模板。模板与素材使用上限立即生效，会影响现有模板对新剧是否可选；不要为了修改未来模板画面而误改这个上限。风景及真人图片使用上限也会影响现有库存：保存后立即检查用满清理。若把上限降低到某条风景已用次数以内，且它没有任务占用，该可用风景文件可能立即被删除；调低前先核对库存。已经占用的任务不会因此重新抽取。

随机性实际来自哪里

风景

抽一批素材分上下两组，互不共用，每组至少两条。各轮重新打乱顺序，轮内和跨轮都避免同一条紧接自己。高度一大一小，蒙版与羽化分别抽取。

贴纸

从单素材库重新抽系列与 16 个素材，上下各 8 个，组合排布和动画。历史 93 套仅为参考，不限制新模板从中选；每份新模板重新组合。

全屏特效

从类型、变化版、组合、取样起点、时间段及强度共同变化。双特效优先使用提前合成的一层组合资源，减少运行时重复计算。

动态边条

抽一个有效画面较满的循环纹理，再抽左右宽度、取景位置与起点。动的是纹理内容，两侧显示位置固定。

随机性增加组合数量，但不会保证任意两份在视觉上绝不相似。完成后仍建议抽看多个模板；不能只依赖模板名称不同判断效果差异。

刷新与人工删除模板

模板区域的“刷新模板”会核对真实文件，缺失或已变化的模板不再作为正常可用项。用满的模板是停止供新剧选用，不等于删除文件。

人工删除从模板预览内操作，先看确认说明。等待或执行中的成片引用模板时会被阻止。确认后预览 MP4 和配方移入模板回收目录，完整效果缓存、既有成片与成功计次保留；软件没有提供一键恢复入口。已人工删除或预览缺失的完成项不再显示在模板制作记录中。

模板制作时间与显卡占用

模板包含风景整理、贴纸动画、特效准备、效果预合成、编码和校验。显卡编码工作只占其中一部分，CPU 缩放、透明混合、磁盘读写也影响速度。显卡总体占用不高，不足以判断是否用了硬件编码。

看任务阶段和处理帧数是否继续增加。连续没有进度时按故障处理保留原因；不要在制作中手动删缓存，或用缩短正式视频、降低帧率来临时绕过问题。

07 / 生产准备

安排账号与剧集，导入主素材

计划只选日期；实际发布时分在自动发布工作台确定。左侧卡片长按可排序，自动合成开关记住关闭前的状态。“制作模板”从模板区域打开独立弹窗。标题左侧封面支持左键替换、右键编辑；剧集和羊头两套各有原图及最多3张修改版，羊头选用修改版时显示第二张，五套共用文字模板可复用。

安排今天：建立生产卡片

入口：顶部“安排今天” → 安排今日制作与发布

  1. 先准备状态“正常”的账号和所属剧场正确的剧集。打开“安排今天”。
  2. 按剧场筛选账号，选择要制作的账号；搜索并选择剧集。检查账号与剧集的组合清单，避免多选后创建了不需要的组合。
  3. 为每个组合核对计划发布日期、时间。可先用常用预设批量排期，再单独微调。
  4. 点“保存并加入今日安排（N）”。到生产中心确认实际创建的 N 个任务。

计划发布时间用于安排和列表管理，不会自动把视频发布到外部平台。安排窗口中的旧剪映队列说明不是新 FFmpeg 任务已自动开始的证明；仍须导入主素材、选模板并提交批量合成。

导入短剧主素材

  1. 在生产中心中选中目标卡片，核对顶部账号和剧名。
  2. 点素材区域的“素材目录”，打开本任务文件夹。把实际要做成片的短剧视频复制进去，不要放到风景目录或公共模板目录。
  3. 等文件复制完成，再回软件点“扫描素材”。系统识别可用视频并建立素材记录及序号。
  4. 检查“有效素材 N 条”和缩略图。点击素材进行预览，核对视频内容、画幅、声音和时长。
  5. 新增或外部移走素材后，再扫描同步。序号不重复回收，删除旧素材后新素材可能出现编号跳号，这是正常情况。
主素材是已经选好的内容

新 FFmpeg 链路保持原时长、原速度和原声，不自动替你做旧剪映的裁头尾、AI 留存判断或 BGM。中插/尾插已接入FFmpeg：参数中心设置全局门槛和位置范围，生产中心素材区设置当前剧集，素材卡左上角“⋯”设置本片例外。需要剪内容时先处理主素材，再导入；避免合成后才发现开头结尾不合适。

保留旧编号，按尾部类型继续编号

原文件名含“羊头”的新视频重命名时保留“羊-”前缀。首次扫描先普通、后羊头；已有正确编号时旧文件名固定，从最大序号后继续，优先处理与最后一条同类型的新视频，再处理另一类。该类型没有新文件就直接处理另一类。例如最后是“羊-剧名-10”，新加入“7.mp4”“8.mp4”“羊头.mp4”，结果为“羊-剧名-11.mp4”“剧名-12.mp4”“剧名-13.mp4”，原来的1～10不动。已有成片记录的任务也可追加扫描。成片区和预览直接显示完整文件名，含“羊-”与后缀。

生产卡片找不到时

依次检查日期范围、状态筛选、账号筛选和剧集筛选。已登记发布的任务可能不在“待制作”范围内。资料中心存在剧集档案，不等于已经给账号安排生产；回“安排今天”确认是否已创建。

08 / 成片制作

批量合成与成片检查

入口：生产中心 → 选中任务 → 成片区域“批量合成”

模板较短重复完整模板周期，最后截断；主素材和原声连续播放，不跟模板一起重头开始。
模板较长按主素材实际所需长度使用，不延长主素材。
模板固定效果直接复用已准备缓存，仍需将主素材与效果混合、编码并校验。
编码与体积预览和成片目标约 2500 kbps、峰值 4000 kbps；有声时 AAC 192 kbps。时长和内容会影响实际文件大小。

新版的合成加速

软件会自动检查显卡能力，在支持时加速普通透明、滤色模板的解码、缩放与画面合成。已有模板继续可用，不用为了升级全部重做；新制作的模板可使用更适合显卡读取的缓存。少数特殊效果或不支持的素材会继续使用兼容方式，实际速度以本机任务耗时为准。

输出保持1080 × 2400、30帧、9:20竖屏画幅和素材原声；完整成片检查仍然保留。若任务行提示使用CPU编码，查看中文原因和“本次检测详情”，按提示处理显卡驱动后再重试；没有提示不代表所有处理步骤都在显卡上。

成片完成后检查这几处

  • 开头：主素材没有被示意灰底盖住，重要内容没有被上下区域或边条遮挡。
  • 中间：风景融合过渡、贴纸运动和特效强度合适。
  • 模板循环附近：模板短于主素材时，在一个模板周期结束前后检查；模板画面允许进入新周期，主素材与声音应连续。
  • 特效切换处：没有异常黑帧、闪断或整屏突变。
  • 结尾：时长、声音与原素材一致，没有额外无声长尾；拖到末尾可以正常解码。

“生成完成”表示处理和媒体校验完成，画面是否符合你的审美仍由实际播放决定。首次新模板、新电脑、新素材类型都建议抽查。

生成耗时怎么看

单条“生成耗时”来自实际执行记录，不把排队时间算进处理速度。生产区域汇总按相关条目执行耗时累加，可能与墙上经过的总时间不同。比较性能时用同一主素材、同一模板，分开看模板一次性制作耗时和成片复用耗时。

09 / 任务管理

看进度、暂停后续、处理失败

入口：顶部任务监控 → 打开任务中心；各制作页也有对应队列

三类队列，分别控制

队列一条任务代表什么完成结果
风景处理一条原片及它的全部裁切份数。全部成功入库后删除这一条原片。
模板制作一份独立随机模板。公共模板及完整效果缓存。
成片合成一条主素材与已选模板。一条带原声的成片（原素材有声时）。

小窗适合快速查看当前任务；完整任务中心可以按“全部、等待、处理中、已完成、失败、已取消”等状态筛选，看完整原因并执行可用操作。三类队列的暂停互不替代。

暂停、取消、重试的区别

操作实际发生什么适合何时用
暂停后续…当前一条继续完成，后续等待项不再开始。准备离开、修改后续安排或等待检查结果。
继续…只恢复该类队列，其他类保持原状态。确认可以继续处理等待任务。
取消排队只取消尚未执行的一条，释放对应预留；不停止正在处理的一条。不再需要某个等待项。
重试制作 / 重试合成失败项按已保存配方重试；成片的已取消项也可重试。不会静默另抽一套模板素材。原问题已解决。先查缺文件、占用、空间等原因。

百分比不等于剩余分钟数

处理画面时主要依据实际输出帧数更新，同时区分准备缓存、合成、校验和保存。画面处理结束后仍可能需要检查，因此 99% 不等于已经入库，100% 才表示完成登记。不同阶段速度不同，不要拿前 10% 的时间线性推算总耗时。

关闭预览、切换页面不会取消后台任务。关闭整个软件可能打断处理：重新启动后中断执行项标为失败，等待人工重试；等待项按已保存队列及暂停状态恢复。需要停止后续时先暂停，并等当前一条完成再退出。

长时间不动或失败时如何处理

  1. 先看更新时间、阶段、帧数是否变化。若提示状态暂未更新，先恢复软件与本地服务连接，不立即重复提交。
  2. 在对应队列切到失败，记录任务名、错误原文、发生时间，以及是在风景、模板还是成片阶段。
  3. 缺文件或模板包不完整：恢复原文件与完整路径，或重新生成可用模板。不要拿同名但不同内容的文件直接替换。
  4. 文件占用或磁盘空间不足：关闭占用相关文件的播放器，检查数据盘。不要删公共模板缓存来给当前任务腾空间。
  5. 原因排除后对单条任务重试。仍失败时提供错误与任务信息排查，保留日志和失败目录。

部分受监控的 FFmpeg 命令连续 120 秒没有新增输出帧会停止该命令并留下原因。它没有覆盖所有贴纸准备等旧工具步骤，不能理解为“任何卡住都会自动恢复”。

10 / 自动发布

通过小V猫发布并查看结果

从成片进入发布工作台

  1. 确认账号、剧集、成片和封面正确，在任务标题右侧点击“自动发布”。本机小V猫需开启MCP和本地远程调试，账号登录有效。
  2. 工作台按账号ID匹配，自动区分正剧和羊，带入各自封面与挂载来源。检查对应剧集，羊默认不挂载；无封面也可继续。
  3. 选择一套默认配置或直接调整文案、声明、地址、份数和排列。地址支持账号默认与公共库，两组可以同步或分别设置；文案可选历史，短标题在更多设置。
  4. 确定整批开始时间、间隔与组顺序，检查完整排期；两组自动接续。制作计划日期不会自动变成发布时分。
  5. 小程序／视频号方式点击“发布”直接提交小V猫发布队列；插件方式点击“发布草稿”保存小V猫本地草稿，实际插件挂载另行处理。
  6. 查看工作台逐份结果，或关闭后在成片区域查看汇总、时间及展开明细。左侧卡片切为紫色发布进度，成功份数与总份数独立于成片条数。

挂载、地址与重复提交

产生外部任务／草稿编号后，文件名后显示挂载或未挂载，任务标题下显示发布位置。显示读取提交时快照，后续改配置不修改旧记录；挂载标签不是平台最终验收。任务暂停只读取状态，不自动恢复。响应不明确时保留任务编号、先核对，不反复点击重新发布。

定时提交成功不等于已经公开

视频号剧集挂载与定时提交已由用户核对官方后台正常。小程序挂载存在官方编辑页未显示具体剧集的现象，当前待实际公开核验。删除小V猫任务记录不等于撤回平台作品。停止V3后续提交不取消已进入小V猫或平台的任务。

发布状态与旧清理规则分开

旧“登记发布／撤销发布”入口已从生产界面移除。当前提交成功或生成草稿不会自动写入旧发布登记，也不会启动文件清理。下表的“已登记”指历史已有登记状态；清理前仍须查看预览和路径，不能用发布队列成功替代清理授权。

  2. 打开清理预览，逐项核对文件类型、数量、路径归属和预计空间。不要只看按钮文字。

11 / 收益复盘

采集收益、查看分析和视频关联

入口：数据分析；右上角“采集收益”打开采集中心

手动同步昨日或历史补采

  1. 先在业务资料里确认账号 ID、所属剧场、账号状态正确。停用账号自动跳过。
  2. 点“采集收益”，选择“全部已接入”“按剧场”或“按账号”。已接入范围是青柠、顶好、触摸、花生四类剧场。
  3. “同步昨日”读取昨日数据；“历史补采”选起止日期。长时间范围分段处理，单次按页面允许的 90 天范围操作。
  4. 点“开始采集”，看读取单元总数、当前账号和成功 / 无结算数据 / 失败计数。
  5. 完成后查看下方采集记录，按剧场、账号、数据日期和结果筛选。默认显示每个账号、每个数据日期的最新结果。
  6. 回分析页使用同一个日期范围查看数据。某天失败先排查再补采，不把空白手动理解为零收益。

不同来源的口径不一样

来源目前能采集到的内容使用时注意
青柠按日收益与逐条视频明细，包括播放、收益等。明细与来源总计核对后写入，可用于视频归因。
顶好按日账号收益。来源返回 0.00 但无法确认身份时记待确认，不当作已核验零收益。
触摸、花生账号累计收益口径。范围采集读取截止日期对应查询结果，不能当作每天新增收益相加。

同账号同数据日期重复采集会更新对应数据，不因为重采就新增一笔收益；采集尝试日志会保留痕迹。来源网站或接口变化可能导致失败，以这次采集结果和说明为准。

状态应该怎么理解
成功，金额 0.00来源明确返回且校验通过的零收益。
无结算数据来源正常响应但没有该日结算记录，不能等同于零收益。
失败 / 待确认读取、匹配、数值或对账未通过，暂不作为完整结果。
未采集 / 待补采还没有可用结果，应先采集。

六个分析页签怎么查

页签适合回答基本操作
收益选定日期内各来源、账号的收益与完整性如何？选日期和剧场，先看采集完整性，再看金额和趋势。
账号哪些账号值得继续安排？筛选账号与日期，对照状态、收益及可用明细；不要只看未采集时的空值。
剧集哪些剧集在已有样本中表现更好？核对名称匹配和数据范围，再比较表现。不是自动剧情评分。
视频哪条平台视频带来播放和收益？查视频 ID、剧名、账号、明细和内部成片关联。
组合账号 × 剧集组合表现怎样？在同样日期与来源条件下对照，缺少明细的来源不应强行拆到单视频。
微信指数指定剧名关键词的搜索热度如何变化？先初始化本机连接，维护关键词，再验证采集。

视频、剧集、组合等细分分析主要依赖青柠明细，不能因为四个来源能采集总收益，就认为四个来源都支持逐条视频分析。页面提示读取条数达到上限时，应缩小日期或账号范围；视频列表当前最多读取 12,000 条，截断结果不能当全量。

把平台视频对应到内部成片

  1. 在“视频”分析里打开目标平台视频，核对账号、剧名、平台视频 ID 与观测日期。
  2. 进入关联入口，窗口标题为“核对平台视频与内部成片关联”。
  3. 逐个播放候选成片，核对画面、主素材、发布时间。推荐候选不等于已经确认。
  4. 选中确切对应的一条，填写必要备注并确认。关联按账号与平台视频身份保存，后续日期可复用。
  5. 没有候选或无法分辨时保持未关联，先补齐正确生产与发布记录，不为清空“待关联”随便选择。

微信指数：连接本机、维护词、采集

  1. 打开微信指数页签并保持本机微信可用，点“开始本机连接初始化”。
  2. 按提示在微信指数里手动查询任意一个词。系统识别到连接后，点“停止并清理”，结束临时连接初始化。
  3. 选择归属剧集，输入关键词，选择角色：主关键词、已确认等价词、相关词、待确认候选或不采用，点“添加关键词”。
  4. 对需要读取的关键词点“验证采集”，检查导入天数和首尾日期，查看原始曲线。
  5. 连接过期显示“需要重新连接”时重新初始化。备用 JSON 请求模板仅用于初始化失败时按页面说明处理，不把真实请求内容发到聊天或公开文档中。

连接初始化会涉及本机临时代理和采集证书，用完必须“停止并清理”。连接资料由当前 Windows 用户加密保存，不随软件自动迁移到另一台电脑。等价词仍保留各词独立曲线，不自动相加。

安全备份的操作顺序

  1. 对三类队列暂停后续，等待当前任务完成，确认没有正在写入的生成或采集，再退出软件。
  2. 在资源管理器中，复制完整业务目录到另一个明确的备份位置；保留日期命名，避免覆盖唯一旧备份。
  3. 不要只备份成片或公共模板 MP4。数据库、同名模板配方、系统数据/tg 等效果包与账本同样需要保留。
  4. 核对复制完成、大小与文件数量，抽看几个媒体；需要正式恢复验证时在独立副本上进行，不能直接覆盖正在使用的目录。
  5. 备份完成后再启动原软件继续生产。

新电脑从零开始，或承接旧业务

从零开始：安装程序、选数据盘，重新建立账号剧集，导入风景和主素材，再按第一章做短片验收。

承接旧业务：先完成完整备份，目标电脑尽量保留相同盘符和业务路径，复制完整业务目录，再核对设置、账号数量、模板可预览且可复用、使用次数与发布记录。当前部分记录保留绝对路径，跨盘符不是自动修复流程；遇到路径不一致先处理迁移，别只改盘符继续生成。

同一台电脑上的 V2 和 V3 保留单实例与共享数据规则，只能轮流运行。独立程序安装目录不代表共享数据库可以随意降级；升级前保留稳定备份。

目标机验收

先做一份短模板与一条带声短成片，检查完整解码、画面、声音与速度，再批量运行。本机曾跑通的测试不能替代另一台电脑的驱动、磁盘、权限和业务路径检查。

14 / 遇到问题时

常见问题速查

优先按下面的顺序排查。遇到错误先留下任务名、错误原文、发生时间和实际文件位置；别反复提交或先清空缓存。

原始风景很多，为什么仍提示风景不足？

模板只抽“可用风景”。先完成裁切入库，再检查剩余额度、队列占用、无效文件和抽取条数。上下组还要求素材互不相同、每组至少两条以及初始时长差；一批完全同长度的素材可能不满足分组规则。

批量裁切成功一部分，失败的怎么办？

按原片独立判定。一条的所有份都成功才删原片，某一份失败会保留原片和已验证部分，其他原片继续。修复原因后用失败项“重试制作”，不要重新导入同一原片另开批次。

贴纸怎么不是从之前的 93 套里抽？

93 套是历史参考。新模板从单贴纸库抽系列和单素材，重新排布、动画；做好的组合缓存只给这份模板复用。复用同一模板的成片保持同样贴纸规则。

改了参数，为什么已做好的模板不变？

新的画面参数用于新建批次；已有批次保留提交时的配方。模板使用上限立即影响可选资格，风景使用上限还会影响现有库存并触发用满清理。想比较新画面，需要另外生成一个新模板。

成片比模板长，是不是又做一遍模板？

直接循环完整模板周期并截断到主素材长度，不按时长扩建模板。成片仍要解码主素材、混合画面、编码和检查，所以复用不等于零耗时。

模板播放正常，为什么合成提示缓存缺失？

播放只用预览 MP4；合成还需完整模板包。检查同名配方、业务目录和系统数据中的缓存是否完整，尤其是否只复制了 MP4 或改过数据盘。

为什么模板次数增加了，又为什么删剧后不减少？

同剧第一条成功计一次，之后同剧的成片不加次数。历史成功使用账必须保留，删卡片或发布后清理不退回名额。界面“占用”是排队预留，与“已用”分开看。

某个模板不见了，但文件还在？

检查是否达到新剧使用上限、同剧跨账号选用限制、文件变化、手动删除或当前筛选。用满不必删除文件，同剧补做资格与新剧不同。

主素材有字幕，成片边缘被裁掉了？

新成片使用固定 1080 × 2400、等比居中裁取。不同画幅可能裁去左右或上下边缘；先处理主素材取景，再生成一条确认。风景蒙版参数不能代替主素材画幅调整。

点暂停，为什么当前任务还在运行？

暂停是“暂停后续”，当前一条继续完成；三个队列各自控制。等待项可取消，运行项不会因为暂停立即被终止。

进度停在 99%，或者显卡看起来不忙？

99% 可能仍在校验和登记。显卡编码之外还有 CPU 与磁盘工作。先看阶段、更新时间、帧数；确认长时间无变化后按任务失败处理，不仅凭显卡总占用判断。

删除剧集后任务仍显示，是否一定是残留？

先确认账号、剧名和任务身份是否为同一条。成功删除应清理相应 FFmpeg 队列；清理失败会保留记录。公共模板制作历史和已用次数独立保留，不是这条成片任务的残留。

收益是空白、无数据、待确认，能按 0 计算吗？

不能。先查看最新采集记录与来源口径；只有明确返回零且校验通过才是零收益。累计收益来源也不能直接按每日新增相加。

资料中心已有剧集，生产中心为什么没有卡片？

剧集档案只是身份。还要用“安排今天”给账号建立生产任务，再放主素材、扫描、选模板和批量合成。

设置页说备份成功，备份文件在哪里？

当前“全量数据快照”只有提示，没有真实备份执行。请按本手册的完整目录备份方法操作，不能靠这一提示判断已备份。

换电脑后模板、账号和次数都没了？

安装软件不等于迁移业务。先核对数据盘与完整业务目录是否迁入，模板缓存、数据库和使用账都需要一起带走。不要在空目录中重复创建大量业务后再覆盖旧库。

需要进一步排查时，提供这些信息

  • 在哪个页面、点了哪个按钮、实际看到什么。
  • 软件版本，任务类别、名称与错误原文，问题发生时间。
  • 是新电脑还是原电脑，是否改过数据盘、搬过目录或删除过模板文件。
  • 当前其他任务是否还在运行；相关视频能否在播放器中打开。
