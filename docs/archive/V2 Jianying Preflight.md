# V2 剪映运行环境预检

V2 只使用系统设置中已配置的 `jianying_executable`（剪映程序）与
`jianying_draft_root`（剪映草稿目录）；预检不会自动发现并改写为另一套安装路径。

预检仅在模板草稿生成、成片草稿生成、视频导出和人工打开真实草稿前执行。它不会
阻塞普通的前端浏览、任务中心、文件管理或收益功能，也不会启动剪映或发送任何 UI
自动化输入。

当前支持并验证的目标是剪映专业版 5.9。预检会核对程序版本、草稿目录可访问性、
5.9 所需的默认调节资源、中文字体、用户数据缓存根目录，以及 Python 自动化运行
环境。失败会返回中文说明和稳定状态码，供桌面端或后续安装器展示。
