# V2 生产中心三层状态规则

本文记录生产中心的唯一状态显示合同（contract，约定）。状态由后端根据数据库、执行器当前任务和实际文件校验计算，前端只显示，不再自行推断。

## 一、左侧任务卡

任务卡只显示账号 × 剧集的业务总阶段，保持简洁；具体草稿或视频阶段显示在右侧区域。

| 后端状态 | 显示 | 判定原则 |
| --- | --- | --- |
| `released` | 已登记发布 | 发布登记已完成 |
| `action_required` | 待处理异常 | 存在草稿或视频异常 |
| `final_processing` | 成片处理中 | 成片草稿排队/生成、草稿已生成待导出、视频排队/导出 |
| `awaiting_release` | 待登记发布 | 当前全部已提交成片均已导出并通过校验 |
| `awaiting_final_generation` | 待生成成片 | 模板视频已就绪，仍有素材未完成成片 |
| `template_processing` | 模板处理中 | 模板草稿或模板视频处于排队/执行/已生成等待导出 |
| `template_error` | 模板异常 | 模板草稿或模板视频失败/超时 |
| `awaiting_template` | 待制作模板 | 已有素材，但尚未创建模板任务 |
| `awaiting_scan` | 待扫描素材 | 素材目录中有未登记视频 |
| `awaiting_material` | 待导入素材 | 没有可处理素材 |

异常数量单独显示，不把异常数量混入正常进度。

## 二、模板区域

| 后端状态 | 显示 | 判定原则 |
| --- | --- | --- |
| `not_generated` | 草稿·待生成 | 尚未创建模板任务 |
| `draft_queued` | 草稿·排队中 | 模板任务已创建，未被模板生成器领取 |
| `draft_generating` | 草稿·生成中 | 模板生成器当前任务 |
| `draft_retrying` | 草稿·重试中 | 正在终止并重新排队 |
| `draft_ready` | 草稿·已生成 | 剪映模板草稿已实际写出，尚未创建导出尝试 |
| `video_queued` | 视频·排队中 | 模板导出尝试已创建，未被视频导出器领取 |
| `video_exporting` | 视频·导出中 | 视频导出器当前模板任务，包括提交后的文件监测 |
| `video_ready` | 视频·已就绪 | 模板 MP4 和配对参数存在且通过校验，并属于同一模板版本 |
| `draft_error` | 草稿·异常 | 模板草稿阶段失败或超时 |
| `video_error` | 视频·异常 | 模板视频导出阶段失败或超时 |

只有 `video_ready` 才允许提交成片生成任务。草稿已写出不等于模板视频已就绪。

## 三、成片区域

| 后端状态 | 显示 | 判定原则 |
| --- | --- | --- |
| `not_generated` | 草稿·待生成 | 素材已扫描但未提交成片任务 |
| `draft_queued` | 草稿·排队中 | 成片任务已提交，未被成片生成器领取 |
| `draft_generating` | 草稿·生成中 | 成片生成器当前任务 |
| `draft_ready` | 草稿·已生成 | 剪映草稿已实际写出，尚未进入导出队列 |
| `video_queued` | 视频·排队中 | 导出尝试已创建，未被视频导出器领取 |
| `video_exporting` | 视频·导出中 | 视频导出器当前任务，包括剪映提交后的文件监测 |
| `video_exported` | 视频·已导出 | 正式 MP4 存在并通过媒体校验 |
| `draft_error` | 草稿·异常 | 草稿生成失败或超时 |
| `video_error` | 视频·异常 | 视频导出失败或超时 |

`视频·导出中` 的唯一权威是视频导出器的 `current_task_id`（执行器当前任务编号）。数据库里有活动记录但不属于当前执行器的，不得伪装成正在导出。

## 四、接口字段

生产任务摘要和详情返回：

- `task_display_status`：左侧任务卡状态；
- `template_display_status`：模板区域状态；
- `videos[].display_status`：单条成片状态。

统计数字也从这些规范状态计算：排队任务不计入“草稿已生成”，只有 `draft_ready` 才计入；只有 `video_exported` 才计入视频完成。

## 五、验收边界

自动检查可以验证状态映射、队列条件、类型和构建；真实剪映草稿写出、视频导出和 MP4 媒体校验仍需在 Windows 实际运行环境中验收。

## 六、成片人工检查模式

系统设置中的 `final_video_manual_check` 只是新建剧集时的全局默认值。每个剧集随后保存自己的人工检查开关，生产中心按钮修改的是当前剧集，不影响其他剧集。

视频导出器在真正开始该剧集的导出前重新读取剧集开关，因此排队中的后续任务会实时采用最新设置。已经进入 `awaiting_human_check`（等待人工检查）的当前任务不因关闭按钮而跳过；关闭设置从下一条尚未进入人工检查的任务生效。
