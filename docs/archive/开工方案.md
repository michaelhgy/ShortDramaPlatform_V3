# 开工方案（简化版）

> 制定：2026-09-17。本文只定"怎么合作"；具体改什么，在执行中通过考古与访谈逐件补充、逐件确认。

## 总原则

**先立规矩和安全网 → 再做记忆重建 → 最后才动功能。小步走，每步用户点头。**

## 核心骨架：记忆机制（贯穿全程）

```
用户口述（需求 / 规则 / 踩的坑）
      ↓
记录成中文文档
      ↓
三层存放：全局 ~/.dsh/AGENTS.md（偏好 + 安全边界）
          项目 AGENTS.md（规则地图，自动加载）
          docs/（规则全文 + 决策日志 + 反馈）
      ↓
四条维护铁律：① 每条规则只存一处  ② 改代码必须同步改文档
              ③ 决策日志只追加、记日期和原因  ④ git 兜底可回滚
      ↓
任何 agent 读文档就懂，用户不用重新解释
```

## 三条铁律（操作层面）

1. 先方案，后动手；破坏性操作必须明确授权。
2. 改代码必须同步改文档。
3. 宁可归档，不可删除。
