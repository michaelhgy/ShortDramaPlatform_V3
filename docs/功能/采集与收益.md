# 采集与收益

状态：当前有效｜最后确认：2026-11-13

- 工作台采集账号日数据、作品在线浏览、作品分析和剧场收益；各类别按自身能力执行。
- 首次或中断补采最多向前90天；已成功日期跳过，缺日、失败、空结果和待复查独立保存，不补成零。
- 累计来源按实际采集日记录新增；历史月份按来源能力覆盖，不跨月相减、不重复入账。
- 停用账号可继续查收益；注销账号停止新采集但保留历史。
- 账号、来源、月份、日期和作品ID用于去重；重试只针对对应账号和类别。
- 验证码、访问限制、来源无能力和配置缺失分别显示，不冒充成功或零收益。

代码入口：`server/operations_collection.py`、`server/v2_revenue_service.py`、`server/revenue_adapters/`。
