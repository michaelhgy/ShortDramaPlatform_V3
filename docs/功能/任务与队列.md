# 任务与队列

状态：当前有效｜最后确认：2026-11-13

- 任务中心显示成片、模板和风景三类队列，状态包括等待、运行、失败、完成、取消和暂停。
- 队列分别暂停/继续；暂停只停止领取后续任务，当前任务完成后生效。
- 进度使用后台实际处理帧数或阶段，不按耗时模拟；失败和取消按规则重试。
- 合成诊断只读日志，按最近运行、指定任务或全部历史导出报告和 ZIP，不初始化任务、不恢复队列。
- 历史剪映任务不计入新 FFmpeg 队列。

代码入口：`server/ffmpeg_finals/`、`server/ffmpeg_templates/`、`src/components/tasks/`。
