# 发布工作台

状态：当前有效｜最后确认：2026-11-13

- 提交前选择账号、来源、封面和计划时间；配置按账号和来源独立保存。
- 小程序和视频号通过 MCP 提交；插件方式只生成本地草稿，不附加原生短剧挂载。
- 每份成片保存提交参数、平台任务ID、发布位置和结果；没有外部任务ID不显示已挂载。
- 操作前重新读取平台状态；暂停、继续、取消和重发只对平台实际允许的状态执行。
- 官方后台全部接受或定时接受且能与本地任务匹配，才算交付完成；本地草稿、失败、未匹配和结果不明不计完成。
- 上传发布结束时间用于生产清理计时，官方公开时间独立用于作品分析。

代码入口：`src/components/production/PublishingWorkbench.tsx`、`server/publishing/`。
