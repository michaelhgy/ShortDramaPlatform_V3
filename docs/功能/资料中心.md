# 资料中心

状态：当前有效｜最后确认：2026-11-13

- 维护账号、剧场、剧集、平台来源、封面、头像和原片下载状态；路径和文件操作由后端执行。
- 账号按平台ID保存，导入时可关联剧场；停用保留历史并可查收益，注销停止新业务和采集但可恢复。
- 剧集来源按账号、剧场和平台ID保存；来源缺失或冲突时保持未确认，不猜测。
- 已有人工封面不自动覆盖；头像和封面缓存只在缺失、损坏或首次获取时补齐。
- 原片下载逐集保存链接、解析、校验和中断阶段；成功文件复用，失败或截断文件按集重试，不覆盖成功文件。
- 所有集数确认完成后才清理下载卡片或剧名，不影响其他剧集。

代码入口：`src/components/assets/`、`server/v2_file_service.py`、`server/drama_catalog.py`、`server/drama_download_reader.py`。
