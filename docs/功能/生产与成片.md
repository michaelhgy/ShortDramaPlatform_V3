# 生产与成片

状态：当前有效｜最后确认：2026-11-13

- 当前新流程使用 FFmpeg 模板和成片合成，保留原声，模板缓存可复用；旧剪映流程只作历史兼容。
- 模板制作冻结风景、贴纸、特效、边条和真人叠层；输入变化、文件缺失或缓存损坏时停止，不静默换料。
- 成片按模板循环、插片规则和原素材时间轴合成，输出前检查分辨率、帧率、音轨、时长和完整解码。
- 原剧二创资料分析完成后，会按剧目和资料方法版本保存高光库；每条高光保存原片集数、台词范围、时间范围和稳定 ID，预览按需从原片截取，正式成片仍直接使用原片。
- 二创生产任务可选定高光 ID 和生产目的；未传高光 ID 时保留旧流程兼容，仍使用当前资料地图中的候选高光。
- 中插、尾插支持全局、账号×剧集和单素材覆盖；插点、资源指纹和继承规则随任务冻结。
- 模板成功使用按模板身份和剧集身份去重；预览、选用、失败和取消不计成功次数。
- 等待或运行中的 FFmpeg 任务阻止删除输入；过程清理保留公共模板、成功使用账和业务历史。

代码入口：`server/ffmpeg_templates/`、`server/ffmpeg_finals/`、`src/components/production/`。
