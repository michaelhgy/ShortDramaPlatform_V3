## 0. 一句话说明：这些插件和短剧业务无关

DSH 是**你和我对话用的工具（AI 助手界面）**，不是短剧推广软件。
本文件里的插件只改**这个对话界面**（加面板、加余额挂件）。

**它们不碰 `D:\ShortDramaPlatform_V2` 的任何业务代码、数据库、生产数据。**
如果哪天你发现短剧软件出问题，**先排除这里，99% 不是它造成的。**

## 2.1 单价配置：已按官网真实价格手填（2026-09-19）

**为什么必须手填**：插件的「单价设置」有三层来源——自定义价 > 官网抓取价 > 内置价 > 兜底价。
实际使用时发现**后两层都是过时的**：

| 项目 | 插件内置 | 官网现在（2026-09-19 查证） |
|---|---|---|
| 模型名 | `deepseek-v4-flash` | **`deepseek-flash`**（旧名仍可调用，同一模型） |
| 输入（缓存未命中） | 1.5 元 | **1 元**（空闲） |
| 输出 | 4.5 元 | **4 元**（空闲） |
| 缓存命中 | 0.05 元 | **0.02 元**（空闲） |
| 高峰时段 | 每天 9:00-14:00 | **工作日** 9:00-12:00 **和** 14:00-18:00 |

而**官网抓取一直是失败的**（日志：`parsed 0 models from pricing page`，官网页面结构变了），
所以不手填的话，费用会按过时的内置价算。

**已配置的内容**（写在 `C:\Users\Michael\.dsh\settings.yaml` 的 `dsh-dock.tokenlog` 段）：

| 模型 | 空闲时段（基准价） | 高峰时段（9-12、14-18） |
|---|---|---|
| `deepseek-flash` | 输入 1 / 输出 4 / 缓存 0.02 元 | 输入 2 / 输出 8 / 缓存 0.04 元 |
| `deepseek-v4-flash`（旧名） | 同上 | 同上 |
| `deepseek-v4-pro` | 输入 4.5 / 输出 13.5 / 缓存 0.15 元 | 输入 9 / 输出 27 / 缓存 0.3 元 |

- 单位：**人民币元 / 百万 tokens**；汇率 USD→CNY = 7.2；官网自动抓取**已关闭**（`fetchOfficial: false`）。
- ⚠️ **已知不精确**：插件的分时价**只能按时钟，不能按星期几**。官网规则是"工作日高峰、周末与节假日全天空闲"，
  程序分不出"周三下午"和"周六下午"，因此基准价取**空闲价**（平时数字偏准），
  代价是**工作日高峰时段中、落在 9-12 与 14-18 之外的情况**以及**周末落在该时段的部分**会偏差一倍。
- ⚠️ **顺序有讲究**：`deepseek-v4-flash` 必须排在 `deepseek-flash` 之前（子串匹配，否则互相抢）。

**验证证据（等级 3，运行时实测）**：直接问运行中的插件（`POST http://127.0.0.1:8080/dsh-dock/tokenlog/pricing`），
返回 `pricingInfo.hasCustom=true, customCount=3`，三个模型的计价来源均为**「自定义」**；
逐条记录的 `priceSource` 均为 `custom`。并用原始 token 数**独立手算复核**过一笔（得到 0.0032058 元，
与插件结果一致）。

**截至 2026-09-19 的用量实测**（插件统计）：

| 模型 | 调用次数 | 估算花费 | 缓存命中率 |
|---|---|---|---|
| `deepseek-flash` | 2364 次 | 4.56 元 | **99%** |
| `deepseek-v4-pro` | 154 次 | 1.14 元 | 96% |
| `deepseek-v4-flash`（旧名） | 79 次 | 0.15 元 | 99% |
| **合计** | **2597 次** | **约 5.85 元** | 99% |

> 注：上表是**当时**的快照，仅用于说明量级；要看当前数字请自己开面板「用量记录」页。
> 有个反直觉但真实的点：**99% 的输入 token 命中缓存**（5750 万缓存 vs 348 万新输入），
> 所以费用的大头其实是**输出**，不是输入。

**以后想改价**：功能坞 →「用量记录」→ 顶部「单价设置」按钮（独立子弹窗）→ 改完保存即生效。
也可以直接编辑 `C:\Users\Michael\.dsh\settings.yaml`（改完自动热生效，**不用重启**）。

## 3. 日常操作命令

DSH 是本地源码版，没有全局 `dsh` 命令，所以命令要写全。**在 `C:\Users\Michael\deepseek-harness` 目录下执行**：

```powershell
# 看当前装了哪些插件、版本是多少
node --import tsx/esm apps/cli/src/bin.ts plugin --profile web list

# 卸载 dsh-dock（卸完要重启 dsh web 才生效）
node --import tsx/esm apps/cli/src/bin.ts plugin --profile web remove dsh-dock

# 重新装上
node --import tsx/esm apps/cli/src/bin.ts plugin --profile web add dsh-dock

# 检查合成配置里插件有没有真的挂上（找 dsh-dock / dsh-whale-widget 两行）
node --import tsx/esm apps/cli/src/bin.ts web --dump-config
```

**重要**：插件分"宿主半部"和"浏览器半部"。改完插件**必须重启 dsh web**，只刷新浏览器不够。

**重启方法**（现成的脚本，会自动等 15 秒让你当前的对话结束）：
`C:\Users\Michael\.dsh\restart-dsh-web.ps1`

## 4. 安全边界（重点看）

### 远程访问 —— 默认关闭，别随手开

dsh 默认**只监听 `127.0.0.1`**（只有本机能访问）。「远程访问」一旦开启，会让 dsh 额外监听 `0.0.0.0`（**局域网里任何设备都能连**），靠账号密码拦截。

- 2026-09-19 安装后已实测：**没有出现 `0.0.0.0:8081` 监听**，仍是 `127.0.0.1:8080`。✅
- 要用手机连，先想清楚：这台电脑所在网络里有谁？密码强度够不够？

### 钉钉 / 飞书推送 —— 消息会离开本机

填 Webhook 后，任务完成/异常的消息会**由 dsh 直接发到群里**（浏览器关着也发）。**Webhook 地址等于一把钥匙**，填了就等于允许发消息，不要外传。

### 图片理解代理 —— 唯一会额外花钱的功能

默认关闭。开启后每次识图按所选视觉模型的价计费。

### 网络访问 —— 插件会主动联网

2026-09-19 日志显示：`dsh-dock` 启动时会去抓 `api-docs.deepseek.com` 的价目页（用于估算费用）。**这是它联网的已知行为，不是异常**。

## 6. 已知毛病（不影响使用，但要知道）

1. **费用估算：已于 2026-09-19 配好**（见 §2.1）。
   原问题：官网价抓取失败（日志 `tokenlog parsed 0 models from pricing page`），退回内置旧价。

2. **小鲸鱼插件的本地改动会被升级覆盖** ⚠️
   `dsh-whale-widget` 被**手工改过**（让余额气泡常驻，不 5 秒自动消失），改动说明在

## 7. 出问题怎么办（决策树）

**症状：刷新浏览器后 dsh 界面打不开（8080 连不上）**

1. 先看日志判断是"装成功"还是"回滚了"：
   ```powershell
   Get-Content C:\Users\Michael\.dsh\install-dsh-dock.log -Tail 20
   ```
   - 看到 `SUCCESS` → 装好了，GUI 起不来是别的原因
   - 看到 `ROLLBACK OK` → 已自动退回装之前的状态，插件没装成
   - 看到 `ROLLBACK FAILED` → **找我**（这是需要人工介入的情况）
2. 手动重启一次：双击/运行 `C:\Users\Michael\.dsh\restart-dsh-web.ps1`
3. 还不行，就手动卸载插件再重启：
   ```powershell
   cd C:\Users\Michael\deepseek-harness
   node --import tsx/esm apps/cli/src/bin.ts plugin --profile web remove dsh-dock
   ```
   然后跑 `restart-dsh-web.ps1`。

**症状：功能坞按钮不见了 / 面板空白**

- 先**重启 dsh web**（不是刷新浏览器）——宿主半部没加载时面板就是空的。
- 再确认配置里有它：`--dump-config` 应输出 `- id: dsh-dock`。
- 还不行告诉我，别自己删文件。
