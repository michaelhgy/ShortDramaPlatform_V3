# V3 功能地图

| 用户要做什么 | 当前文档 | 主要代码入口 |
|---|---|---|
| 查看账号、剧集、来源、封面、原片 | `功能/资料中心.md` | `src/components/assets/`、`server/v2_file_service.py` |
| 看经营总览、账号矩阵、作品分析 | `功能/工作台.md` | `src/components/cockpit/`、`server/operations_dashboard.py` |
| 制作模板、合成成片、插片、重新生成 | `功能/生产与成片.md` | `server/ffmpeg_templates/`、`server/ffmpeg_finals/` |
| 准备发布、提交、取消、重发 | `功能/发布工作台.md` | `src/components/production/PublishingWorkbench.tsx`、`server/publishing/` |
| 采集收益、视频和作品分析 | `功能/采集与收益.md` | `server/operations_collection.py`、`server/v2_revenue_service.py` |
| 看队列、暂停、重试、诊断 | `功能/任务与队列.md` | `server/ffmpeg_finals/`、`server/ffmpeg_templates/` |

跨模块规则见：`数据与文件边界.md`、`验证与发布.md`、`AGENTS.md`。
