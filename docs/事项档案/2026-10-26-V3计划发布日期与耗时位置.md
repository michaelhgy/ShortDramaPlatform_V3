# V3 计划发布日期与耗时位置

日期：2026-10-26。状态：源码、正式前端、自动检查和隔离运行完成，用户当前程序未重启，使用验收待进行。

## 目标与影响排查

用户要求生成耗时移到计划发布下方，计划发布时间改为计划发布日期、去掉时分，同时排查依赖。已检索真实代码的planned_publish_at、scheduledTime、scheduledPublishTime、计划标签、排序/逾期及排期输入，覆盖生产中心、新建任务、设置、任务中心三个执行器/显示顺序、关联候选、收益日期关联和自动发布。

## 规则与改动

- 标题下第一行计划发布日期YYYY-MM-DD，第二行生成耗时；原计算耗时来源保留。
- 新建任务只选择日期，默认可暂不设置；批量统一今天/明天/指定日期，移除小时预设、错峰及时间输入。设置页只展示默认计划日期偏移，旧时间预设数据保留兼容、不再参与此流程。
- 新计划写纯日期；原planned_publish_at字段名和数据库结构不改，旧日期时间兼容读取为日期，不批量改库。原始旧记录在只读请求后仍保留原值，测试已核对。
- 逾期按上海日历日判断，当天不逾期，过了该日才逾期；无日期不逾期、排序置后。
- 生产列表、任务中心优先级及模板/成片/导出候选按日期，再按任务创建顺序；忽略旧小时分钟，手动优先级保留。前端同日排序补任务created_at，模板候选补同日任务创建时间，保持各入口一致。
- 任务详情、优先级卡、生产列表、视频关联候选的计划信息显示日期；收益中date(planned_publish_at)和日期切片可接受新旧格式，关联测试通过。
- 隐藏的旧手工登记兼容逻辑不再从计划时分推断实际发布时刻，实际时刻默认当前时间或已保存实际值。实际发布时间、自动发布开始时间/间隔、生成计时、清理保留小时和每日采集时刻继续使用完整时间，不受计划日期格式影响。
- 工作台原型的日期显示/编辑一起改为日期；其原本未投入的内存排期修改机制不扩大为生产任务修改接口。
