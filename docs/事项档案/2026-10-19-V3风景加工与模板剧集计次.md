# V3 风景加工与模板剧集计次

日期：2026-10-19。范围仅 V3，保护已有未提交改动，不重启软件，不处理真实原片、不改 V2。

## 用户目标与落地

原始风景不能直接用于模板。资料中心提供人工裁切，处理结果自动命名；对应原片选定的各份全部生成、检查并入库后删除原片。成功后不保留来源关联。处理后素材按原风景规则使用，次数与用满清理接通。

模板的使用上限改按不同剧集计数，同剧多条成片只计一次，删除已发布剧集卡后保留次数。

## 现场核对

开始时正式应用没有等待或运行的模板/成片任务。只读查模板账本：一个模板有5条成功成片，但 `drama_key` 只有1个，原统计按成片行计数导致显示5次。现在按历史明细中的剧集身份去重，显示应为1部剧；成功明细不清空、不改写，正常重启加载新统计后生效。

原风景此前递归扫描整个目录，居中裁取并按成功模板计次，上限仅停抽、未清理。新模块只把人工处理成功的素材提供给模板生成器；旧目录未入库文件转为原片页待处理，不自动移动。旧排队模板仍引用的原片禁止处理删除。

## 代码与规则

- `server/scenery/`：独立加工库、短编号、队列、实际编码进度、检查、原片删除、失败复用、用满清理及 HTTP 接口。启动创建单例与中断恢复受锁保护。
- `src/components/assets/SceneryWorkbench.tsx`：原始/可用页签、播放与时间拖动、1/2/3份布局、框拖动与缩放、整数坐标、动态局部预览、入库视频播放和用量显示。
- 资料中心资源扫描只展示已入库且文件状态有效的素材；原片不计可用库存。任务中心、顶部统计、小窗加入独立风景处理队列。
- 模板制作使用已处理清单，与加工、额度、文件清理共用锁；成功用量及排队占用均参与可用判断。达到上限且无预留、原片事务已完成才删除处理文件，身份与账保留。
- 模板库保留每条成功成片的账，显示与上限按剧集去重；排队预留也按剧集去重，已有同剧使用/预留不重复占名额。删除生产任务不会退回次数；同剧另建卡片仍只算一次。同剧跨账号的既有限制不变。
- 删除公共模板检查所有活动成片引用，避免首条成功后已无待转成功的预留、却仍有同批成片运行时误删模板。

- 自动检查中的用量结算与模板渲染使用隔离替身，验证状态和清理；真实媒体检查针对新裁切流程，没有重新制作完整效果模板或重跑成片性能测试。

## 交付与保留

源码和当前规则已更新；V3 正式窗口未重启。用户正常重启后进入“资料中心 → 生产资源 → 风景视频 → 原始风景”，可对旧目录中的原片接续人工处理，也可打开原片目录放入新下载视频。

没有自动删除正式视频、没有迁移正式原片、没有清空历史计次、没有提交或推送。测试视频、日志、截图和改动前备份保留在上述独立验收目录，不进入真实素材库。正式长视频、多批处理和用户实际构图验收仍由后续使用确认。
