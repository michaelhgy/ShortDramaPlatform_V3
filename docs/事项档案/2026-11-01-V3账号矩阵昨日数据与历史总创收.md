# V3 账号矩阵昨日数据与历史总创收

日期：2026-11-01。用户要求按官方昨日数据的四项调整矩阵卡片，并在未获取昨日时低调区分旧数据，底部发片量换历史总创收。

## 改动与口径

- 进入运营总览→账号矩阵，可见净增关注、新增播放、新增爱心、新增评论4列，固定取北京时间昨天，不随顶部区间变化。
- 昨日缺失或失败时保留最近完整有效日，显示实际日期及“待昨日更新”。使用浅灰底和浅色数字，不使用醒目警告色；昨日取得后恢复普通样式。没有历史为“待获取”和“—”，不当0；确认零、负净增关注保留。
- 新增纯数据选择器与共用显示组件，每项来自同一完整账号日记录，排除今天、未来、其他账号、失败/不完整/无效值，不跨日拼凑，不累加快照。大数紧凑显示，辅助名称保留完整数值。
- 运营只读接口新增account_daily_latest字段，每账号保留最近完整有效日；最新失败不会抹掉已保存成功值。原主报表日快照、覆盖/失败数量保持。旧数据响应无新增字段仍可回退。注销账号继续排除。
- 底部发片数改为历史总创收，复用账号评级已确认累计（含已结算，去除日/月重叠），两位金额小数，缺失为“—”。主创收/总播放/优化率仍按原日期筛选。

## 验证与边界

160项前端检查、16项相关后端检查、src类型检查及前端正式构建通过。后端检查覆盖新旧日快照并存、失败不抹成功、注销排除和既有统计行为，均在临时数据库中执行。

7组独立离屏页面检查通过：官方四项与实际昨日数值、旧日期与浅色等待、无数据/确认零/负数、历史累计含结算与去重、切日期保持两块固定、7档窗口宽度四列不溢出、刷新到昨日数据后恢复样式。已查看1600像素截图，窄屏360像素也留存截图。

本轮没有写真实业务数据库，没有进行小V猫或外部数据获取，没有操作用户窗口、没有重启真实后端，没有提交/推送或生成安装包。前端已构建；完整的成功快照保留需正常重启V3开发版后加载后端，由用户在实际窗口验收。
