# V3 封面文本框与模板调整

日期：2026-10-26。状态：独立预览页调整完成，正式生产中心接入仍未执行。

## 用户目标

文本框可上下左右调整；可隐藏选框查看真实效果；文字上下居中；底部保存简化为“导出封面 / 另存新版 / 保存使用”，保持样式；新增最多五个可跨封面复用的模板。

## 实现

- 文本模型增加可选高度和上下对齐，兼容上一轮已存的旧文字参数。八个方向调整宽高，旋转后固定对边/对角；字号单独设置，空间不足时缩小容纳。绘制改用实际字形升部/降部计算垂直位置，不以字体行框冒充字形居中。
- 图片空白处点击或隐藏按钮关闭选框；点文字或显示按钮恢复。选框始终是独立界面层，不进入导出。另有画面水平/垂直居中。
- 移除独立“设为使用 / 覆盖此修改版”动作，保留三个按钮。白底“导出封面”只下载；黄色“另存新版”新增但不切换使用；深色“保存使用”保存并选用，已有修改版原位更新。保存过程防重复点击，持久化失败保留原状态和未保存编辑。
- 最多五个通用模板，包含文字、花字和排版，不含源图和成品图；保存于独立 IndexedDB 记录。换封面时仍可选用，自动按目标尺寸适配位置、框尺寸和字号。支持删除，满额不覆盖旧模板。
- 原配色、字号、卡片和三种按钮视觉保留。当前仍为独立预览布局。
