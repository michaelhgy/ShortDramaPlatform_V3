# 事项档案

这里记录一次主事项从需求确认到结案的完整过程，方便以后直接了解目标、方案、改动、验证和遗留事项。

每份事项档案只记录一个主事项。功能当前规则写入 `docs/功能档案/`，长期选择写入 `docs/4-决策日志.md`，当前状态写入根目录 `项目控制台.md`。

## 固定内容

- 要解决的问题
- 需求挖掘后的目标
- 方案与范围
- 改动的正式文件
- 验证与验收状态
- 临时文件处理
- 遗留事项与下一步
- 结案状态
