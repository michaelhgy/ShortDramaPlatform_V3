## 目标

## 方案与改动

- 重新编译当前前端页面和 Windows 程序。
- 使用 Inno Setup 制作中文安装向导，提供桌面快捷方式、开始菜单和标准卸载入口。

- 安装包不包含真实业务数据；目标电脑首次运行时使用自己的业务目录。
