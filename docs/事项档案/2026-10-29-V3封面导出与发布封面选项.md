# V3 封面导出与发布封面选项

## 目标

修复封面编辑器导出不能选择保存位置的问题，并让自动发布可以按分组选择是否附带自动带入的封面。梳理发布后出现错误或部分失败时的安全重发边界。

## 实现

- `tools/run_v2_desktop.py`：pywebview窗口挂载`save_png`桌面API，使用Windows原生保存文件对话框并把PNG写入用户选定路径。
- `public/cover-editor.html`与`tools/cover-editor-preview/main.ts`：iframe向V3封面弹窗发送PNG保存请求，由父窗口调用桌面API；取消保存不写文件、不增加花字导出使用次数。非桌面预览仍保留普通下载回退。
- `src/components/production/PublishingWorkbench.tsx`：封面区域增加“使用封面”勾选，按当前分组保存`cover_mode=auto/none`；取消后提示本组不使用封面。后端原有发布参数构造在`none`时省略封面字段。
- 依据项目内2026-10-28 MCP工具清单，`vcat_cancel_publish_task`可取消任务但不能删除历史记录，发布中止也只是尽力而为。适配器已在显式`writable + publishing`权限下放行该工具；取消、状态复查和失败项重发规则详见自动发布功能档案。
