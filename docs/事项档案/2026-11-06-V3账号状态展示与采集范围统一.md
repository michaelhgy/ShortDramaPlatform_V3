# V3账号状态展示与采集范围统一

日期：2026-11-06。状态：源码修改、自动检查及隔离页面操作完成；正式桌面和用户验收待做。

## 目标与确认规则

账号生命周期较短，停止发布后仍可能等待次月收益结算。停用表示暂时不使用；注销表示不再运营并停止采集。所有状态均保留已有流量、收益、作品和任务历史，各界面分别控制默认显示范围。

| 位置 | 默认账号范围 | 补充 |
| --- | --- | --- |
| 经营总览、数据导出 | 全部状态 | 历史流量和收益保留，可按账号状态筛选 |
| 账号矩阵、作品表现、账号优化 | 正常、观察、限流、二限、实名、封禁 | 可切换停用、注销、全部状态 |
| 资料中心账号管理 | 全部状态 | 保留原有状态筛选和编辑 |
| 收益采集 | 除注销外全部，包含停用 | 仍需有效采集器配置 |
| 流量、作品、账号资料采集 | 默认未停用且未注销 | 停用可手动选入；注销禁止采集 |
| 新安排的账号选择 | 正常 | 沿用既有前后端限制 |
| 历史生产、发布、任务 | 全部状态 | 注销不再使历史记录从列表消失 |

## 实际修改

- 数据分析按页面独立选择“全部状态、未停用/未注销、停用、注销”。金额、排行、账号菜单、作品、数量和分页使用同一页面范围；切换矩阵不改变经营总览。账号管理保持全量档案。
- 后端历史查询保留注销账号及关联缓存、作品、收益、生产和发布任务，不删除账号档案或媒体。新安排仍按原有正常账号限制。
- 已结算且金额有效的历史收益参与所属期间分析；同账号整月累计与覆盖日收益去重，避免历史收益恢复后重复计入。未改原始金额、结算状态或收益日期。
- 收益采集保留停用，注销不可选。平台采集推荐排除停用，手动可勾选停用行“本次也采集平台数据”。混合任务保存独立的平台账号子集，停用收益不会顺带触发平台采集；执行前复核注销状态。自动优化检测继续排除登录失效，并排除停用、注销。
- 注销操作说明及相关功能档案同步更新。未新增账号状态，不涉及数据库结构迁移。
