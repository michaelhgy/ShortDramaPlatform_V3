# V3收益空结果与采集记录修复

日期：2026-11-05。范围：现有11个内置采集器的空/零/失败处理、统一收益续采和账号采集记录。未新增剧场、未修改绑定、未迁移或修复正式历史记录，未重启、打包或发布。

## 已确认问题与改动

1. 顶好成功响应0.00被代码记为indeterminate，统一引擎转换成失败，无法触发连续7天空结果停止。正式库只读确认有同轮同日期重复记录；原站页面将0.00提示为数据为空。已改为no_data、金额为空，并注册为空记录边界。
2. 首次历史未完成时，统一队列先查新日期，历史阶段又把新日期加入计划。失败日期会同轮重复查询。历史阶段现从持久化原起点续采，不重复本轮新日期。
3. 青柠旧数字解析会把空字段变0、把含数字错误文案读成数；触摸旧正则可忽略负号；花生缺total会变成正常空。现均失败并保留原数据；正常明确信号仍可识别。
4. 任务整轮仅失败曾显示待继续；正常空也只显示已完成。已分别显示查询失败、无收益记录，最新失败记录可重试。
5. 过程原来整批只存最后120条，前面账号过程会被挤掉。现每账号每类型独立120条并提示截断，仍保留每类型最近3次尝试。无法恢复之前已丢失的事件。
6. 新记录显示本次入账，累计来源另显示来源累计和入账日期；不改变已确认的日收益归属规则。新增每项开始结束时间，旧记录显示任务创建时间。
7. 同秒日志改为按写入顺序排序；后续失败不覆盖原有效收益。
