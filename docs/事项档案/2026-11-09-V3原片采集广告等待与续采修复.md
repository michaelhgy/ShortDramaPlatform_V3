# V3 原片采集广告等待与续采修复

日期：2026-11-09。范围：现有V3原片下载中相邻集采集的广告恢复及横幅区域OCR；不启动真实任务，不制作EXE。

## 故障与修改

现场《妆匣渡古今》已保存第1—9集链接，滑动后进入广告。旧逻辑只滑一次，等待横幅后尝试选集；广告播放结束仍需再滑才能离开，导致目标第10集未确认而停止。

`tools/short_drama_downloader_lab/阶段1_收集链接.py` 新增相邻集恢复：正常切集先快速确认；无“免费剧集”横幅时按可能广告或加载页处理，从上次滑动后留出7秒播放时间，重试前再次核对是否已自动返回目标集；仍无横幅才再滑动。最多额外3次滑动，广告恢复循环使用45秒时间预算（单次OCR/设备操作耗时可能使实际返回略超预算）。读到其他集或横幅集号不明时重新选集，重新选集沿用原有独立超时，不误保存目标集链接。只在目标集确认后暂停视频，等待广告时不暂停。

新增动作日志包括目标集数、等待原因、已等待秒数、再次滑动次数、错集重选及超限停止。原有停止通过后端终止当前子进程；保存成功的链接仍逐集落盘。

`tools/short_drama_downloader_lab/导航.py` 横幅OCR在同一张截图先识别左下窄区，未确认横幅或目标集时才扩大到左下宽区；宽区结果独立判断，避免窄区错号污染。未改成全屏OCR。

## 检查与生效

新增11项隔离检查，与原26项流程检查合计37项通过；动作日志3项检查通过。涵盖正常换集无额外等待、广告需二次滑动与至少7秒间隔、持续广告停止、错集重选、等待期间自动返回、超时、已有9集链接后仅选择第10集及窄宽区域回退。测试不连接手机、真实解析接口或业务数据，使用虚拟时钟和临时链接表。

现有V3每次采集通过新子进程读取脚本，下次点击开始即使用此次修改；无需重启桌面或重新构建前端。本轮没有启动真实手机任务，没有修改正式采集表、任务状态或视频。广告场景的手机实测留给用户重试；不能以隔离检查代表真实广告页面已验收。
