# V3子诗四类收益采集器

## 目标与结果

按用户提供的八个入口增加子诗达人、子诗机构、子诗达人IAA、子诗绿泡泡四个采集器；沿用已有剧场复核、账号选择、查单管理、统一采集中心和日期收益分析。

三个业务按月累计入账、昨日交叉检查；绿泡泡只采月累计。月累计首次和漏采增量归采集日，日金额不再次相加。来源实际日期、金额、链接写入成功采集证据，日志显示延迟和差异。机构本月及上月的金额独立保存基线、合并到当天，不改历史日收益。

## 真实来源证据

2026-11-05，使用用户此前提供的非IAA ID只读查询：

- 机构昨日入口返回“昨日11.3广告收益”0.03；本月入口返回11月累计0.09；上月入口返回10月累计203.98。
- 达人飞书字段为“11.4广告收益”“至11.4当月收益”，绿泡泡为“11月绿泡泡挂载总收益”；上述月入口未匹配该ID，返回明确total=0且hasMore=false，记录映射可缺省。已按正常空匹配处理为pending，不写假零。
- IAA用户表中M1链接标题实际为当月、D6为昨日，默认角色按网页标题配置；该ID在IAA入口无匹配记录，尚未验证正收益结果。
- 未将单日金额与月累计相减推测某一天收益；单日不超过累计也不代表能确认累计截止日。不存在的历史入口不会伪造查询支持。

## 实现与保护

新增 `server/zishi_collector.py`，复用古言的匿名飞书传输、分页完整性和账号精确匹配；原古言解析/访问约束保持默认，子诗使用单独的来源及字段解析。易查分查询采用独立Cookie会话，核对结果ID与唯一收益字段；验证码或异常结构明确失败，不记零。

注册四个固定编号及业务别名，扩展查单配置支持昨日和上月链接，并将全部链接纳入试查指纹、配置版本、启用及恢复。统一采集引擎按实际月份去重、计算月累计增量；同一天多个月份的证据保留合并。数据库沿用已有表，无结构变化。
