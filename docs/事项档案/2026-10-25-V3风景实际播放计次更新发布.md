# V3 风景实际播放计次更新发布

版本：2026.10.25.2。用户在源码修复完成后授权重新打包。本次在2026.10.25.1基础上纳入风景按实际播放计次修复，保留之前各版本安装文件。

## 包含内容

- 只为模板时间轴实际播放的风景预留用量，成功后每条计1次；同条循环、部分播放仍只计1次。
- 未播到的候选不占用次数，不因本模板触发用满删除；文件缺失、变化或被其他任务正常清理不影响本模板制作和重试。
- 初始化时释放旧等待任务未播放候选的多余预留，原配方保持，历史成功用量不追溯改写。
- 参数改称“上下合计风景候选条数”，同步更新用途说明、功能规则和离线手册。
- 保留2026.10.25.1已有全屏贴纸、真人叠层、图片计次清理、建议区间、25项说明及其他现有功能。

具体业务规则及源码验证见[风景计次修复](2026-10-25-V3风景按实际上屏计次修复.md)。这次不修改风景排布、随机配方、画面混合、输出尺寸及帧率。

## 打包与验证方式

源代码与正式前端使用本轮已通过的409项后端、54项前端、类型检查、界面构建、浏览器及实际媒体结果；不因重新打包重复跑全部源码检查。

打包验收直接运行冻结程序：比对修复源文件、程序内新模块和正式前端，检查1458个运行资源，并在独立目录生成实际模板及带声成片。计次检查使用6条候选、1秒模板，只有上下实际播放的2条预留及计次；测试上限1，仅清理这2条，其余4条保留。模板完成后继续生成12秒带声成片，核对GPU与CPU兼容路径、模板缓存复用、音频一致、方形像素及9:20显示比例。

安装器检查与上述冻结程序检查分开记录，使用本轮新建测试安装目录，核对安装文件、版本和安装后运行环境；测试卸载仅处理此次隔离安装。若电脑已有V3安装注册项，验收脚本会停止，避免接管用户原安装。

本轮过程证据集中在`local-test-output/v3-release-20261025-2/`。最终逐项结果与安装文件SHA256记录在交付目录的`验收结果.json`和`SHA256SUMS.txt`；这些文件是此次安装包实际完成状态的依据。
