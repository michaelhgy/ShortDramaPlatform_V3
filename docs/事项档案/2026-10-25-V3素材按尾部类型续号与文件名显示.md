# V3素材按尾部类型续号与文件名显示

日期：2026-10-25。

## 用户确认与范围

用户给出的现场示例：普通视频1～4、羊头视频5～10已经编号，又加入 `7.mp4`、`8.mp4` 和 `羊头.mp4`。用户确认应在10之后继续编号，优先衔接尾部类型，尽量成组；同时要求成片区域直接显示文件名。

本事项替代同日初版“补入普通素材后移动羊头尾段”的规则。改动仅在V3源码和正式前端；未操作V2或真实业务素材。

## 当前行为

- 保留 `剧名-N` 和 `羊-剧名-N` 的正确旧名称、扩展名与编号，N为正整数。
- 新素材从数字最大的有效编号＋1开始；该尾部是羊头时先编新增羊头，是普通时先编新增普通；无同类新文件则直接编另一类。组内自然排序，两类不交错。
- 没有任何有效编号时从1开始，普通在前、羊头在后。重复编号会在改名前提示核对，不擅自改旧文件。
- 示例结果：旧1～10保持，`羊头.mp4` → `羊-剧名-11.mp4`，`7.mp4` → `剧名-12.mp4`，`8.mp4` → `剧名-13.mp4`。
- 已有成片制作记录的任务支持这种追加扫描，原素材ID和成片关联保持不变。
- 成片列表及预览直接显示文件名。已生成项目优先读取实际成片路径的文件名；尚无输出文件时显示当前素材文件名。素材缩略图标题同步显示真实素材名，保留羊前缀。

## 改动

- `server/v2_file_service.py`：命名计划改为固定已有编号、按最大号和尾部类型追加。
- `server/tests/test_material_sheep_order.py`：更新增量扫描场景，新增用户截图对应1～10追加11～13、普通尾部优先、无同类回退与重复号保护等回归。
- `src/adapters/production.ts`：已产生成片的标题优先取实际输出文件名，兼容Windows及正斜杠路径。
- `src/components/production/ProductionCenter.tsx`：素材、成片列表和成片预览直接显示文件名；扫描提示改为续号说明。
- 同步资源扫描规则、生产中心说明、业务说明、离线手册、控制台，并将初版事项标为历史。
