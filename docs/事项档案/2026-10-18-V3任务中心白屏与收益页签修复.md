# V3 全局任务中心白屏与收益页签修复

## 目标与范围

用户报告点击全局任务中心会白屏，收益中心也有问题；后续补充：收益页剧集显示 0，切到账号变成 1，在剧集为 0 时点击剧集会白屏。本事项修改 `D:\ShortDramaPlatform_V3` 的页面和收益读取逻辑，保留原 V2、业务记录与媒体，不操作采集、生产任务或剪映。

## 确认原因

- 全局任务弹窗关闭时提前返回，打开时才执行后面的孤儿记录 Effect，导致前后两次渲染的 Hook 数量不同。旧构建实际复现 React #310，根页面节点清空。
- 收益页使用简版结果，固定提供空剧集列表和“明细正在读取”的视频状态；账号等页签使用完整结果。每次切回收益又覆盖完整数据，造成剧集数量 0/1 跳变。
- 同样从收益切到视频，视频组件先走空态提前返回，数据到达后才执行后面的 Hook，独立复现 React #310。剧集页在独立浏览器没有复现整个根页面崩溃，但确认简版造成的假 0 和剧集详情区域缺少空态提示；已修正读取流程，并覆盖用户补充的点击路径。

## 实际改动

- `TaskCenterModal.tsx`：孤儿记录 Effect 移到关闭状态提前返回之前，内部仍按打开状态决定是否请求。
- `DataAnalyticsView.tsx`、`revenueAnalyticsService.ts`：五个收益页签使用同一完整快照，移除清空剧集的简版读取分支；切页签复用当前数据，日期、剧场或数据变化才刷新。保留按筛选条件缓存、并发去重和异步过期结果丢弃。
- `AnalyticsHeader.tsx`：首次读取中用省略号表示未知数量，成功确认空数据后才显示 0。账号/剧集读取中显示状态，失败显示错误。
- `DramaModule.tsx`：没有数据或搜索无匹配时，详情区域显示明确提示。
- `VideoModule.tsx`：所有 Hook 执行后再决定是否显示不支持视频明细的空态。
- 正式浏览器回归脚本 `tools/verify_ui_navigation.cjs`：全部 API 返回隔离测试数据，禁止实际 API 写操作，验证任务弹窗、数量一致、读取中点击、真实空数据、搜索、缓存重载和首次读取失败。
