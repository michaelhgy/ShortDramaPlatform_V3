# V3趋势图数值标注与单日布局

## 目标及确认

用户要求播放/收益点旁显示数值，超过14天时取消数值以免拥挤，单日居中并解决紫色点被绿色点遮住。已先读取绘制代码并提出方案，用户回复“可以”后实施。保持用户自行验收，不控制桌面窗口。

## 实现

- `src/components/cockpit/dualTrendLayout.ts`：统一计算日期跨度、点坐标和数值布局。1—14天显示两项数值，超过14天不显示，判断使用选定的日历区间而非有数据的点数。
- `InteractiveCharts.tsx`：播放量紫色、万/亿量级紧凑显示；收益绿色¥金额保留两位小数。小字号配白描边，避让文字及圆点，必要时错行/横移并加细引线。较长区间日期刻度抽稀，仍保留首尾日期和所有数据点。
- 单个数据点横坐标为绘图区水平中心，日期同步居中，不显示单点路径/面积。两条纵轴独立缩放导致单日两项正值必然同高；重合或接近时紫圈较大、绿圈较小，保留各自纵坐标，不改数据或比例。
- `CockpitView.tsx`和`AccountDetailDrawer.tsx`传入统一日期边界，两处行为一致。悬停区域覆盖当天的两项指标，并保留完整数值提示及键盘聚焦查看。图表渐变使用独立ID，避免首页和详情同时存在时串用。
- 未修改数据库、模拟数据、采集链路或其他业务模块。

## 验证及边界

- 全量前端105项通过，新增4项覆盖14/15天阈值及稀疏日期、单日正值/零值/单项为零、14天密集零值和交叉曲线避让、量级格式及空数据。
- 全部src TypeScript源文件及测试文件类型检查通过，使用继承正式配置的临时检查配置，未改项目类型设置；Vite最终构建通过，源码和dist已更新，保留原有大文件分块提示。
- 通过8782本地只读接口读取现有数据，直接调用实际React图表离线渲染SVG与PNG，没有启动或操作浏览器/软件窗口。昨天/近7天/近14天/近30天分别渲染2/14/28/0个常驻数值；已查看14天及单日图片，紫绿点可见，数值清晰。
- 对实际全矩阵及39个账号共40个14天布局检查，计算所得数值包围框重叠0。离线图片不包含整页布局或真实鼠标交互，不能替代桌面显示、悬停及用户视觉验收。

本地核验材料位于 `local-test-output/dual-trend-values-20261101/`：四个日期区间的SVG/PNG和`verification.json`。正式实现为上述源文件；未生成安装包/升级包，未重启后端。用户刷新或重新进入V3开发版后查看“运营总览→经营总览”，切换日期并打开账号详情验收。
