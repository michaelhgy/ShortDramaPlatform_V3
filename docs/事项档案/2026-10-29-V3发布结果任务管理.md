# V3 发布结果任务管理

## 目标

在自动发布工作台管理已经提交到小V猫的任务，支持按状态筛选、批量暂停/重发/取消，并安全地按当前设置重新发布失败项目。不得把已成功或结果不明的任务误提交第二次。

## 实现

- `src/components/production/PublishingWorkbench.tsx`：发布结果增加状态筛选、单条/多条勾选、全选当前筛选，以及“暂停”“继续提交”“重发”“取消”批量操作。底栏“保存设置”左侧的“重新发布”先弹确认框，确认后进入当前参数编辑模式；点击“按新设置发布”创建全新批次，不依赖旧任务选择。
- `server/publishing/http.py`与`service.py`：拆分继续提交接口与远端任务管理接口。继续提交只接受没有小V猫任务ID的 pending 项；重发只处理已有远端任务；重新发布使用当前设置创建新批次，旧任务仅保留历史关联。
- `server/publishing/publisher.py`：每次操作前重新查询小V猫。暂停只作用于“待发布”；取消对所有有远端任务ID且未完成的记录尝试调用小V猫取消接口，接口拒绝时保留实际原因；重发通过优先级复用已暂停、失败、已取消任务。已成功任务不重发。新尝试使用新批次，保留旧任务记录和旧ID关联。
- 新增“排期重发”：完整显示当前批次任务，失败/暂停/取消/未提交项默认勾选，成功项默认不勾选；原时间只用于参考排序，人工选择第一条新时间和可编辑间隔后重新计算全部新时间。确认后使用原参数、只替换发布时间，创建新批次并关联旧任务。
- 排期重发提交前使用新排期校验，不再被原来已经到点或过期的时间拦截；已有 `:attempt:` 任务编号会映射回原视频后再创建新尝试。普通发布按每条作品的实际 `scheduleTime` 校验，避免批次运行跨过整组首条时间后误伤后续仍在未来的条目。排期弹窗在勾选变化后立即重算预览，确认提示只统计选中条数。
- 排期重发默认不选择正在发布和本机定时等待任务；活动远端任务会锁定保存/检查/重新发布。重新发布仍允许用户确认后按当前设置创建全量新批次，失败项补发使用排期重发。
- 同一批次的单条任务出现参数回读提示或远端失败时只隔离该条，继续提交后续未提交项；只有提交结果不明时停止整批。时间核对优先使用小V猫任务列表的本地定时字段，兼容部分版本表单时间的时区序列化差异，避免第一条误判后阻断后续任务。
- 对半提交批次，`needs_help` 会继续回读远端任务；没有小V猫任务ID的 `pending` 项支持在V3本地暂停/取消，点击重发会继续提交这些未提交项。重新发布筛选包含 `pending` 与可确认远端状态的 `needs_help`，结果不明项仍需先核对，避免重复创建远端任务。
- 重新发布不再复用旧任务的选择状态：确认后可修改自动发布参数，提交动作使用当前全部分组、份数、时间、地址、挂载、封面和文案生成新批次；“重发”仍是原任务继续执行，两者不共用入口。
- `server/publishing/vcat.py`：已有写入与发布权限门禁下使用已核实的小V猫任务更新方法；未增加删除小V猫任务记录的能力。
- `server/tests/test_publishing_publish.py`：新增隔离夹具验证暂停/取消状态范围、成功项排除、取消接口拒绝、过期定时保护、账号级明确拒绝后的继续提交、重新发布作废确认与取消失败阻断、排期重发计划、过期设置使用新时间以及 attempt 编号映射。
- `server/tests/test_publishing.py`：补充跨过整组首条时间后，后续实际未来条目仍按自身发布时间校验的回归测试。

## 验证

- `python -m unittest server.tests.test_publishing_publish`：28项通过，包括首条参数提示不阻断后续任务、账号级明确拒绝后的继续提交、定时字段时区兼容、半提交批次继续提交、重新发布作废确认与取消失败阻断，以及排期重发使用新时间、自动选择、间隔和 attempt 映射。
- `python -m unittest server.tests.test_publishing server.tests.test_publishing_publish`：80项通过。
- `npm test`：89项通过；`npm run lint`与`npm run build`通过，构建保留现有大JS分包提示。新增的前端时间工具固定使用`Asia/Shanghai`，覆盖跨午夜排期和非北京时间主机。
- `git diff --check`：目标文件通过。未进行真实桌面工作台交互验收。
- 未连接真实小V猫，未操作、取消、重发或删除任何真实远端任务，也未发布作品。

## 遗留

需要在用户重启V3后检查工作台布局和批量选择体验。真实小V猫任务状态的业务验收尚未进行。取消发布中的任务只能尽力中止，必须重新读取状态；它不删除任务记录，也不保证平台端已撤回。
