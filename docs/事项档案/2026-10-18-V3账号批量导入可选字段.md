# V3 账号批量导入可选字段

## 最终规则

用户要求批量导入只必填账号昵称、账号 ID、剧场；状态为空默认正常，报白时间、注册时间和备注可空。用户随后明确子剧场直接允许为空，取消创建“通用剧场”。本次最终实现以该补充为准，没有数据库结构迁移，版本仍为 4。

列顺序：账号昵称、账号 ID、剧场、子剧场、状态、报白时间、注册时间、备注。前三列必须填写，所属剧场须已存在且启用。子剧场、报白时间、注册时间、备注为空时保存空字符串；状态为空时保存正常。有值的状态和日期仍校验；填写子剧场时仍验证其属于该剧场。账号重复跳过，归属错误中断并保留此前成功行的现有规则不变。

## 改动

- 新增 `src/utils/accountBatchImport.ts` 集中解析表格，保留 Tab、逗号、分号中的空列，避免状态、日期和备注向前错位；读取真实剧场 ID，取消缺失剧场时套用默认名称。保留既有文本分隔和 Excel 日期转换。
- `AccountBatchImportModal.tsx` 使用统一解析，更新填写说明和示例，预览增加注册时间与备注；输入变化后清除旧预览，确认导入须重新解析。
- `server/v2_file_service.py` 批量入口补齐三项必填校验，空白状态归一为正常；既有空子剧场和空日期存储保持。后端文件保留 CRLF。
- `src/adapters/catalog.ts`、账号列表和编辑表单保留空值；列表/预览用中性「—」占位，编辑保存不补“主分发专区”、当天注册时间或“批量导入账号”。手动新增表单原有的初始日期未改，本事项重点是批量及后续编辑保留空值。
- 新增 7 项前端解析测试、3 项后端实际存储测试；同步功能档案与控制台。
