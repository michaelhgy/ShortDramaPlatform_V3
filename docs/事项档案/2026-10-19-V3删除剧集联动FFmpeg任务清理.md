# V3 删除剧集联动 FFmpeg 任务清理

日期：2026-10-19。用户发现生产剧集已删除，任务中心仍有对应成片记录，要求沿用之前清理规则适配新流程。

## 原因与范围

原清理从业务库删除旧剪映任务及生产任务，但新成片队列 `final_jobs` 和模板选用 `selections` 在独立模板库中，遗漏了级联；`系统数据/fg` 中的新成片尝试目录也未进入清单。旧清理弹窗声称保留历史成片，与原有过程清理实际会删除成片的规则不符。

只改 V3。未调整视频合成效果、模板缓存复用、队列执行策略、保留时长或 V2 源码，保护此前未提交改动。

## 实施

- 新增 `server/ffmpeg_finals/lifecycle.py`，统一队列归属、活动任务检查、安全临时路径、记录清理和历史残留核对。只按已验证编号清理任务 `fg` 目录，路径跳转、前缀归属冲突或异常编号停止清理。
- `server/v2_file_service.py` 接通删除、手动过程清理和到期清理。先执行文件清理并提交业务结果，成功后清除队列和选用；文件失败保留记录。发布/收益记录、原素材到期规则不变。
- `server/ffmpeg_finals/service.py` 与 `server/template_library.py` 共用锁保护创建、选用、投影和清理。等待/运行任务阻止删除，定时清理跳过；投影不恢复已清理记录，快照及领取过滤失效父任务。
- 启动时移除父任务已不存在或过程已清理的历史队列/选用记录，保留历史磁盘文件。成功使用账、公共模板和 `tg` 复用缓存不随剧集清理，不退回模板次数。
- `ProductionCenter.tsx` 删除后刷新任务中心和生产快照，提示文字符合实际删除范围，阻止原因可见且确认按钮禁用。
