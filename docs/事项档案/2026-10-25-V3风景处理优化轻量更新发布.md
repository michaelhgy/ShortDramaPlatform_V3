# V3 风景处理优化轻量更新发布

版本：2026.10.25.3。基础版本：2026.10.25.2。用户明确当前安装的是`ShortDramaPlatform_V3_Setup_2026.10.25.2`，授权把风景处理优化制作为升级包。

## 本版内容

自动布局下横屏保留完整画面，符合要求的30秒以内整段横屏直接复制视频流、去掉声音并保留原分辨率。长片随机切成15—28秒的无声短片，每份不超过30秒；竖屏同时间段的三块取景共享解码，直接输出最终短片。界面显示取景块数、时间段数和最终份数，重试沿用保存的分段方案。

旧已入库风景不重切、旧队列保留原规则。整条原片所有结果入库并核对后才删除原片。完整业务规则与源码实测见[源码优化记录](2026-10-25-V3风景横屏快速入库与随机短片.md)。

## 发布方式

使用`packaging/build_v3_update.py --base-version 2026.10.25.2 --version 2026.10.25.3`构建。只冻结新程序并生成差异更新EXE，不编译几GB完整安装器，不重新分发未变化的固定素材与运行组件。

交付位置：`packaging/updates/2026.10.25.2_to_2026.10.25.3/交付/`。更新EXE明确适用于.2→.3；不是首次安装程序。旧.2完整包及.1→.2更新包保留。新电脑先装.2完整包再运行本更新包；已经是.2的电脑直接更新。

## 验证和证据

复用刚完成的445项后端、56项前端、类型检查、构建、隔离页面与实际风景/模板/成片检查；构建前记录核心源码哈希，构建后核对包内版本、源码、模块和正式前端。

升级验收在本轮新建的独立.2安装副本执行；若电脑已有用户安装登记，改用独立程序副本，保留用户安装登记。直接运行交付的更新EXE，核对全部目标文件、固定资源、业务哨兵文件、版本登记和重复运行。

升级后的冻结程序实际处理高清带声横片及长竖片，验证去声、视频不重编码、15—28秒分段与三块取景共享解码；随后执行模板、GPU与CPU兼容带声成片、比例及音频检查。只卸载此次隔离安装，不操作用户当前程序。

本轮证据集中在`local-test-output/v3-update-20261025-3/`。最终实际结果、更新文件大小及哈希以交付目录`验收结果.json`、`更新信息.json`、`SHA256SUMS.txt`为准。

## 使用

等当前任务结束，正常退出V3，双击`.2_to_.3`轻量更新EXE，确认原V3安装目录后更新。完成后从原快捷方式启动。新建的风景处理任务使用新规则，原有素材和队列不自动重做。

更新前核对原文件并保存本次涉及文件的恢复备份；失败自动恢复，断电或意外退出后重跑同一更新程序恢复并继续。备份只涉及程序文件，不回退业务数据库。更新器不强制关闭软件，不自动启动业务队列。完整规则见[轻量更新说明](../功能档案/04-跨模块规则/软件发布与轻量更新.md)。

本轮不修改V2、历史发布目录、真实业务数据或用户当前安装；目标电脑实际性能与用户使用验收仍需在目标机器确认。
