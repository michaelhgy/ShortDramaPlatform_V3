# V3 原片下载实时动作日志

日期：2026-11-09。范围为原片下载的执行反馈与阶段展开，不变更手机导航策略、解析接口或任务清理规则。

## 实际修改

- 采集脚本在查找选集、选择集数、核对播放页、打开分享面板、右滑菜单、复制链接、读取剪贴板、滑动下一集之前立即输出具体动作。
- 下载脚本在发出解析请求、收到视频名称、连接下载服务器、接收文件数据、文件保存完成及失败时输出进展。显示真实集数，批次序号独立标明；下载字节每秒更新，服务器提供总大小时显示百分比。
- 后台直接消费子进程输出；等待期间每5秒更新无新进展的持续时间。下载字节刷新只更新当前动作，关键事件写入阶段历史，各阶段最多保留300条。
- 当前阶段默认展开，阶段或运行状态切换后清除之前手动展开的覆盖；任何阶段可手动展开/收起。历史最新记录优先展示，可滚动查看。
- 视频校验在实际探测文件之前切换至阶段四，避免校验日志归到阶段三。
- 后台恢复状态时，若保存的任务显示运行但本进程不存在执行线程，明确标为上次运行中断，保留任务、链接及文件，不再长期假显示解析中。
- 单剧限量处理先筛选剧名再截取数量，避免其他剧的历史采集记录占用限额。
