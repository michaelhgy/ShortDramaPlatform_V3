# V3账号同质化比例与优化作品指标

## 用户要求

账号行标题改为“优化量/优化率/同质化”，整体优化率之后增加同质化优化率，胶囊尺寸与优化率一致，使用顶部同质化卡片的紫色色系。展开被优化作品的流量数据改为播放量、完播率、爱心、转发、点赞。截图另标注通知区改为作品分析并展示原文。

## 实现

正式前端改动集中在`src/components/cockpit/AccountOptimizationView.tsx`：

- 每行复用现有`summarizeAccountOptimization([stat])`计算同质化数÷该账号总发片数，保留一位小数的既有格式。零发片/零同质化为0%，分类筛选不改变分母。整体优化率、原风险阈值和顶部统计均保持。
- 新比例用`bg-indigo-100 text-indigo-600`紫色，字号、字体、内边距及圆角与原优化率一致；直接接在原比例之后，不按健康状态改变紫色。标题为用户指定文字。
- 中间表现区为固定180px数据列及自适应原因区；窄宽度改为上下排列。原因保持原彩色描边、完整名称及数量，使用按可用宽度自动排列的网格，全部平铺、不折叠。
- 展开作品保留已接入的流量标签和作品详情入口，数据从`views/completionRate/hearts/shares/thumbsUp`依次显示，分开转发和点赞，不把评论或爱心当作其他字段。中等宽度上下排列，窄处指标组可横向阅读。
- 分析区标题改为“作品分析：”，直接显示记录的`officialNotice`文本，保留换行并以文本方式渲染特殊字符；删除手工附加引号、影响摘要和“公域推荐流降权”默认文案。字段为空时显示“暂无作品分析原文”，不替换为七类通知模板。
