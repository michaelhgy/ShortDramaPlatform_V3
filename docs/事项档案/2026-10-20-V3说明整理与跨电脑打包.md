# V3 说明整理与跨电脑打包

## 目标和边界

用户暂时接受目前效果与性能，要求整理从 V2 到 V3 的新业务与功能逻辑，并打包给另一台电脑使用。只在 V3 工作，保护既有未提交修改；不恢复优化实验、不重启用户应用、不迁移或更改真实业务数据。

## 实际改动

- 新增 `docs/V3业务与功能说明.md`，作为新流程总入口，连接已有详细功能档案。
- 更新部署说明，保留修改前的 V2 部署历史；在首页、文档索引和功能档案入口添加 V3 指引。
- 新增 V3 专用构建脚本、资源闭包、程序定义和安装定义；独立 EXE、安装目录、快捷方式及安装产品身份。
- 1072 个运行资源文件随包校验，包括 31 系列 670 个单贴纸、23 类特效的 104 个变化及组合条目、10 段边条。资源合计 2,764,864,119 字节。
- 贴纸动态加载需要的 Python 文件随包保留，不依赖开发目录或原剪映下载缓存；效果实际运行输入全部来自随包文件。
- 软件携带离线 HTML 使用说明及详细规则。真实数据库、账号、素材视频、成片和已完成模板缓存不进入软件包。
- 启动窗口和错误提示改为 V3；保留内部 `v2` 模块名、现有共用数据盘设置与单实例规则。
- 新增冻结程序只读资源校验及隔离媒体验收入口。测试只创建新的独立目录，合成后检查模板包没有被改写。

## 目标电脑使用边界

软件和业务数据分开交付。新电脑可独立导入风景和主素材开始使用；继续本机任务需要另行完整备份、迁移数据，并处理绝对路径约束。当前安装包不承担跨盘符数据修复、联网同步或自动汇总。
