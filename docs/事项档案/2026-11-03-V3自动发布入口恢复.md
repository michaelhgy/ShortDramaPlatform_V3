## 原因与改动

生产中心按钮已经设置当前任务标识，且已导入发布工作台组件，但页面未挂载该组件，导致点击后只更新状态、不显示窗口。已在 ProductionCenter.tsx 恢复 PublishingWorkbench 的条件挂载，传入任务标识、关闭回调及提示回调，并按任务标识重建组件，避免切换任务后沿用上一个任务的窗口状态。此次产品源码仅补回这一处连接，保留现有布局和发布规则。

- src 范围类型检查和 npm run build 均通过；dist 已重新构建。构建中的大文件体积提示为警告，不是此次入口失效的原因。
- Edge 隔离页面五项检查通过：打开完整工作台、关闭按钮、再次打开及 Esc 关闭、切换剧集后显示对应工作台、1200 像素窗口无页面横向溢出且可关闭。截图已查看，无页面脚本错误。
