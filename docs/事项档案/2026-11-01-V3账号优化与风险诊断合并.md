# V3账号优化与风险诊断合并

## 目标与用户确认

用户截图指出两页重复，确认保留账号优化及原账号列表，把截图统计融合进去，独立风险诊断页签删除；涉及账号数换为同质化优化率，删除分类标题中的“（7种真实通知）”。不改数据、收益/流量分级或外部平台采集。

## 当前行为

- 导航保留经营总览、账号矩阵、账号优化、作品表现、数据导出五项，桌面和窄屏一致。总览原平台优化按钮和原因分布图统一进入账号优化，原因图可带分类筛选进入。
- 顶部只有五张卡：周期发片总量、被优化视频数、整体优化率、最高频优化类型、同质化优化率。整体优化率按被优化作品÷全部发片量，同质化优化率按同质化作品÷全部发片量，按作品发布时间所在选区、剧场与账号范围计算，汇总计数后算比例，不平均各账号比例。
- 保留七类分类、账号/剧场/健康筛选、账号搜索、展开对应被优化视频、通知及账号/作品详情。分类选择只筛下方账号及展开的视频，顶部统计分母不收缩；分类卡百分比显示“占优化”，与顶部优化率区分。页面内剧场/健康/账号搜索选择账号范围时，顶部与列表同步更新。
- 原页面内账号搜索保留，进入账号优化时隐藏另一个全局作品搜索，展开明细使用同一日期/剧场/账号范围的完整作品数据。原因筛选不再作用于作品表现列表，避免从优化页切换后只剩某类作品。
- 无发片时安全显示0%，没有已归类优化记录时最高频类型显示暂无/待归类，不默认同质化。未归类风险仍按已有模型进入总体优化视频数，不伪造分类。
