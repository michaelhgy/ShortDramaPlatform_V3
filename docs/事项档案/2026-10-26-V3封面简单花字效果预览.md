# V3 封面简单花字效果预览

日期：2026-10-26。阶段结果：完成独立花字效果验证；整个双封面业务功能仍在接入前阶段。

## 目标和边界

用户确认每部剧两套封面，每套原图加三张修改版，要求先看简单剪映花字的真实效果，并保护另一会话正在做的生产中心封面显示与点击替换。

本轮全部实现放在新增的 `src/coverEditor/` 与 `tools/cover-editor-preview/`，没有编辑 `ProductionCenter.tsx`、`v2_file_service.py`、封面上传 API、发布工作台、正式 dist 或真实封面。现场发现另一会话在本轮期间继续修改生产中心和控制台，保留其全部内容。控制台仅插入本事项独立状态行。

## 实际改动

1. 只读剪映本地缓存，已有目录 808 款中 127 款存在对应文件夹；其中 43 款 TextStyle 配置可读取并有预览图，84 款为 InfoSticker 格式。本轮筛出不依赖纹理且非节令的 15 款样式，复制参数与小预览图到独立目录；不修改剪映缓存。
2. 新增基于 Canvas 的独立花字绘制模块和双封面版本状态模块。版本各自最多三张，保存底图和文本参数，支持重新编辑。
3. 构建离线效果页，可换原图、添加文字、选择花字、拖动/缩放/改换行宽度、旋转、设文字底色、保存/选用/删除版本和导出 PNG；浏览器本地保存与业务数据库隔离。
4. 初版检查发现内嵌色层与 CSS 内阴影含义不同，造成白色字芯变红或变黑，已按源参数及资源预览调整为位移字形与原字形交集色层；同时支持 `feather` 与 `diffuse` 两种字段。再次生成后目视检查通过。

## 验证

- `node --test src/coverEditor/model.test.ts`：5 项通过，覆盖上限、独立性、选用、删除回退和明确覆盖；失败操作不改变原状态。
- `node tools/cover-editor-preview/verify.cjs`：15 款均输出不同实际像素，字形非空且效果边缘不贴画布边界；11 项交互通过，包括拖动、缩放、两套三张、第四张阻止、独立选用、删除回退、透明导出、刷新保存、窄屏无横向溢出；浏览器错误 0，网络请求 0，业务写入 0。
- 导出封面 PNG 与实际预览画布 PNG 字节相同，选中框作为 DOM 层不进入导出。
- Pillow 读回：4 张真实封面样张均为源图尺寸 540×720；透明文字 PNG 的 alpha 范围为 0～255。
- `tsc --noEmit` 全项目类型检查通过，尚未构建或覆盖正式前端。
- 实际查看 15 款效果总图和编辑页截图，修复上述内嵌色层后重新生成。

自动验证通过不代表剪映等同还原或用户观感验收。尚未进行相同字体和文字在剪映中的逐像素对照，也未接入生产封面和发布选图。
