# V3 运营总览筛选下拉样式

日期：2026-11-01。范围：用户指出顶部剧场与账号选项打开样式难看，并补充账号直接用现有账号标签。

## 实际改动

新增CockpitFilterSelect共用组件，替换CockpitView顶部的两个原生select。白色圆角浮层、细边框柔和阴影、选中高亮/勾选、搜索、列表滚动、无匹配说明和搜索清空。剧场搜索名称/编码；账号支持昵称/ID等搜索，显示头像、剧场和现有复合标签。

AccountRatingBadge增加仅展示模式，直接复用原BadgeFace、颜色/图标及尺寸；常规交互模式与静态模式共用StatusBadgePopover导出的边框框架样式。列表行不嵌套按钮，原有标签说明/规则弹窗行为保持。等级/阶段/更新状态仍由V3数据模型判定。

选择值和回调不改：剧场继续级联账号，跨剧场时重置不匹配账号，注销继续排除。“全部”可随时重置，搜索不写业务数据。点外部或Esc关闭、方向键和回车选择、Tab继续导航，打开时搜索框聚焦并定位当前选中项。浮层通过独立挂载和动态定位避免裁切/出屏；账号最小336像素、剧场288像素，受窗口宽度限制，最大高度360像素，短窗口向上展开。
