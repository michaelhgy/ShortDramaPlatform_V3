# V3 作品分析标签配置

日期：2026-11-05。

## 目标与确认范围

在账号优化的优化设置中新增作品分析页签，归集相同分析原文，由人工自由填写标签，相关作品、标签卡、筛选及统计同步。按用户最新纠正，不固定标签，不处理不同用户命名不一致的问题。

## 实际实现

- 页签顺序：处理设置 / 作品分析 / 处理记录。相同正文忽略排版合并，显示原文格式、记录数和账号数。
- 标签自由输入，已有标签仅为建议；逐组保存、恢复默认、显式待归类。每页10组，搜索及归类状态筛选，列表独立滚动，分页固定。
- 复用已有文档表保存映射，默认规则作兼容，手动映射优先。原文、匹配、处理策略与平台状态保留。配置对当前共用V3数据库生效，不跨独立数据库同步。
- 后端提供分组及保存接口与乐观版本校验；dashboard携带配置。模型统一重新归类历史和后续数据，账号/作品标签、原因分布、主要原因及对应原文一起变化。修改或恢复标签后清除失效筛选。
- 原创优化率沿用现行“原创优化”标签的定义，不将其他自定义标签自动算作原创优化。所有分类仍计入总优化。
