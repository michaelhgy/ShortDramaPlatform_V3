# V3 轻量更新包与发布流程

日期：2026-10-25。状态：源码工具、首个轻量更新EXE、自动检查、实际安装升级、升级后运行和文档完成，用户及目标电脑使用待验收。

用户要求：增加轻量更新包，以后小修改不再每次生成几GB完整安装包。

## 方案与交付

保留完整程序构建作为版本依据，逐文件比较基础版与目标版，只打包变化的程序、界面和说明。生成可双击的独立Windows更新EXE，含自身运行环境，不要求目标电脑有Python或Node。

首包为2026.10.25.1到2026.10.25.2，目标仍为刚才已经交付的业务版本，不制造没有业务改动的额外版本。位置：`packaging/updates/2026.10.25.1_to_2026.10.25.2/交付/ShortDramaPlatform_V3_Update_2026.10.25.1_to_2026.10.25.2.exe`。

大小30,284,153字节，约30.28MB；完整安装包为3,101,533,758字节，减少约99%。变化文件31个、20,374,425字节，移除1个已不再使用的旧界面脚本。固定素材与运行组件沿用原安装。已有两个正式构建时不重编译主程序，本次更新EXE冻结约8.6秒；从新源码制作未来版本仍需编译主程序及必要验证。

SHA256：`c1022b45c4314f884ac358f2f2d7dabdee64a6fe08bc5677294354474815aff0`。交付目录另含适用版本、操作说明、校验和及本次验收结果。

## 实现

- `packaging/build_v3_update.py`：从新源码构建或复用已有构建，比较版本、文件内容及依赖兼容性，生成差异清单和轻量EXE；新源码路径自动更新前端，拒绝覆盖已发布目录。
- `tools/v3_update_core.py`：版本、文件、路径、占用、空间与进程检查，差异替换，恢复备份、原子处理记录、中断恢复及当前用户版本登记。
- `tools/v3_update_app.py`：自动读取V3安装位置、手动选目录、中文状态与错误提示；包含独立验收使用的静默入口。
- `server/tests/test_v3_updates.py`：20项实际文件事务及故障注入检查。
- `AGENTS.md`：把日常小修改优先使用轻量包写入项目发布规则；完整构建元信息排除更新包生成目录，避免把临时构建当成正式源码。

程序只处理明确的V3软件文件清单，不迁移、删除或恢复业务数据库、素材、模板缓存和成片。更新失败自动恢复；突然退出后再次运行同一包先恢复中断操作。已用过新版后的任意业务降级不在本功能范围，开发者发布前仍需判断数据库兼容性。完整当前规则见[软件发布与轻量更新](../功能档案/04-跨模块规则/软件发布与轻量更新.md)。

## 使用与边界

此首包仅支持2026.10.25.1到2026.10.25.2。已经安装2026.10.25.2的电脑不必再次运行。其他旧版本使用对应更新包或完整安装器；首次安装仍用完整包。

大素材、FFmpeg、Python动态库或其他依赖变化时拒绝轻量打包，使用完整包。版本连续更新按包注明的顺序执行，不能拿一个包覆盖任意旧版。

恢复备份保存在安装目录`.v3-updates`，不自动清理。旧完整安装器的卸载记录未登记轻量更新新增的说明和界面文件，卸载后这些文件及恢复备份可能保留；测试已如实记录，不把安装目录全部移除作为本功能结论。

未在目标3060 Ti电脑及真实业务目录执行升级，未修改历史完整包、未修改V2，未重启用户软件。正式新增文件为打包工具、更新程序源码、测试、规则文档和轻量交付；脚本、日志、独立安装残留备份及媒体证据集中保留在本轮测试目录。
