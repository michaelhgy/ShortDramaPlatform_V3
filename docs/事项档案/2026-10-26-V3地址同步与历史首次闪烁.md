# V3 地址同步与历史首次闪烁

日期：2026-10-26。状态：源码、正式前端及隔离验证完成，用户体验待验收。

## 目标及实现

用户要求正剧/羊地址可选择是否同步，并可存入默认配置；历史首次打开左上角有闪烁；补充把方案状态统一为“与配置一致／与配置不一致”，绿/黄采用柔和色。

配置location.sync、任务sync_location保存同步开关。新配置默认true；工作台可即时开关。同步时编辑任一标准组的完整地点或清空地点都会同时更新另一组；开启时以当前组为准，关闭后各自保持。后端读取/保存维护同一规则，正剧为标准地址的归一来源；前端已从当前组同步两个对象再提交，避免羊组更改被归一反转。自定义组、账号默认、挂载和视频归属不变。旧未标注任务若地址不同按不同步兼容，仅读取不改库。

方案读取补齐旧同步字段并提示版本变化，原任务参数快照不反向覆盖；捕获、默认优先级、地址范围应用、参数变化比较和缺失公共地点修正链路都带上同步选项。不选地址范围不更改该开关。

历史原来以(0,0)初始坐标创建浮层，再在普通effect中重新定位，符合首次闪一下、第二次保留位置的现象。改为点击事件先读取按钮位置和视窗计算坐标，与显示状态一并提交，挂载时就使用正确位置；保留搜索、删除、滚动关闭和ESC层级。

状态改为emerald浅底深字/amber浅底深字，只有一致/不一致两个标签。前端按最新方案完整可复用配置比较，而非旧快照是否修改；支持羊文案继承、独立挂载、全地址对象和同步字段。局部应用留有其他差异时显示不一致；每批时分、拍摄日期和单纯方案改名不产生差异。
