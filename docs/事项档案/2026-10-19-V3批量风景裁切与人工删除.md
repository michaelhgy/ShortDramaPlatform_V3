# V3 批量风景裁切与人工删除

日期：2026-10-19。用户已验收单条处理，要求多选批量裁切；随后补充原始风景独立预览，两类风景人工删除。

## 实施与范围

只修改V3，不改V2、不提交推送、不重启用户软件。保护既有工作区修改，在本轮独立验收目录保存目标文件修改前副本。真实业务素材和数据库未参与测试。

- 原片支持勾选、全选，批量窗口按实际尺寸默认竖版三份、横版一份；统一布局、逐条预览修改、移出本批、份数汇总后一次提交。
- 原单条裁切编辑器拆出复用，批量保存仅改本条方案。既有30fps、H.264、完整时长、不带声音等输出规则保持。
- 批量接口逐原片独立入队，单条提交失败不影响其他项；复用原有串行队列与暂停状态。固定逐条请求标识用于失联重查，防止重复处理。
- 每条结果全成功才自动删除对应原片，失败继续后续任务，重试复用已完成部分。任务尚未结束时显示原片名便于定位；成功后不保留来源关系。
- 两类风景均支持独立预览、卡片和预览内删除、永久删除确认。运行/排队占用、旧模板引用、文件替换受保护。人工删除失败原片清理对应任务和暂存，正式入库结果保留；删除可用素材保留历史用量，不影响已完成模板。
