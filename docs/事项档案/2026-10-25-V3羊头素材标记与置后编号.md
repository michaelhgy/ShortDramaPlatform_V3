# V3羊头素材标记与置后编号

日期：2026-10-25。

后续调整：用户以增量导入截图确认，应保留所有正确旧编号，从最大序号后按尾部类型续接，不再挪动已编号的羊头段。当前有效规则及验证见[续号与文件名显示事项](2026-10-25-V3素材按尾部类型续号与文件名显示.md)；下文保留本轮初版实现的历史记录。

## 目标与有效规则

用户要求扫描主素材时识别文件名里的“羊头”，重命名保留“羊”字，且全部普通素材在前、羊头素材在后，序号共用同一序列。例如10条普通加10条羊头输出为 `剧名-1` 至 `剧名-10`、`羊-剧名-11` 至 `羊-剧名-20`。

入口：V3生产中心 → 成片制作 → 选择账号×剧集任务 → 扫描素材。

- 普通与羊头分组，组内自然排序；已有编号的羊头按原编号排序，新增羊头接在其后。
- 重复扫描识别 `羊-剧名-序号`，保持标记和数字序号。列表、合成队列按数字排序，FFmpeg成片沿用素材名。
- 新增普通素材接在普通段最大号之后；羊头尾段必要时整体顺延，保留组内顺序和原素材记录ID。首次入库的原文件名继续保留。
- 已有成片制作记录且需要改动现存素材编号时，在文件重命名前拒绝并提示另建独立任务；无改号的重扫继续支持。
- 沿用分阶段改名与防覆盖机制，补强改名失败时的回滚；数据库路径同步分阶段迁移，避免路径交叉时串记录。
- 保持既有普通素材编号，不因文件移走而主动补齐旧空号。
