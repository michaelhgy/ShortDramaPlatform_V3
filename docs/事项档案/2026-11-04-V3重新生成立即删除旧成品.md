# V3 重新生成立即删除旧成品

日期：2026-11-04。用户明确要求：“直接删除，点击重新生成后，直接删除原来的”。取代原先保留旧视频、另存_R02版本的实现。范围为V3源码、功能档案和隔离验证，不在本轮执行正式媒体删除、数据库迁移、重启或打包。

## 当前行为

- 生产中心单条旋转箭头保持原UI；点击后检查本条原素材/模板/当前插片设置，检查通过立即删除旧成品，再排队合成。整个剧集仍从“批量合成”左侧的“全部成品重新生成”进入，确认前无操作；确认后对本批全部记录做前置检查，通过后删除并排队。
- 旧成品不等待新文件成功才删除；队列暂停时仍立即删除，暂停状态保持。生成失败也不备份、不恢复旧视频。
- 新文件使用原素材对应的标准成片名，不加_R02、_R03。每次重新读取当前已保存的全局→剧集→素材中插/尾插设置；原素材、原模板保持不变。
- 仅删除本任务明确记录的成品路径和历史尝试的final.mp4副本，以及旧发布凭据；归属可由历史JSON证明的旧R版本一并清除。不会用_R通配符扫删其他视频；原标准名被未归属本任务的文件占用时拒绝操作。
- 历史配方、失败及身份信息仍以JSON保留，但不保留旧视频。模板成功使用账沿用原身份，不重复扣次数。新发布凭据绑定本次代次，旧凭据即使路径/字节相同也不能让新一轮跳过生成。
- 全部前置检查失败时不删旧文件、不提交部分队列；如果实际删除中途遇占用/权限错误，则停止并将已触及记录标失败。文件删除不能事务回滚，已删除视频不恢复；未触及记录保持原状，解除占用后可以再次重新生成。
- 同名媒体和缩略图URL使用文件修改时间及大小区分缓存版本，避免重新生成后仍显示旧视频。
