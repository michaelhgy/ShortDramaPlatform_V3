- 控制台、文档索引新增正式手册入口。

## 当前事实核对中特别说明的边界

1. 参数中心旧祝福语、中插尾插及设置页旧剪映字段不作用于新 FFmpeg 链路。
2. 设置页下载标准模板、Excel 导入导出、全量数据快照仅提示，未真实执行；手册不能据此声称备份完成。诊断自检和打开日志入口也未形成真实检查流程。
3. 工作台演示、部分剧集资料编辑和爆款资产前端状态不是完整持久化生产能力。
4. 模板按成功使用的剧集计次，删除生产任务不退回；风景按成功模板计次。
5. `TemplateGenerationService.save_config` 保存后调用 `SceneryLibrary.clean_exhausted`；调低风景上限也可能立即清理已用满且无占用的素材，手册明确提示。
6. 已经发生文件清理的生产任务不能撤销发布登记；撤销软件登记不撤回外部平台视频。
7. 新电脑安装和业务目录迁移分开；现存绝对路径、机器设置与微信连接需另外核对。

截图使用当前 `dist` 界面，由 Playwright 在独立临时静态服务载入；所有 API 请求在浏览器内被示例响应拦截，外部网络请求阻断，没有连接真实业务服务。虚构“示例账号A / 示例剧集·归家”，进度为固定说明场景，视频取自既有隔离验收色条样本。截图不是新一轮生产、收益或外部平台测试的证据。

`local-test-output/v3-user-manual-20261020/capture.cjs` 与 `capture-result.json` 记录 15 张图和页面错误检查；最终页面脚本错误为 0。

`verify.cjs` 与 `validation.json` 已检查：14 章目录、所有页内链接及重复 ID、中文搜索和结果定位、无结果/清空、15 张图载入、键盘放大/Esc 关闭、FAQ 展开、1440/1024/390 宽度无整体溢出、移动目录、打印 PDF、无网络请求、无脚本错误。额外检查手册源文件、交付副本、压缩包的文件一致性与未来打包复制入口。
