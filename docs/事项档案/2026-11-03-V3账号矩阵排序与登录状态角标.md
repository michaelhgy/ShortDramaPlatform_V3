# V3账号矩阵排序与登录状态角标

日期：2026-11-03。状态：源码、自动检查和隔离浏览器显示检查完成；正式桌面运行、真实小V猫采集及用户验收待完成。

## 目标与结果

用户要求在账号矩阵标题栏中央加入当前创收、历史创收、总播放量、账号状态、登录状态五个排序标签，并同意用头像右下角角标显示最近核验的登录状态。昵称旁保留账号业务状态，右上角收益评级/阶段/更新指示保留。

- 矩阵排序独立于经营总览，默认当前创收降序。首次点击数值标签降序，状态标签按约定顺序；重复点击反转，切换页面后保留本次会话选择。
- 当前创收、总播放量跟随顶部日期范围；历史创收沿用卡片已有累计口径，不随日期变化。真实零保留，缺失和非有限数值始终最后；同值按原账号目录顺序稳定排列。
- 账号状态正序：正常、观察、限流、二限、实名、封禁、停用，未知最后；封号归入封禁。注销仍按现有全局规则排除。
- 登录状态正序：登录有效、明确失效/未登录/过期、未获取；反转时未知仍最后。未知返回值不直接判失效。
- 头像角标：绿色勾号为有效，红色感叹号为失效，灰色问号为未获取。悬浮/聚焦显示说明，点击固定显示，支持关闭、点击外部、Esc；不触发账号详情。显示上海时区核验时间，明确是最近一次结果。

## 数据链路与影响

现有采集队列、旧收集入口和定时发布跟踪在成功读取完整小V猫账号列表后，复用其中明确返回的loginStatus，将最少必要的状态和本地核验时间保存至已有v3_operations_cache表的login类别。仅匹配当前唯一关联账号；无明确状态/列表中缺失不覆盖先前结果，网络错误不生成失效结果。不新建表，不增加远程调用，不在打开页面时主动连接小V猫。

驾驶舱读取已保存结果，通过账号数据传给卡片与排序。此前没有保存记录的账号先显示未获取，正常执行现有更新数据流程后才会有状态。显示核验时间以说明可能过时，未将收益更新圆点或业务停用状态视为登录状态。
