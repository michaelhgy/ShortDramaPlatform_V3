# V3采集中心手动选择与收益登录解耦

日期：2026-11-04。入口：运营驾驶舱 → 数据采集 / 刷新。

## 目标与现行规则

用户纠正先前严格禁选策略：登录失效账号不自动选择，但可以主动选择；剧场收益与平台登录独立。

- 平台采集默认推荐、场景快选、“按本次任务选择”排除失效账号。手动勾选和主动全选允许选择，刷新状态不会单凭失效撤销已有选择。
- 只补收益时，根据可用采集器及收益缺口默认选择，忽略平台登录状态；已完成收益照常跳过。混合任务默认排除失效账号，可手动添加。
- 手动/重试平台采集先重新读取小V猫本次本地登录记录，仍失效才跳过平台项；收益照常执行。该读取不代表即时在线登录验证。
- 自动优化检测仍排除失效账号；未知登录不等于失效。未绑定平台和未配置收益采集器的能力限制保留。
- 尚未执行时提示“登录待核对”，执行状态按本次实际结果显示。
