# V3 查单管理与链接配置

## 目标与授权

用户确认在资料中心增加“查单管理”，界面跟现有软件风格一致。管理软件内置采集器的查单链接、启停与试查，不用人工重绑剧场/账号，不从任意链接生成采集器。本轮授权不包含真实账号查询、正式业务库改写、重启软件、发布或版本收口。

## 实际改动

- `src/components/assets/QueryManagementTab.tsx`：同风格列表、搜索、编辑、试查预览、启停、历史链接载入与确认。按日试查最多昨天；累计结果明确为来源总额而非本次入账额。弹窗内显示错误和未保存确认，不使用原生浏览器确认弹窗。
- `src/api/revenueQuerySettings.ts`：独立配置接口，试查超时设置180秒。
- `src/components/assets/AssetsCenterView.tsx`、`src/assetsTypes.ts`：资料中心新增顶级页签。
- `src/components/assets/BusinessDataTab.tsx`、`src/components/assets/modals/TheaterModal.tsx`：剧场编辑快捷入口及未保存提醒。
- `server/revenue_query_settings.py`：只读测试、配置版本/修订、默认回退、候选指纹、30分钟单次测试凭证、并发版本检查、URL与请求来源限制。
- `server/revenue_collectors.py`：新增配置表初始化入口，软件定义和固定编号不变。
- `server/v2_revenue_service.py`：实际查询读取配置、停用拦截、飞书token读取及字段/精确账号/记录完整性校验、采集结果记录配置来源。
- `server/revenue_collection_state.py`：同一期补月份标注复用原累计基线，新月份隔离，保留所有旧快照与收益。
- `server/v2_file_service.py`：GET/POST/PATCH模块挂载，不改现有端口或正式启动入口。
- `server/tests/test_revenue_query_settings.py`：24项隔离检查。
