## 一、最终业务结论

V3 使用 FFmpeg 直接合成成片，再通过 MCP 调用小V猫发布。生产中心不再使用人工“登记发布”流程，也不再提供人工确认发布成功按钮。

小V猫发布任务成功，只代表小V猫已经接受并执行了发布任务，不能单独代表官方作品已经公开发布。只有小V猫任务记录和官方作品记录同时满足条件，生产任务才算发布完成并进入清理周期。

## 二、发布完成判断

当前自动发布批次的每一条任务都必须满足：

1. 小V猫任务状态为成功：状态码为 `2`，或状态文本为“发布成功”“已发布”“success”等；
2. 官方作品列表中已经出现对应作品；
3. 官方作品状态为 `published`；
4. 官方作品具有 `postId`；
5. 官方作品具有实际发布时间 `postUnix`；
6. 通过 `localId`、`batchSource`、账号 UID、排期时间等信息匹配到当前本地发布记录。

全部条目满足后，系统才执行以下动作：

- 将当前生产任务标记为已完成发布；
- 记录官方作品 ID和实际发布时间；
- 以当前批次所有作品中最晚的实际发布时间作为清理计时起点；
- 写入过程文件和原素材的清理到期时间；
- 允许任务进入自动清理周期。

“已提交”“小V猫任务成功”“定时任务已创建”都不能提前触发清理。

## 三、异常处理

任意一条任务出现以下情况，当前批次都不进入清理周期：

- 小V猫任务失败、取消、状态不明或无法再次读取；
- 小V猫任务成功，但官方作品没有出现；
- 官方作品仍是定时或未确认状态；
- 缺少官方作品 ID或实际发布时间；
- 官方作品无法匹配到本地生产记录；
- 作品匹配出现多个候选，无法确定归属。

这类任务在生产中心使用现有“删除剧集”处理。删除范围只针对当前账号×剧集的生产任务及其专属文件，不删除公共模板、公共资源、爆款素材、剧集资料或其他任务。

## 四、清理时间与文件范围

继续保留设置页中的两个设置：

- 短期过程文件清理时间：默认24小时；
- 原素材保留时间：默认7天。

两项时间都从当前自动发布批次所有官方作品中最晚的 `publishUnix` 开始计算：

```text
process_cleanup_at = 最晚实际发布时间 + 短期过程文件清理时间
raw_cleanup_at     = 最晚实际发布时间 + 原素材保留时间
```

过程清理包括当前任务能够证明归属的：

- FFmpeg任务专属成片目录；
- `系统数据/fg/<任务编号前缀>` 下的任务缓存、配方、日志和中间文件；
- 当前任务的成片、模板过程文件、缩略图和任务临时文件；
- 仍存在的历史导出残留，只能按数据库记录且路径归属明确时清理。

原素材在过程清理成功后继续保留，直到原素材保留时间到期。过程清理失败时，不提前删除原素材。

以下内容不随单个生产任务清理：

- 公共模板；
- `系统数据/tg` 公共模板复用缓存；
- `生成资源` 下的公共风景视频、真人图片、引流视频；
- `内容资产` 下的爆款素材；
- `剧集资料` 下的封面等长期资料；
- 生产记录、发布任务记录、官方作品关联、收益和优化分析记录。

## 五、数据记录要求

发布数据分为两层保存：

- 小V猫任务记录：保存本地任务与小V猫 `localId`、`batchSource`、任务状态和错误信息的关系；
- 官方作品记录：保存账号 UID、官方 `postId`、实际发布时间、官方发布状态、匹配状态和本地发布条目关系。

只有已经匹配本地生产记录的官方作品，才进入发布统计和优化分析。优化记录必须关联到本地发布记录、官方作品 ID和账号 UID，不能用无法归属的作品填充统计。

发布历史和分析记录独立于生产文件清理保存，便于后续数据分析。清理生产文件不会删除已确认的发布归属和优化分析历史。

## 六、界面规则

生产中心保留：

- 自动发布入口；
- 小V猫任务状态同步；
- 官方作品状态同步；
- 发布异常时的“删除剧集”；
- 发布完成后的清理状态和清理设置。

生产中心移除：

- 登记实际发布时间；
- 发布地址登记；
- 确认登记发布；
- 撤销登记发布；
- 人工确认发布成功按钮。

旧的登记字段和后端接口只作为历史数据兼容，不作为新的业务入口或清理依据。

## 七、实现位置与验证边界

主要实现位置：

- `server/publishing/publisher.py`：读取和映射小V猫发布任务状态；
- `server/operations_collection.py`：读取官方作品、匹配本地发布记录、保存发布历史和发布完成门禁；
- `server/publishing/service.py`：刷新发布状态后触发官方作品确认，并写入清理到期时间；
- `server/v2_file_service.py`：执行FFmpeg过程文件和原素材的分阶段清理；
- `src/components/production/ProductionCenter.tsx`：生产中心的自动发布、删除剧集和清理界面。

已完成的自动检查：

- 官方未发布时不能通过清理门禁；
- 官方已发布且匹配全部本地条目后可以进入清理周期；
- 任意一条失败或未匹配时不能进入清理周期；
- FFmpeg清理相关回归测试通过；
- 前端生产构建通过。

尚未作为正式业务验收的内容：真实安装包升级、真实小V猫完整发布链路、真实官方作品到期后自动清理。
