# V3账号详情页签与视频指标布局

## 范围与结果

按用户两张截图标注调整运营总览的账号详情，未修改业务数据库、收益/流量算法或外部采集。

- `AccountDetailDrawer.tsx`：把“播放与收益走势”移到已发视频明细前，每次打开/切换账号默认选中趋势。三个页签增加选中状态说明，原视频、趋势、优化分析内容和入口保留。
- 视频列表改为封面居左，右侧上行显示文件名、已有优化标记和精确发布时间，下行显示播放量、完播率、爱心、评论、转发/点赞。五项标签与数值均同行，整组不折行，空间不足时在指标行内横向滚动；文件名可缩略，点击整卡仍打开原作品详情。
- `AccountRatingBadge.tsx`中的详情摘要：用户框出的收益分级/阶段依据、更新与查询说明移入现有“查看标签规则与近期记录”折叠区，默认收起；累计、最近日、峰值和近3日四项摘要及人工复核提醒保留。

## 验证

src全部源码/测试类型检查和最终Vite构建成功，产物`dist/assets/index-B1ZtfFmo.js`；保留原有大分块提示。没有变更后端，不需要为本次布局重启服务。

使用实际组件与最终CSS，在独立无窗口浏览器的测试夹具里完成6项检查：趋势排第一且默认选中、规则说明默认折叠且可展开、五项指标相同纵坐标且位于文件名下/封面右侧、点击作品入口不变、窄内容区可横向滚动且仍不折行、原Esc关闭不变。检查页签切换后只选中一个按钮，无页面脚本错误。已查看1320×960趋势及视频列表截图，并检查520像素宽时指标的滚动；不据此宣称整个桌面界面适配移动端。

没有连接或操作用户已打开的软件窗口，也没有刷新/重启软件。用户刷新V3开发版后，从任一账号进入详情检查页签顺序、视频行和折叠效果；实际桌面观感尚待用户验收。
