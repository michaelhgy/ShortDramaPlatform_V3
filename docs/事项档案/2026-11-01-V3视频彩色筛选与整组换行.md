# V3视频彩色筛选与整组换行

## 用户要求

删除截图红线中的“当前账号筛选”提示及旧的独立文字标签行。在排序栏右侧绿色框位置平铺视频彩色标签：空间够则同行，不够时整组标签进入下一行，不允许只掉下部分标签。

## 改动

- 新增`VideoTrafficFilter.tsx`，包含全部及8种流量状态，保留当前范围数量、选中状态与原筛选回调；不使用下拉或折叠。
- 从`VideoTrafficTags.tsx`提取纯展示的`VideoTrafficStatusMark`，筛选与视频卡片使用同一套彩色底、图标、字号及圆角。筛选只展示状态微标与范围数量，不带作品播放数、采集圆点或悬浮详情，不更改卡片徽章样式。
- `CockpitView.tsx`删除旧账号范围提示和“视频标签:”独立行，将排序区和完整标签区作为两个不收缩的flex子组。两组能同时放下时同行并列；否则完整标签组换到下一行。极窄宽度下，已独立换行的标签组内部继续自然换行，保持所有标签平铺且无横向溢出。
- 筛选仍使用既有`rateVideoTraffic`和日期/账号/剧场/搜索范围；计数先按全部范围统计。分页、排序、空态恢复及12/24小时时点推进保持。
