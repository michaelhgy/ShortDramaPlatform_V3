## 采集链路与关键字段

1. `vcat_list_accounts`：账号身份与登录状态；不按昵称关联。
2. `vcat_refresh_account_stats`后调用`vcat_get_account_stats`：账号总量与日期范围内的日数据。
3. `vcat_start_post_sync`、`vcat_get_post_sync`、同步记录：从官方更新小V猫缓存；再分页读取`vcat_list_posts`。
4. `vcat_get_verify_result`：现有异常作品及exportId；`VcatClient.optimization_detail`复用已验证的官方详情GET。

## 实现与使用

正式源码：

- `tools/collect_v3_account_data.py`：独立命令入口，默认只读小V猫缓存，默认最近7个完整自然日；仅显式参数触发刷新和同步。无V3数据库写入。
- `server/publishing/vcat.py`：复用既有本机MCP连接，扩展有授权标记的统计刷新/作品同步及只读诊断查询。发布写权限不因数据采集授权而开放。
- `server/tests/test_account_data_collection.py`：隔离测试，不连接真实小V猫或业务库。

读取缓存并补充已有异常作品的官方分析：

```powershell
python -X utf8 tools/collect_v3_account_data.py --optimization-details --sync-records
```

明确刷新账号统计并同步全部作品，然后读取分析详情：

```powershell
python -X utf8 tools/collect_v3_account_data.py --refresh --sync-posts --optimization-details --sync-records
```

可用`--uid`逐个指定账号；未指定时选择当前登录有效的视频号账号。`--start`和`--end`控制账号日数据日期，不限制作品发布日期；本入口作品同步范围是全部作品。无登录有效账号时明确报错，不写一组0。

每次新建`artifacts/account-data-collection/时间-随机标识/`目录，保留脱敏快照、摘要、过程日志和运行中检查点；不会覆盖以前结果。默认不获取作品分日数据和剧场收益。

注意：`--sync-posts`会改变小V猫保存的同步账号与范围；同步配置已从原来的“一只羊13652、近3天”变为上述4账号、全部作品、单账号并行、不抓分日数据。首次快照保留原配置；本次未自动恢复，以免另行触发同步。正在同步时再次要求同步会拒绝，不取消别人的任务。结束等待不等于取消平台同步，超时须先查看状态再决定下一次操作。

账号会话只在内存用于指定官方域名的GET请求；不保存Cookie、不输出临时签名地址。详情GET拒绝跟随跳转。脱敏快照只保留封面和视频地址是否存在，供后续展示接入时按需取地址。
