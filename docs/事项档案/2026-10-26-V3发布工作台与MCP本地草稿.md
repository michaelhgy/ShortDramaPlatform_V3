# V3 发布工作台与 MCP 本地草稿

日期：2026-10-26。

## 目标与范围

按已确认的自动发布方案实现第一阶段：账号识别、地址搜索、剧集自动匹配及记住关联、分组参数、时间份数和人工辅助，执行停在小V猫本地草稿。用户最新要求封面可不填，任务标题左侧显示与资料中心共用的封面，点击替换，无图显示剧名占位；羊专用封面后续再定。

## 实现

- 新增server/publishing：标准库CDP只读查询、MCP草稿白名单、持久化准备信息、按条执行与重试核对、HTTP入口。
- 新增发布工作台与任务封面组件；生产中心第4步为发布准备，兼容手工登记入口保留。
- 新建任务默认稍后定发布时间；前后端支持空计划时间。
- 封面上传补建档案，替换不重置原片资料；不指定封面合法。
- 搜索前处理剧名符号；按文字规则自动/人工确认，稳定内部ID对应平台剧集ID，按账号核对权限。
- 保存每条草稿与原参数；创建结果不明确先核对；人工辅助可打开对应草稿、预览并采纳单条设置。
- 数据库结构版本从4到5，新增独立文档表；无旧数据清理或迁移，未修改V2。

## 发现与修复

地址带当前城市前缀可能返回商家而非目标地点，增加去前缀回退及排序。工作台重开时执行状态与自动检查有时序问题，增加状态依赖及新接口no-store/读取防缓存。旧结构版本断言更新为当前结构常量。失败截图及中间记录保留，不作为最终验收结果。
