# V3 发布封面开关与自定义图片

日期：2026-11-05。

## 目标与最终规则

用户反馈发布工作台取消封面后，保存和关闭重开都会重新选中；要求封面开关进入默认配置，并允许直接点图选择自定义封面。后续明确交互为“使用封面、使用自带、使用自定义”。

- “使用封面”为总开关；开启后，来源二选一：“使用自带”或“使用自定义”。取消只停用，保留来源和已保存的自定义图片。
- 使用自带：按实际视频类别自动带入当前剧集的正剧/羊封面。自带封面缺失沿用原规则，允许无封面继续。
- 点击图片或占位图打开文件选择；成功保存副本后切换为使用自定义。取消选择、读图失败、保存失败均保留原选项和图片。
- 默认配置分别保存正剧、羊的开关/来源/图片，不受“羊沿用正剧文案与声明”影响。自定义应用新增“封面设置”范围；只应用排期与份数不修改封面。
- 从当前任务另存配置、软件/账号默认、新任务应用、后生成羊视频的配置恢复、配置一致性提示均包含封面规则。更新或删除配置不反向改变已经保存的任务。

## 原因与改动

`server/publishing/planning.py` 的分组整理原本无条件执行 `cover_mode='auto'`，保存与读取均经过此处。改为只补缺失默认值，保留明确的 none/custom。

`server/publishing/covers.py` 新增系统托管图片：位于系统数据根目录的“发布封面”目录，与数据库同属一套数据目录，不写入成片、任务素材或封面编辑器项目。使用图片内容散列作为编号，同图复用，替换写新图片，旧文件保留。任务和配置保存编号，发布时解析到本机托管文件；不依赖用户原图路径。

导入支持 JPG/PNG/WebP，最大15MB、4000万像素；校验实际图片内容、校正方向、透明部分铺白、保持比例且长边最多2160，保存为JPEG。通过临时文件完整落盘后原子替换。预览入口只接受64位散列编号，不能读取任意路径。缺失的自定义图片在保存/发布参数校验时明确报错，不静默切回自带；已停用时允许保存缺失引用，方便关闭封面后继续使用。

`PublishingCoverControl.tsx` 供发布工作台与默认配置共用；导入期间禁止保存与关闭，避免保存尚未落盘的图片。原有封面编辑器封面及原始图片保持不变。当前旧版已强制保存为auto的历史选择无法反推出用户原意，加载新代码后需重新选择一次。
