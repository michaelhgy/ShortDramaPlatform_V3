# V3运营总览日期筛选调整

## 目标与范围

按用户截图移除全局“仅看优化异常”。用户要求昨天、近7天、近14天、近30天、本月、指定某日及自定义区间，并明确指定某日、本月常用、近30天不常用。仅调整V3运营总览的界面及日期计算；不写业务数据库、不操作电脑窗口，不修改生产中心、资料中心或外部平台数据。

## 实现

- 主栏为“昨天 / 近7天 / 近14天 / 本月 / 指定某日 / 更多”，默认近7天。更多包含近30天、保留的全部历史和自定义区间。指定某日直接选日期并显示完整年月日；区间应用后显示日期，长区间压缩展示、悬停可看完整范围。
- 新增 `src/components/cockpit/CockpitDateFilter.tsx`，全局、账号优化、风险诊断三处共用，状态相互联动。区间使用现有居中弹窗，取消不改变筛选，点击空白或Esc可退出；拒绝空值、无效日期、结束早于开始及未来日期。
- 新增 `src/services/cockpitDateRange.ts`，按接口返回的北京时间日期进行纯日期运算。滚动7/14/30天截至昨天，本月从1号至今天，自定义可以包含今天，包含两端日期。全部历史保留截至昨天。
- 数据模型统一起止日期，消除原先部分列表只检查开始日期的遗漏；作品、风险明细和风险分布统一按作品发布时间，检测日期单列。月累计仍要求完整周期包含于多日选区，不拆日。
- 日均收益按选区实际天数计算。趋势标注具体起止日期；账号详情取消“30日/近14天”固定标题与14天截断，详情中的风险明细也跟随全局日期，只有账号流量而没有日收益时仍展示流量趋势。数据导出沿用已筛选列表。
