# V3 FFmpeg模板生成接入

日期：2026-10-19。

## 目标与结论

按用户授权，在V3跑通“参数中心保存规则 → 生产中心模板制作 → 现有任务中心查看进度 → 完成后自动进入模板区域”。本轮源码、界面构建、相关自动检查和独立真实运行均完成；用户正式桌面重启和最终观感待确认。成片合成后续单独接入，V2保持原样。

当前规则集中维护于 [FFmpeg模板制作](../功能档案/02-执行器/FFmpeg模板制作.md)，本文记录本轮改动与验证证据。

## 正式改动

- 新增 `server/ffmpeg_templates/`：参数验证、持久化队列、批次参数副本与随机配方、风景用量预留、串行制作、媒体检查、发布入库及HTTP接口。
- 新增 `src/components/templates/` 和 `src/api/templateGeneration.ts`：模板参数、批次提交、队列与预览。生产中心增加“成片制作 / 模板制作”，现有模板卡片增加快捷入口。
- 接入原任务中心、顶栏状态及全局暂停/继续。模板暂停在当前份结束后生效，失败保留配方与记录，等待项可取消，失败项可按原配方重试。
- 成功输出经尺寸、帧率、帧数和完整解码检查后进入公共模板目录；刷新既有索引，确认卡片可识别后完成任务并记使用次数。
- 每模板保存预览MP4、配方、风景时间轴及蒙版、透明贴纸缓存、边条缓存和特效安排。预览中间是主素材位置示意；后续成片要使用分层文件。
- 复制所需素材运行文件到V3的 `tools/ffmpeg_overlay_lab/`，共1072个文件、约2636.8 MiB。包括31个贴纸系列670个单素材、104项特效素材记录及10个边条源片。贴纸为每模板重新随机组合，已有固定组合不限制新模板抽取。
- 同步功能档案、V3说明、决策日志及项目控制台。未提交、推送或打包。

制作默认规格为1080×2400、30fps；已确认的上下高度、蒙版、羽化、动画和边条规则沿用。首次接入的时长、条数及次数上限提供可调整默认值，参数表详见功能档案。

## 保护与实际影响

本轮只修改V3副本，保留V3已有未提交修改。未重启用户正在使用的V2或V3窗口，未运行剪映，未向业务任务或生产素材写入测试数据。

真实运行使用V3内独立测试工作区与独立数据库；复制8个现有风景文件后测试，不改变原片。测试服务使用5196端口，未启动旧生产调度器、收益调度器或清理任务。检查结束后确认无等待或执行任务，已停止本轮专用测试服务，保留全部测试文件。

从迁移清单逐一复核1072个V2源文件的SHA-256，变化数为0。迁移和校验记录位于本轮验证目录。V3运行时使用自己的素材副本，不依赖读取V2目录。

风景达到次数上限后停止抽取；本次没有接入自动删除原片。配额按成功模板计次，失败和取消不消耗次数，排队任务预留配额。此边界已在参数界面和功能规则说明。

## 耗时与优化边界

120秒样片完整生成耗时422秒，此结果在最后一次稳定段混合优化之前测得。随后对同一底片、同一特效、同一相位和强度、同样870帧做对照：特效稳定段从54.532秒降至5.469秒。改动为使用FFmpeg恒定透明度混合代替逐像素表达式，四种强度的像素对照已通过。

这项结果只代表同一29秒特效段的处理耗时。最新优化后尚未重新跑完整120秒制作，不能将局部约10倍差异套用于整条模板，也未验证另一台机器的速度。证据为 `optimized-effect/check.json` 和 `blend-check.json`。

## 文件归属与使用

- 正式源码、规则及V3素材副本保留在项目中；V2素材不变。
- 本轮测试脚本、独立数据库、失败尝试、成功视频和截图位于上述 `local-test-output`，属于验收材料，不导入真实业务模板库，也不自动清理。
- 用户从根目录 `启动V3开发版.bat` 正常重启V3后使用；若V2仍在运行，先正常关闭V2，保持原单实例护栏。
- 参数中心保存模板规则，生产中心 → 模板制作 → 生成模板；完成后可在该页预览，也自动进入成片制作内的模板区域。
- 真实生成物默认进入当前工作区的 `内容资产/公共模板`；模板分层包保存在 `系统数据/tg`，队列保存在 `系统数据/template_generation`。这些分层文件是后续成片合成的输入，不能仅保留MP4后清理掉。
