# V3素材数量强调色与素材管理弹窗

日期：2026-11-05

## 目标与最终范围

生产中心的素材数量采用软件强调色；点击“素材区域”标题打开管理弹窗，集中预览视频、查看详情、调整本素材中插/尾插。保留原双击预览，并在该预览底部“关闭”左侧增加删除按钮。

用户后续明确：删除直接删除原文件，不移入回收区；原素材、对应本地成片和合成任务一起删除。本次最终实现以这条规则为准，前期回收区及保留成片的建议不再适用。未执行真实业务删除。

## 已实施

- 有效素材数量使用深色小底（#1A1D2E）配荧光黄绿数字（#DDFD00）。
- 管理弹窗左侧可搜索、切换素材；中间为原视频播放器，支持进度、声音与全屏；右侧显示完整文件名、时长、大小、分辨率和可展开的完整路径。
- 本素材中插、尾插分别继承剧集、关闭或启用；展示实际继承规则，不扩展为本片独立选广告及设置时间。保存后留在弹窗，切换/关闭时保护未保存修改。保存和删除操作固定在右侧底部。
- 管理弹窗与原预览共用删除确认：读取原文件、已记录的当前/历史成片文件、对应合成缓存及任务；显示具体路径、成片数和任务数。再次确认时核验文件与任务指纹，变化则要求重新读取。
- 同时删除原文件、本素材关联的成片文件、专属FFmpeg缓存，以及本素材的FFmpeg任务、生产视频任务和关联导出子记录；等待任务一并删除。其他素材、公共模板、模板共享缓存和已成功使用计次保留。
- 正在合成/导出/发布、正式作品已关联、已登记发布、跨任务共用、路径归属或路径跳转异常时阻止删除；只使用数据库及历史记录证明归属的文件，不按相似名称批量删除。
- 素材保留不可见的已删除编号标记，扫描不把该标记当作普通缺失素材处理；新增不复用其最高编号，同名路径重新出现时提示核对。
- 删除前释放浏览器视频播放资源；失败不宣称成功，保留JSON记录和可重试状态。已经删除的文件不恢复，也不保存视频备份。删除结果审计位于系统数据目录的 `diagnostics/material-deletions/`。

## 实现入口

- `src/components/production/ProductionCenter.tsx`：标题入口、原预览删除按钮、详情/数量/任务刷新。
- `src/components/production/MaterialManagerModal.tsx`：管理弹窗。
- `src/components/production/MaterialDeleteDialog.tsx`：共用删除确认。
- `src/components/production/InsertionSettingsModal.tsx`：复用原插片设置，支持嵌入及固定操作区。
- `src/api/v2Production.ts`、`src/productionTypes.ts`：删除接口与状态。
- `server/production_materials.py`：删除范围、归属和执行保护、文件与任务删除、失败记录。
- `server/v2_file_service.py`：接口路由和扫描编号/删除状态处理；无新增数据库结构。
