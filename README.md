# 短剧推广运营系统 V3（开发版）

这是从 `D:\ShortDramaPlatform_V2` 当前工作区复制出的独立升级开发项目。公共模板支持短名称、实际视频预览、选用、人工删除与使用上限；生产资源为风景视频，BGM界面入口已撤下。FFmpeg模板制作与成片合成都已接入生产中心及任务中心，直接使用模板分层缓存合成素材并保留原声，成功后进入成片区域。

- V3 源码：`D:\ShortDramaPlatform_V3`
- 保留的 V2：`D:\ShortDramaPlatform_V2`，本次不改动。
- 数据：按用户要求，共用原机器设置对应的业务目录和数据库；当前目录为 `D:\短剧推广运营系统`。
- 共用数据库时两版轮流运行。以后 V3 改变数据库结构，可能影响旧 V2 的运行兼容性；用户已接受数据库内容变化或丢失。
- 视频、素材、草稿和导出成片仍受保护，不因共用数据库而允许清理。

## 启动

Windows 上双击根目录 **`启动V3开发版.bat`**。需要本机已有 Node.js 20+ 和 Python 3.12.10，以及 V2 原有的 Python 运行依赖。

入口首次缺少界面依赖时执行 `npm ci`，每次从本副本源码构建界面，再启动标题为“短剧推广运营系统 V3（开发版）”的桌面窗口。若 V2 已占用本地服务端口，现有护栏会拒绝启动 V3；先正常关闭 V2，再启动 V3。入口不会自动终止 V2。

原 `tools\start_v2_desktop.bat` 已转接到 V3 入口；原重启脚本在本副本中已改为不停止其他进程的兼容入口。

## 验证

沿用 `tools\一键验证.bat` 或 `py -3.12 tools\verify_v2.py`。验证脚本仍把数据库指向临时工作区，保护真实业务环境。
