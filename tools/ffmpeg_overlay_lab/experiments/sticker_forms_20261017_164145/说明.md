# 上下贴纸五种形态方向样式板

按用户确认的范围，先只探索上下贴纸，统一浅色平面线描，生成一张三列五行的方向样式板。内置 image_gen 调用一次，调用耗时 36.743 秒，不包含提示词整理、归档和编号预览制作时间。

| 编号 | 形态 | 内容 |
|---|---|---|
| 01—03 | 独立小图案 | 茶杯、银杏叶、相机 |
| 04—06 | 小簇组合 | 小花簇、星月组合、枝叶小簇 |
| 07—09 | 角落装饰 | 枝叶角饰、弧线角饰、水纹角饰 |
| 10—12 | 垂挂或伸入 | 垂挂小物、下垂花枝、向上细叶 |
| 13—15 | 短线和零散装饰 | 短段水波、圆环散点、虚线轨迹 |

- `样式板_编号预览.jpg`：加深色预览底、中文编号的查看图。预览底色与文字不包含在透明原图中。
- `样式板_透明原图.png`：生成原图的项目副本，971×1619，RGBA；未进行单件切分或启用为正式素材。
- `prompt.json`：本轮实际完整提示词与编号顺序。
- `generation_result.json`：生成工具原始路径与本次调用耗时。
- `checks.json`：原图和项目副本 SHA-256 一致；alpha 最小值 0、最大值 255，约 66.3% 像素完全透明。
- `preview.ffgraph`、各标题和编号文本：可复核编号预览的排版过程。

实际查看确认十五种图案均出现，分布与编号对应；用途是选择形态和画法。生成的一张样式板不等于十五份已经通过验收、可直接生产使用的独立素材。选定方向后再单独生成、细化素材。本轮不处理左右纹理、粒子或视频合成。
