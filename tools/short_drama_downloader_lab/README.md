# 短剧原片下载实验工具

这是 V2 项目目录下的独立实验工具，不接入 V2 主程序、V2 数据库或现有生产任务，也不修改 `D:\爆款拆解`。

## 使用顺序

1. 手机连接并保持主微信用户0/ADB 可用。
2. 双击 `start_collect.bat`，每集分享短链会写入本目录的 `采集表.txt`。
3. 双击 `start_download.bat`，脚本调用解析接口并下载 MP4 到 `原片\剧名\`。

## 快速测试

```powershell
python -X utf8 批量解析下载.py --limit 1
python -X utf8 批量解析下载.py --drama "医武镇九州" --limit 20
```

配置在 `配置.json`。当前已验证参数为 `uid=408333`、`agentid=82`。解析服务失效时只需替换配置或解析适配器，不影响 V2 主程序。
